# Figma-плагин DS Builder

Приватный плагин организации: вход в DS Builder, просмотр токенов темы и экспорт темы в переменные и стили
открытого файла Figma.

## Устройство

- `src/main` — основной поток Figma: `figma.clientStorage`, внешний браузер и запись плана экспорта в документ.
  Об API, OAuth и правилах DS Builder не знает.
- `src/ui` — окно плагина на React: экраны и связь с общими Kotlin-модулями.
- `frontend-kt/plugins/figma-core` — вход, сессия, запросы к API и построение плана экспорта на Kotlin/JS. Сборка
  плагина собирает его сама, поэтому нужен JDK 17.
- `src/shared` — протокол сообщений между ними.

Запросы к API идут из окна. Его origin — `null`, поэтому gateway нужна настройка `OIDC_PLUGIN_ORIGINS=null`.

## Экспорт в Figma

Кнопка «Экспортировать в Figma» читает выбранную тему и версию и записывает в открытый файл структуру образца
`DS BUILDER | STYLES`:

| Коллекция | Режимы | Содержимое |
|---|---|---|
| `00. Palette` | Default | ступени палитры темы `<группа>/<шкала>/<ступень>` |
| `01. Theme` | Light, Dark | цвета всех контекстов, ссылки на палитру; скрыты из выбора |
| `02. SubTheme` | Default, onDark, onLight, Inverse | цвета без контекста, ссылки на тему |
| `03. Typography` | Large, Medium, Small | размер, высота строки, интервал, насыщенность, семейства |
| `04. Numbers` | Default | скругления |
| `05. Spacing` | Default | отступы |

Кроме переменных создаются текстовые стили с привязкой к `03. Typography`, стили эффектов для теней и стили заливки
`Light/…` и `Dark/…` для градиентов. Состояния `-hover`, `-active`, `-brightness` лежат рядом с основным цветом:
`Primary`, `PrimaryHover`, `PrimaryActive`, `PrimaryBrightness`. Скругления повторяют набор образца: `cRxxs` … `cRxxl`,
`null` = 0, `Rounded` = 1000 и внутренние радиусы `calc:[cR<размер>-2]`. Выключенные в DS Builder токены не
экспортируются.

Повторный экспорт находит созданное по общему ключу плагина `dsbuilder` и обновляет его: дубликатов нет, привязанные
слои получают новые значения. То, чего больше нет в теме, не удаляется и считается в отчёте устаревшим.

Один файл Figma рассчитан на одну дизайн-систему: экспорт другой дизайн-системы в тот же файл пометит прежние
переменные устаревшими. Темы одной дизайн-системы перезаписывают значения друг друга, отчёт называет последнюю.

Ограничения Figma: на тарифе Starter у коллекции один режим, и экспорт остановится с причиной на втором режиме.
Текстовый стиль пропускается, если шрифта семейства нет у пользователя Figma; отчёт называет недостающие шрифты.
Figma desktop видит шрифты, установленные в системе, поэтому у дизайнеров с SB Sans стили создаются.

В просмотре токенов любое имя и значение копируется нажатием.

## Запуск

```bash
npm install
npm run build:dev   # адрес gateway http://localhost:8080
```

В Figma desktop: Plugins → Development → Import plugin from manifest, выбрать `manifest.json`.

Локальному контуру нужны клиент `dsbuilder-figma-plugin` и роль `offline_access` в составе `user`: они создаются
импортом realm. Импорт не выполняется поверх существующей базы Keycloak, поэтому пересоздайте её.

## Проверки

```bash
npm test
npm run build       # адрес боевого gateway
```

## Публикация

Приватная публикация выполняется в организации Figma. Figma выдаёт `id` плагина: запишите его в `manifest.json`
вместо значения для разработки.
