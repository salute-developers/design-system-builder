# Локальная генерация тем JS CLI

CLI вызывает `generateThemeSet(themeSources, outputDirectory, options)` из
`js/cli/src/generator/themeBuilder` — генератора, перенесённого из удалённого сервиса генерации.
В CLI нет отдельной реализации генерации CSS, TypeScript или токенов темы.

Адаптер `js/cli/src/generate-theme.ts` раскрывает ссылки на локальную палитру `.sdds`
в цвета, включая альфа-канал, и передаёт метаданные и web-вариации генератору.
Неразрешённая ссылка вызывает ошибку до очистки результата, чтобы генератор не
подменил отсутствующий локальный цвет значением из встроенной палитры.
Исходные данные не изменяются: `meta.js` и `variations.js` сохраняют прежний формат.
Перед генерацией CLI очищает каталог результата темы.

Тема всегда передаётся генератору явно; загрузки темы из внешнего источника нет.
Структура результата остаётся `themes`, `css`, `tokens` и корневой `index.ts`.
Побайтовая совместимость с удалённым `cli/theme-builder` не гарантируется:
форматирование, обработка пропущенных значений и старых имён токенов Plasma
определяются генератором.
