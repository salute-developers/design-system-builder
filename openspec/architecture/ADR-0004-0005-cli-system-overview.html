ADR-0004 + ADR-0005 · Верхнеуровневая архитектура

CLI, MCP и приложения используют одни сценарии, контекст и авторизацию

CLI — только один из интерфейсов. Бизнес-логика живёт в общем KMP application layer, а доступ к backend всегда проходит через единые правила контекста и credentials.

Проектный режим · владельцы дизайн-системы и CI

CLI → локальная <workspace>/.sdds → project key → генерация, синхронизация и публикация воспроизводимых артефактов.

2
Потребительский режим · IDE, Desktop и MCP

User auth → явный выбор дизайн-системы → контекст в IDE/Desktop или ~/.sdds. Локальная .sdds проекта не обязательна.
