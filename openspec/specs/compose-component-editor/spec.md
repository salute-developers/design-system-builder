# compose-component-editor Specification

## Purpose
Редактирование конфигураций Compose-компонентов и выбор платформенного превью с восстановлением после остановки плагина.

## Requirements
### Requirement: Component configs are served per platform

`GET /legacy/design-systems/{name}/component-configs` SHALL принимать необязательный параметр
`platform` со значениями `web` и `compose` и отдавать только компоненты этой платформы. Без
параметра endpoint MUST вести себя как `platform=web`. Неизвестное значение MUST давать `400`.

#### Scenario: Запрос без платформы

- **WHEN** клиент запрашивает конфиги без `platform`
- **THEN** ответ MUST содержать только web-компоненты, как до изменения.

#### Scenario: Запрос Compose-конфигов

- **WHEN** клиент запрашивает `platform=compose`
- **THEN** ответ MUST содержать Compose-компоненты дизайн-системы
- **AND** `platformMappings.compose` свойств MUST быть заполнен.

#### Scenario: Неизвестная платформа

- **WHEN** `platform` не равен `web` и `compose`
- **THEN** endpoint MUST ответить `400` и MUST NOT вернуть данные.

### Requirement: Editor lists Compose components separately

Клиент SHALL при заданном URL плагина и поддерживаемом окружении загружать Compose-конфиги и
показывать их отдельной платформой: переключатель платформ над списком компонентов, где показываются только платформы с компонентами. Идентичность компонента в клиенте MUST включать платформу, а
web- и Compose-компоненты с одним именем MUST NOT подменять друг друга.

#### Scenario: Имя есть и у web, и у Compose

- **WHEN** у дизайн-системы есть `Avatar` обеих платформ
- **THEN** меню MUST показывать оба и открывать каждый со своими свойствами.

#### Scenario: Плагин не настроен

- **WHEN** URL плагина не задан либо окружение не поддерживает Wasm
- **THEN** платформа Compose MUST NOT предлагаться, поведение редактора остаётся прежним.

### Requirement: Compose binding is derived from the component

Привязка Compose-компонента к плагину SHALL выводиться из его имени: `componentId` и `storyId`
равны имени. Клиент MUST NOT хранить жёсткую привязку имён web-компонентов к Compose-компонентам.

#### Scenario: Компонент есть в манифесте

- **WHEN** имя Compose-компонента входит в `manifest.components`
- **THEN** editor MUST отрисовать его Compose-плагином по свойствам из его конфигурации.

#### Scenario: Компонента нет в манифесте

- **WHEN** имя не входит в `manifest.components`
- **THEN** editor MUST открыть компонент без preview с диагностикой и MUST NOT падать.

### Requirement: Preview recovers from a stopped plugin

Клиент SHALL считать плагин остановленным, если запрос render завершился `failure` с кодом
`render_crashed` или `plugin_crashed`, либо не получил ответа за время ожидания запроса. Клиент SHALL
перезагрузить iframe, MUST NOT повторно отправлять payload, остановивший плагин (сравнение по содержимому, а не по ссылке на объект), и SHALL показать причину.
Следующий payload SHALL отправляться в перезапущенный плагин.

#### Scenario: Компонент останавливает плагин

- **WHEN** payload компонента останавливает Compose в плагине
- **THEN** клиент MUST перезагрузить iframe и показать, что превью перезапущено
- **AND** клиент MUST NOT отправлять тот же payload повторно.

#### Scenario: Выбор другого компонента после сбоя

- **WHEN** пользователь выбирает другой компонент после сбоя плагина
- **THEN** клиент MUST отрисовать его в перезапущенном плагине.

#### Scenario: Плагин отклоняет payload

- **WHEN** плагин отвечает `failure` с кодом, не означающим остановку (например, `preview_preparation_failed`)
- **THEN** клиент MUST показать причину и MUST NOT перезагружать iframe.

### Requirement: Preview учитывает сочетания стилей

Клиент SHALL учитывать значения свойств, заданные для сочетаний стилей нескольких вариаций
(`combinations`). Значение сочетания действует, когда выбраны все его стили; более полное сочетание
перекрывает менее полное, а любое сочетание перекрывает значение отдельного стиля.

#### Scenario: Выбраны все стили сочетания

- **WHEN** выбраны `size=xxs` и `gap=wide`, а для этого сочетания задан `spacing`
- **THEN** payload MUST содержать значение `spacing` этого сочетания.

#### Scenario: Часть стилей сочетания не выбрана

- **WHEN** выбран `size=xxs`, а `gap` не выбран
- **THEN** значение сочетания `size=xxs` и `gap=wide` MUST NOT попадать в payload.

### Requirement: Preview передаёт вложенные стили

Свойство-ссылка на стиль другого компонента (`basic-button.xxs.default`) SHALL передаваться как
вложенный стиль: клиент находит конфигурацию целевого компонента, выбирает указанные стили (остальные
вариации берут стиль по умолчанию), собирает его свойства, включая сочетания и вложенные ссылки, и
ссылается на него через `styleRef`. Ссылка, которую нельзя развернуть (нет цели, цикл, глубина больше предела),
MUST NOT отправляться как ссылка на токен.

#### Scenario: Компонент ссылается на стиль другого компонента

- **WHEN** выбранный стиль `ButtonGroup` содержит ссылку `basic-button.xxs.default`
- **THEN** payload MUST содержать вложенный стиль компонента `BasicButton` со свойствами выбранных стилей
- **AND** свойство `buttonStyle` MUST ссылаться на него через `styleRef`.

#### Scenario: Ссылка не разворачивается

- **WHEN** целевой конфигурации нет в дизайн-системе
- **THEN** свойство MUST быть пропущено, а preview MUST отрисоваться со стилем по умолчанию.
