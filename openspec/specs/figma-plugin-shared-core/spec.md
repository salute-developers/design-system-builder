# figma-plugin-shared-core Specification

## Purpose
Окно плагина Figma работает с бэкендом только через общие Kotlin-модули.
## Requirements
### Requirement: Единая интеграция с бэкендом

Окно плагина MUST выполнять все запросы к gateway через общие Kotlin-модули. Код окна на TypeScript MUST NOT содержать пути API и вызовы `fetch`. Адрес gateway и идентификатор клиента остаются настройками сборки и передаются в модуль при создании.

#### Scenario: Чтение данных

- **WHEN** экран запрашивает проекты, дизайн-системы, темы, версии или токены
- **THEN** запрос MUST выполняться через API модуля `:plugins:figma-core`

#### Scenario: Проверка исходного кода

- **WHEN** выполняются тесты плагина
- **THEN** они MUST завершаться ошибкой, если в `js/apps/figma-plugin/src/ui` вне сгенерированного кода есть вызов `fetch` или путь `/api/`

### Requirement: Отказы для экранов

API модуля MUST передавать отказ с видом и кодом, чтобы окно показывало сообщения экранов.

#### Scenario: Запрет доступа

- **WHEN** gateway отвечает `403`
- **THEN** окно MUST показать сообщение «Нет доступа»

#### Scenario: Сбой сети

- **WHEN** запрос не дошёл до gateway
- **THEN** отказ MUST иметь вид `network`, а сохранённая сессия MUST остаться

#### Scenario: Сбой сети при ожидании входа

- **WHEN** соединение обрывается, пока плагин ждёт подтверждения входа
- **THEN** опрос MUST продолжиться

#### Scenario: Отказ OAuth

- **WHEN** Keycloak отклоняет обновление токена с кодом `invalid_grant`
- **THEN** общий клиент MUST передать этот код, а сессия MUST завершиться

### Requirement: Сессия при выходе

Обновление токена, начатое до выхода, MUST NOT возвращать токены после выхода.

#### Scenario: Выход во время записи токена

- **WHEN** пользователь выходит, пока обновлённый токен записывается в хранилище
- **THEN** после завершения записи хранилище и память MUST NOT содержать токенов

### Requirement: Отмена запроса

API модуля MUST отменять запрос по переданному `AbortSignal`.

#### Scenario: Смена контекста

- **WHEN** пользователь выбирает другую тему, пока загружаются токены
- **THEN** прежний запрос MUST быть отменён, а его результат MUST NOT попасть на экран

#### Scenario: Отмена после получения токенов

- **WHEN** пользователь нажимает «Отмена», когда токены уже получены и записываются
- **THEN** вход MUST завершиться, а окно MUST показать выбор контекста

### Requirement: Сборка плагина

Сборка плагина MUST собирать Kotlin-модуль сама. Результат сборки Kotlin MUST NOT храниться в Git. Размер `dist/ui.html` MUST NOT превышать 900 КиБ.

#### Scenario: Чистая копия репозитория

- **WHEN** разработчик запускает сборку плагина в чистой копии
- **THEN** сборка MUST создать `dist/ui.html` со встроенным Kotlin-кодом без ручных шагов

#### Scenario: Лишние зависимости

- **WHEN** размер `dist/ui.html` превышает 900 КиБ
- **THEN** проверка сборки MUST завершиться ошибкой
