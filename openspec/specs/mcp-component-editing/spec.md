# mcp-component-editing Specification

## Purpose
Редактирование конфигураций компонентов выбранной дизайн-системы через MCP: оси, варианты, значения свойств, ссылки, наборы состояний и порядок без изменения общего каталога.

## Requirements

### Requirement: Управление конфигурациями

MCP SHALL предоставлять `component_configuration_create`, `component_configuration_duplicate`, `component_configuration_update`, `component_configuration_delete`. Операции SHALL использовать существующие правила имён, дублирования, зависимостей и защиты конфигурации по умолчанию.

#### Scenario: Новая конфигурация и копия
- **WHEN** пользователь создаёт конфигурацию или дублирует существующую
- **THEN** сервер MUST выполнить соответствующую существующую атомарную операцию
- **THEN** MCP MUST вернуть appearanceId и подтверждённые данные
- **THEN** редактирование копии MUST NOT изменять исходную конфигурацию от имени клиента

#### Scenario: Переименование и защищённое удаление
- **WHEN** пользователь переименовывает конфигурацию или пытается удалить конфигурацию по умолчанию
- **THEN** MCP MUST сохранить проверку уникальности имени и отказ default_appearance_protected

#### Scenario: Используемая конфигурация
- **WHEN** на удаляемую конфигурацию существуют ссылки
- **THEN** MCP MUST сохранить серверный reference_in_use и детали зависимостей
- **THEN** MCP MUST NOT обходить reference_in_use дополнительными удалениями зависимостей

### Requirement: Оси конкретной конфигурации

MCP SHALL предоставлять `component_axis_create`, `component_axis_update`, `component_axis_delete`, `component_axes_reorder`. Обновление SHALL поддерживать имя, позицию, defaultStyleId, isRoot, isColorScheme и declaredType в пределах существующего API редактора.

#### Scenario: Создание и изменение оси
- **WHEN** пользователь добавляет ось со значениями, меняет её имя или роли
- **THEN** MCP MUST адресовать объявление оси выбранной конфигурации
- **THEN** прямые административные мутации variation общего каталога MUST NOT вызываться

#### Scenario: Порядок и значение по умолчанию
- **WHEN** передан полный axisIds либо defaultStyleId
- **THEN** MCP MUST делегировать проверку полноты порядка и допустимости значения серверу
- **THEN** ответ последующего чтения MUST отражать подтверждённый порядок и значение по умолчанию

#### Scenario: Заблокированная или используемая ось
- **WHEN** удаляется заблокированная ось либо ось с зависимостями
- **THEN** MCP MUST сохранить axis_locked или reference_in_use и серверные детали
- **THEN** confirmCascade MUST NOT включаться автоматически

### Requirement: Значения осей и варианты

MCP SHALL предоставлять `component_axis_value_create`, `component_axis_value_update`, `component_axis_value_delete`, `component_axis_values_reorder`. Значения SHALL адресоваться ID объявления значения в конкретной конфигурации, а ссылки свойств — соответствующими styleId.

#### Scenario: Работа с вариантом
- **WHEN** пользователь создаёт значение оси, меняет displayName, authoredId или позицию либо удаляет значение
- **THEN** операция MUST сохранить существующие правила редактора и стабильные ID остальных значений
- **THEN** MCP MUST NOT подменять ID объявления идентификатором стиля каталога

#### Scenario: Перестановка вариантов
- **WHEN** передан полный упорядоченный список valueIds одной оси
- **THEN** MCP MUST отправить его существующему API перестановки
- **THEN** неполный, повторяющийся или чужой список MUST завершаться ошибкой без клиентского исправления

### Requirement: Значения свойств и наборы состояний

MCP SHALL предоставлять `component_property_set`, `component_property_reset`, `component_states_reorder`. Область SHALL задаваться appearanceId, propertyId, styleIds и states; пустой styleIds означает базу, один стиль — вариант, несколько — сочетание вариантов.

#### Scenario: Литерал или ссылка
- **WHEN** пользователь задаёт литерал, tokenId либо ссылку на стиль вложенного компонента с поддерживаемыми alpha/adjustment
- **THEN** MCP MUST передать типизированный запрос существующему редактору
- **THEN** ссылка MUST NOT заменяться её текущим вычисленным значением или именем

#### Scenario: Добавление и удаление состояния свойства
- **WHEN** пользователь задаёт значение с непустым states или сбрасывает такое назначение
- **THEN** MCP MUST создать либо удалить значение именно этого набора состояний в указанной области
- **THEN** базовое назначение MUST NOT изменяться от имени клиента

#### Scenario: Порядок наборов состояний
- **WHEN** пользователь передаёт упорядоченный массив наборов состояний свойства в выбранной области
- **THEN** MCP MUST использовать существующую операцию state-order
- **THEN** он MUST NOT менять общий каталог состояний

#### Scenario: Несовместимый тип или область
- **WHEN** тип значения несовместим со слотом либо styleIds не образуют допустимую область
- **THEN** MCP MUST сохранить серверную ошибку и MUST NOT менять тип слота или выбирать другую область

### Requirement: Чтение исходной модели редактора

`component_editor_get` SHALL принимать appearanceId и возвращать исходную модель черновика: конфигурацию, оси, роли, значения по умолчанию, варианты, назначения свойств, состояния и доступные предметные редакции. `component_config_get` SHALL сохранять назначение чтения вычисленных свойств.

#### Scenario: Подготовка изменения
- **WHEN** пользователь читает модель для редактирования
- **THEN** результат MUST сохранять ID объявлений осей и значений отдельно от variationId и styleId
- **THEN** исходные назначения MUST сохранять область, набор состояний и доступные редакции

#### Scenario: Вычисленное значение
- **WHEN** пользователь вызывает существующий `component_config_get`
- **THEN** его схема и вычисленная семантика MUST оставаться совместимыми
- **THEN** описание MUST направлять к `component_editor_get` для исходных назначений

### Requirement: Общий каталог недоступен для записи

MCP MUST NOT предоставлять мутации общих компонентов, свойств, состояний, платформ и их административной меты. Использование существующих состояний в конфигурации SHALL оставаться доступным в пределах прав пользователя редактора.

#### Scenario: Учётные данные администратора
- **WHEN** сервер MCP запущен с административными учётными данными
- **THEN** реестр MUST NOT содержать инструменты записи общего каталога
- **THEN** инструменты конфигурации MUST NOT принимать произвольный административный маршрут
