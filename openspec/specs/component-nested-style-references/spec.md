## Requirements
### Requirement: Запись ссылки на стиль вложенного компонента

Операция записи значения свойства типа `component_style` SHALL принимать ссылку как оформление целевого компонента и список стилей его осей и записывать значение и запись `component_style_references` с `component_style_reference_styles` в одной транзакции.

#### Scenario: Ссылка на стиль вложенного компонента

- **WHEN** редактор записывает значение свойства `component_style` со ссылкой на оформление `basic-button` и стили `size=xxs`, `view=default`
- **THEN** `ds-service` MUST записать значение и ссылку, указывающую на это оформление и эти стили
- **THEN** текст значения MUST собираться из действующих имён оформления и стилей в порядке осей целевого оформления

#### Scenario: Ссылка у значения с состоянием

- **WHEN** ссылка записывается у значения с набором состояний
- **THEN** `ds-service` MUST записать ссылку этой строки значения
- **THEN** ссылка базы той же области MUST NOT измениться

#### Scenario: Ссылка у сочетания

- **WHEN** ссылка записывается у значения сочетания стилей
- **THEN** `ds-service` MUST связать ссылку с этим сочетанием

#### Scenario: Зависимость компонентов

- **WHEN** целевой компонент отличается от компонента оформления и связи `reuse` между ними нет
- **THEN** `ds-service` MUST создать её в той же транзакции

### Requirement: Проверка ссылки

`ds-service` SHALL проверять ссылку до записи и отклонять невалидную операцию без изменений.

#### Scenario: Цель не существует

- **WHEN** целевое оформление не существует или недоступно для чтения
- **THEN** `ds-service` MUST ответить `422` с кодом `reference_target_not_found`

#### Scenario: Стиль не принадлежит цели

- **WHEN** стиль не объявлен в осях целевого оформления либо два стиля принадлежат одной оси
- **THEN** `ds-service` MUST ответить `422` с кодом `reference_invalid_styles`

#### Scenario: Другая дизайн-система

- **WHEN** целевое оформление принадлежит другой дизайн-системе
- **THEN** `ds-service` MUST ответить `422` с кодом `reference_target_not_found`

#### Scenario: Цикл

- **WHEN** запись замкнула бы цепочку ссылок, в том числе на собственное оформление
- **THEN** `ds-service` MUST ответить `422` с кодом `reference_cycle`

#### Scenario: Предельная глубина

- **WHEN** длина цепочки ссылок от оформления превысила 5
- **THEN** `ds-service` MUST ответить `422` с кодом `reference_too_deep`

### Requirement: Каскад при переименовании и удалении

Переименование оси или значения оси и их удаление SHALL приводить ссылки на них в согласованное состояние в той же транзакции.

#### Scenario: Переименование значения

- **WHEN** переименовано значение оси, на которое указывают ссылки других оформлений
- **THEN** `ds-service` MUST пересобрать текст `reference` и значение этих ссылок с новым именем
- **THEN** связи ссылок со стилями MUST NOT измениться

#### Scenario: Переименование конфигурации

- **WHEN** переименовано оформление, на которое указывают ссылки других оформлений
- **THEN** `ds-service` MUST пересобрать текст `reference` этих ссылок с новым именем первого сегмента

#### Scenario: Удаление значения

- **WHEN** удалено значение оси, на которое указывают ссылки
- **THEN** `ds-service` MUST удалить ссылку и значение свойства, которому она принадлежит, или отклонить операцию с кодом `reference_in_use`
- **THEN** ответ MUST перечислять затронутые значения

### Requirement: Импорт сохраняет ссылки значений с состояниями

Импорт конфигурации SHALL записывать ссылку на стиль вложенного компонента и для значений с состояниями.

#### Scenario: Значение с состоянием содержит ссылку

- **WHEN** импортируется значение `component_style` с состоянием
- **THEN** `ds-service` MUST записать ссылку, связанную с этой строкой значения
