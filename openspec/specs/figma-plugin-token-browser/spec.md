## Requirements
### Requirement: Выбор контекста

После входа плагин SHALL проводить пользователя по шагам проект → дизайн-система → тема с хлебными крошками. При движении вперёд шаг с единственным вариантом SHALL пропускаться. Последний выбор SHALL запоминаться для пользователя в `figma.clientStorage`.

#### Scenario: Один проект

- **WHEN** пользователю доступен один проект
- **THEN** плагин MUST сразу показать дизайн-системы этого проекта

#### Scenario: Возврат на шаг

- **WHEN** пользователь нажимает элемент хлебных крошек
- **THEN** плагин MUST показать содержимое этого элемента (темы дизайн-системы, дизайн-системы проекта, для корневого элемента «Проекты» — список проектов) и сбросить выбор следующих шагов
- **THEN** открытый шаг MUST показать список, даже если вариант в нём один
- **WHEN** элемент соответствует текущему уровню
- **THEN** элемент MUST быть неактивным и отмечен `aria-current="page"`

#### Scenario: Запомненный контекст недоступен

- **WHEN** сохранённая тема больше не доступна пользователю
- **THEN** плагин MUST вернуться к ближайшему доступному шагу без ошибки на экране

#### Scenario: Нет доступных проектов

- **WHEN** список проектов пуст
- **THEN** плагин MUST показать текст о том, что нет доступных проектов, и действие «Выйти»

### Requirement: Выбор версии

Плагин SHALL предлагать активный черновик и опубликованные версии дизайн-системы. По умолчанию SHALL выбираться последняя опубликованная версия, а без опубликованных — черновик. Все чтения токенов SHALL выполняться на выбранной границе с одним `versionId`.

#### Scenario: Опубликованная версия

- **WHEN** пользователь выбирает версию `1.2.0`
- **THEN** определения и значения токенов MUST читаться с `versionId` этой версии

#### Scenario: Темы нет в версии

- **WHEN** выбранной темы нет в опубликованной версии и API отвечает `404`
- **THEN** плагин MUST сообщить об этом и оставить выбор версии доступным

#### Scenario: Черновик

- **WHEN** пользователь выбирает черновик
- **THEN** чтения MUST выполняться без `versionId`, а плагин MUST показать пометку, что значения не опубликованы

### Requirement: Просмотр токенов

Плагин SHALL показывать токены выбранной темы только для чтения в разделах «Цвета», «Типографика», «Размеры» со значениями платформы web. Плагин MUST NOT изменять данные DS Builder. Файл Figma плагин MUST изменять только по явному действию «Экспортировать в Figma».

#### Scenario: Цвета

- **WHEN** открыт раздел «Цвета»
- **THEN** токены `color` и `gradient` MUST показываться по группам с образцом и значением выбранного режима Light или Dark
- **THEN** значения MUST браться разрешёнными из `tenants/{id}/token-values`, а не из глобальной палитры

#### Scenario: Типографика

- **WHEN** открыт раздел «Типографика»
- **THEN** стили MUST показываться по группам и выбранному экрану с размером, высотой строки, весами и семейством

#### Scenario: Размеры

- **WHEN** открыт раздел «Размеры»
- **THEN** радиусы, отступы и тени MUST показываться со значением в px, тени — со слоями

#### Scenario: Значение не разобрано

- **WHEN** значение токена не удалось разобрать
- **THEN** строка MUST показать исходное значение и пометку, а остальные токены MUST показываться

#### Scenario: Просмотр без экспорта

- **WHEN** пользователь открывает разделы и ищет токены, не нажимая «Экспортировать в Figma»
- **THEN** плагин MUST NOT создавать и изменять переменные, стили и узлы документа

### Requirement: Поиск токенов

Плагин SHALL искать токены открытого раздела по имени без учёта регистра; совпадения с начала имени SHALL идти первыми.

#### Scenario: Нет совпадений

- **WHEN** поиск не находит токенов
- **THEN** плагин MUST показать текст, что ничего не найдено

### Requirement: Загрузка и ошибки

Плагин SHALL показывать состояние загрузки каждого шага и ошибку с действием «Повторить». Смена контекста SHALL отменять результат предыдущего чтения.

#### Scenario: Ответ устаревшего чтения

- **WHEN** пользователь сменил тему, пока шло чтение предыдущей
- **THEN** ответ предыдущего чтения MUST NOT попасть на экран

#### Scenario: Нет прав

- **WHEN** API отвечает `403`
- **THEN** плагин MUST показать, что нет доступа, и вернуть к выбору контекста

### Requirement: Оформление окна

Окно плагина SHALL следовать светлой и тёмной теме Figma через цветовые переменные Figma.

#### Scenario: Тёмная тема Figma

- **WHEN** в Figma включена тёмная тема
- **THEN** плагин MUST показываться в тёмном оформлении без действий пользователя

### Requirement: Копирование из просмотра

Каждое показанное в просмотре токенов имя и значение SHALL копироваться в буфер обмена нажатием: имя токена, значение цвета или градиента, размер и высота строки, насыщенности, шрифт, значения размеров и слои тени. После копирования окно SHALL показать подтверждение со скопированным текстом.

#### Scenario: Копирование HEX

- **WHEN** пользователь нажимает значение `#24B23E` у токена в разделе «Цвета»
- **THEN** в буфер обмена MUST попасть `#24B23E`, а окно MUST показать «Скопировано: #24B23E»

#### Scenario: Копирование имени

- **WHEN** пользователь нажимает имя токена
- **THEN** в буфер обмена MUST попасть показанное имя

#### Scenario: Буфер недоступен

- **WHEN** окно не может записать в буфер обмена
- **THEN** окно MUST сообщить, что скопировать не удалось, и не прерывать просмотр
