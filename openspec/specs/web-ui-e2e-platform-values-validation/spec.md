# web-ui-e2e-platform-values-validation Specification

## Purpose
Закрепить воспроизводимыми UI E2E платформенные радиусы и слои теней, распространение начертаний типографики и сохранность данных при невалидном числовом вводе.

## Requirements

### Requirement: Платформенные и вычисляемые радиусы
Набор MUST проверять собственный радиус Android и пересчёт производных радиусов при изменении основного, включая сохранение после повторного открытия.

#### Scenario: T800 — собственный радиус Android
- **WHEN** Editor добавляет, изменяет и снимает собственный радиус Android
- **THEN** Web и iOS сохраняют исходные значения, Android хранит своё значение до снятия, затем наследует Web; результат сохраняется после перезагрузки

#### Scenario: T738 — пересчёт производных
- **WHEN** Editor изменяет основной радиус
- **THEN** дерево, борд и производные значения показывают новый радиус и соответствующие смещения с нижней границей ноль, а соседний радиус и полное скругление сохраняются

### Requirement: Защита от невалидного радиуса
Набор MUST проверять, что недопустимый числовой ввод не сохраняется и не изменяет значения или ревизии размеров.

#### Scenario: T739 — отклонение неверного радиуса
- **WHEN** Editor вводит отрицательный, превышающий 1000 px, дробный, пустой или нечисловой радиус
- **THEN** UI сообщает об ошибке, запрос сохранения не отправляется, предыдущее значение и производные сохраняются после повторного открытия

### Requirement: Состав и платформенная изоляция теней
Набор MUST проверять добавление и удаление слоёв Web и независимые слои iOS без изменения соседних токенов.

#### Scenario: T751 — добавление и удаление слоёв
- **WHEN** Editor добавляет слой Web, задаёт отличимые параметры и удаляет выбранный слой
- **THEN** состав и порядок оставшихся слоёв, превью и сохранённые данные соответствуют действиям после перезагрузки; тень сохраняет хотя бы один слой

#### Scenario: T754 — собственные слои iOS
- **WHEN** Editor добавляет собственные слои iOS и меняет слои Web
- **THEN** iOS сохраняет собственные параметры, Android продолжает наследовать Web, а снятие собственных слоёв восстанавливает наследование iOS

### Requirement: Начертания и платформы типографики
Набор MUST проверять изменение Bold на всех экранах и независимые платформенные значения высоты строки Android и веса Bold iOS.

#### Scenario: T696 — вес Bold на всех экранах
- **WHEN** Editor меняет вес Bold
- **THEN** Bold сохраняет новый вес на крупных, средних и мелких экранах, Regular и Medium сохраняют исходные веса

#### Scenario: T700 — высота строки Android
- **WHEN** Editor задаёт собственную высоту строки Android и меняет Web
- **THEN** Android сохраняет свою высоту, iOS наследует Web; после снятия собственного значения Android тоже наследует Web

#### Scenario: T702 — вес Bold iOS
- **WHEN** Editor задаёт собственный вес Bold iOS и меняет основной вес Bold
- **THEN** iOS сохраняет своё значение, основной вес и наследующие платформы обновляются, Regular и Medium не меняются

### Requirement: Валидация типографики
Набор MUST проверять положительность размера и высоты строки и диапазон трекинга от -0.2em до 1em, сохраняя исходные данные при ошибке и принимая допустимые границы.

#### Scenario: T703 — неверный размер и высота строки
- **WHEN** Editor вводит отрицательное, нулевое или нечисловое значение Size либо Line Height
- **THEN** значение не сохраняется, значения и ревизии API не меняются; корректный ввод после ошибки можно сохранить

#### Scenario: T704 — границы трекинга
- **WHEN** Editor вводит трекинг вне диапазона, затем граничные -0.2em и 1em
- **THEN** неверный ввод не изменяет данные, обе границы сохраняются и отображаются после повторного открытия
