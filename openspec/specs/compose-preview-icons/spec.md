# compose-preview-icons Specification

## Purpose
Передача иконок из конфигурации компонента в Compose-превью по имени с ограничениями редактирования.
## Requirements
### Requirement: Свойство иконки входит в модель конфигурации

Клиент SHALL сохранять в модели конфигурации Compose-компонента свойства типа `icon` со строковым значением (например,
`disclosure.down.fill.16`) и MUST NOT отбрасывать их при загрузке.

#### Scenario: Конфигурация с иконкой

- **WHEN** клиент загружает конфигурацию `AccordionItem` со свойствами `closedIcon` и `openedIcon`
- **THEN** обе иконки MUST присутствовать в модели со своими значениями.

### Requirement: Иконка передаётся в payload по имени

Клиент SHALL передавать значение свойства Compose-компонента типа `icon` в payload как `literal` с исходной строкой
(`disclosure.down.fill.16`). Клиент MUST NOT передавать это значение как `tokenRef`. Свойство без значения MUST NOT попадать
в payload.

#### Scenario: У свойства иконки есть значение

- **WHEN** у свойства `closedIcon` выбранного стиля значение `disclosure.down.fill.16`
- **THEN** payload MUST содержать для `closedIcon` источник `{ "type": "literal", "value": "disclosure.down.fill.16" }`.

#### Scenario: У свойства иконки нет значения

- **WHEN** у свойства иконки нет значения
- **THEN** payload MUST NOT содержать это свойство, а превью MUST рисоваться без иконки.

#### Scenario: Свойство иконки во вложенном стиле

- **WHEN** иконка задана у стиля, на который ссылается свойство `styleRef`
- **THEN** вложенный стиль в `styles` MUST содержать иконку тем же литералом.

### Requirement: Значение иконки в редакторе только для чтения

Панель свойств SHALL показывать значение иконки как выбранную иконку каталога (изображение и каноническое имя) и MUST позволять выбрать другую иконку из каталога. Выбранное значение MUST сохраняться строкой старого формата (`disclosure.down.fill.16`). Если каталог не загружен или значение отсутствует в нём, панель MUST показывать значение строкой и MUST NOT скрывать его.

#### Scenario: Панель свойств компонента с иконкой

- **WHEN** пользователь открывает `AccordionItem`
- **THEN** `closedIcon` и `openedIcon` MUST показываться выбранными иконками каталога с возможностью выбрать другую.

#### Scenario: Сохранение выбора

- **WHEN** пользователь выбирает иконку `DisclosureUpFill` размера `16`
- **THEN** сохранённое значение MUST быть строкой `disclosure.up.fill.16`.

#### Scenario: Каталог не загружен

- **WHEN** в окружении нет каталога иконок
- **THEN** панель MUST показать значение строкой, как до выбора из каталога.

### Requirement: Иконка из конфигурации достигает превью

Плагин SHALL рисовать иконку, найденную по имени из payload. Иконка с неизвестным плагину именем MUST NOT останавливать
превью.

#### Scenario: Стрелка аккордеона

- **WHEN** у стиля `AccordionItem` заданы `closedIcon` и `openedIcon`, а плагин знает эти имена
- **THEN** превью MUST показывать стрелку раскрытия.

#### Scenario: Плагин не знает имя иконки

- **WHEN** имя иконки отсутствует в реестре плагина
- **THEN** превью MUST отрисоваться без иконки, а результат MUST содержать предупреждение `unknown_icon`.

### Requirement: Иконки превью передаются SVG-ресурсами

Клиент SHALL добавлять в `assets` payload превью Compose для каждой иконки каталога, выбранной в свойствах компонента (включая вложенные стили),
ресурс `{id: "icon:<значение>", type: "SVG", url}`, где `<значение>` — значение свойства в старом формате, а `url` — абсолютный адрес
SVG-файла этой иконки и размера в каталоге. Значение свойства MUST оставаться `literal`-строкой.

#### Scenario: Иконка из каталога

- **WHEN** у компонента выбрана иконка `AppsOutlineBold` размера `16` (значение `apps.outline-bold.16`)
- **THEN** payload MUST содержать ресурс `icon:apps.outline-bold.16` с адресом `<assetsBaseUrl>/16/AppsOutlineBold.svg`.

#### Scenario: Значение без начертания

- **WHEN** значение иконки `close.24` разрешается каталогом как `CloseOutline`
- **THEN** ресурс MUST иметь идентификатор `icon:close.24` и адрес файла `CloseOutline`.

#### Scenario: Иконки нет в каталоге или каталог не загружен

- **WHEN** значение иконки не разрешается по каталогу
- **THEN** ресурс MUST NOT добавляться, а превью MUST показать иконку по умолчанию с предупреждением `unknown_icon`.
