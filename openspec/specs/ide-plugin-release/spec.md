# ide-plugin-release Specification

## Purpose

Определяет выпуск плагина Android Studio / IntelliJ IDEA через GitHub Release по версионному тегу: сборку установочного архива, проверку контрольной суммы, защиту существующего выпуска и инструкции установки.

## Requirements

### Requirement: Релиз плагина в GitHub Release

Репозиторий SHALL содержать workflow публикации плагина IDE, который по тегу `idea-plugin-v<MAJOR>.<MINOR>.<PATCH>` собирает плагин `:plugins:android-studio` и создаёт GitHub Release с архивом плагина и файлом `SHA256SUMS`.

#### Scenario: Выпуск по тегу

- **WHEN** отправлен тег `idea-plugin-v1.2.3` либо вручную выбран существующий тег такого формата
- **THEN** выпуск MUST содержать `dsbuilder-ide-plugin-1.2.3.zip` и `SHA256SUMS`
- **THEN** SHA-256 архива в `SHA256SUMS` MUST совпадать с контрольной суммой файла

#### Scenario: Версия берётся из тега

- **WHEN** workflow собирает плагин по тегу `idea-plugin-v1.2.3`
- **THEN** версия в `plugin.xml` собранного архива MUST быть `1.2.3`

#### Scenario: Некорректный тег

- **WHEN** тег не соответствует формату `idea-plugin-v<semver>` либо workflow запущен не на самом теге
- **THEN** workflow MUST завершиться ошибкой до сборки и MUST NOT создавать выпуск

#### Scenario: Повторный запуск для того же тега

- **WHEN** выпуск для тега уже существует
- **THEN** workflow MUST завершиться ошибкой с пояснением, что выпуск уже существует
- **THEN** workflow MUST NOT изменять выпуск, перезаписывать или удалять его архив и `SHA256SUMS`
- **THEN** конкурентные запуски для одного тега MUST выполняться последовательно и повторно проверять существование выпуска перед публикацией

### Requirement: Описание установки

Описание выпуска и README плагина SHALL содержать установку из архива («Install Plugin from Disk»), поддерживаемые версии IDE (`sinceBuild`/`untilBuild`) и контрольную сумму.

#### Scenario: Пользователь устанавливает плагин

- **WHEN** пользователь скачивает архив и проверяет сумму по инструкции
- **THEN** он может установить плагин в поддерживаемую IDE без сборки из исходников
