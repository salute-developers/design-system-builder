## Requirements
### Requirement: Страница каталога иконок

Клиент SHALL предоставлять страницу `/projects/:projectId/icons`, доступную авторизованному участнику проекта, и ссылку на неё из навигации проекта. Страница MUST загружать каталог из `GET /api/projects/{projectId}/design-systems/catalog/icons` и показывать иконки сеткой карточек: изображение иконки выбранного размера и каноническое имя. Страница MUST показывать версию пакета-источника, дату загрузки и число иконок.

#### Scenario: Открытие страницы

- **WHEN** участник проекта открывает страницу иконок
- **THEN** страница MUST показать в раскладке остальных разделов редактора три области: категории слева, фильтры и сетку иконок по центру, сведения справа (об источнике каталога, а для выбранной иконки — её значение, начертание, размеры, синонимы и действия копирования)
- **AND** версия пакета-источника и общее число иконок MUST быть видны без выбора иконки.

#### Scenario: Каталог ещё не загружен

- **WHEN** бэкенд вернул пустой каталог
- **THEN** страница MUST показать пояснение, что каталог загружается командой `dsbuilder icons publish`, и MUST NOT показывать пустую сетку без объяснения.

#### Scenario: Ошибка загрузки

- **WHEN** запрос каталога завершился ошибкой
- **THEN** страница MUST показать сообщение об ошибке с действием «Повторить».

#### Scenario: Загрузка не сбрасывает рамку раздела

- **WHEN** пользователь переходит в раздел иконок из другого раздела редактора
- **THEN** рейл редактора и левая панель MUST оставаться на месте на время загрузки каталога (скелетоны панелей, как в других разделах), а не заменяться отдельным экраном загрузки.

### Requirement: Поиск и фильтры

Страница SHALL предоставлять поле поиска по имени и синонимам (без учёта регистра, по подстроке; поиск `добавить` MUST находить иконку с таким синонимом), список категорий с числом иконок (`Все` и категории каталога) для фильтра, переключатель начертания (`Все`, `Outline`, `Outline Bold`, `Fill`) и переключатель размера (`16`, `24`, `36`, по умолчанию `24`). Фильтрация MUST выполняться на клиенте по уже загруженному каталогу. Иконка, у которой нет выбранного размера, MUST NOT показываться в сетке этого размера. Страница MUST показывать число найденных иконок.

#### Scenario: Поиск по подстроке

- **WHEN** пользователь вводит `arrow`
- **THEN** сетка MUST показать иконки, в имени которых есть `arrow` в любом регистре, и число найденных.

#### Scenario: Поиск по русскому синониму

- **WHEN** пользователь вводит `добавить`
- **THEN** сетка MUST показать иконки, у которых этот синоним есть в списке, например `AddOutline`.

#### Scenario: Фильтр по категории

- **WHEN** пользователь выбирает категорию `Actions & Feedback`
- **THEN** сетка MUST показать только иконки этой категории, а число рядом с каждой категорией MUST соответствовать каталогу.

#### Scenario: Иконки без категории

- **WHEN** в каталоге есть иконки без категории
- **THEN** они MUST быть доступны в разделе `Все` и MUST NOT создавать пустую категорию.

#### Scenario: Фильтр по начертанию

- **WHEN** выбран `Fill`
- **THEN** сетка MUST показать только иконки с начертанием `fill`.

#### Scenario: Размер, которого нет у иконки

- **WHEN** выбран размер `36`, а у иконки есть только `16` и `24`
- **THEN** иконка MUST NOT появиться в сетке.

#### Scenario: Ничего не найдено

- **WHEN** запросу не соответствует ни одна иконка
- **THEN** страница MUST показать сообщение «Ничего не найдено» и действие сброса фильтров.

### Requirement: Иконки рисуются из SVG билдера

Клиент SHALL рисовать иконку из SVG по адресу `<assetsBaseUrl>/<size>/<name>.svg` из ответа каталога и MUST NOT зависеть от установленных в клиенте пакетов иконок. Иконка MUST наследовать цвет текста: клиент MUST рисовать её как маску (`mask-image`) или встроенным SVG с `currentColor`. Если файл не загрузился, карточка MUST показать нейтральную заглушку, а страница MUST продолжать работать.

#### Scenario: Иконка загружается

- **WHEN** каталог содержит `AddOutline` с размером `24`
- **THEN** карточка MUST показать иконку из SVG по адресу `<assetsBaseUrl>/24/AddOutline.svg` цветом текста.

#### Scenario: Файл недоступен

- **WHEN** запрос SVG завершился ошибкой
- **THEN** карточка MUST показать заглушку, остальные карточки MUST отображаться как обычно.

### Requirement: Копирование имени

Клик по карточке SHALL копировать каноническое имя иконки в буфер обмена и показывать подтверждение «Скопировано» не менее одной секунды. Если запись в буфер недоступна, страница MUST показать имя выделенным текстом для ручного копирования.

#### Scenario: Копирование

- **WHEN** пользователь кликает по карточке `AddOutline`
- **THEN** в буфер MUST попасть строка `AddOutline`, а карточка MUST показать подтверждение.

#### Scenario: Буфер недоступен

- **WHEN** запись в буфер обмена отклонена браузером
- **THEN** страница MUST показать имя выделенным текстом.

### Requirement: Большой каталог не замедляет страницу

Страница SHALL отрисовывать только видимую часть сетки (виртуализация или постраничная подгрузка), потому что каталог содержит порядка тысячи иконок. Изображения MUST запрашиваться только для отрисованных карточек.

#### Scenario: Первая отрисовка

- **WHEN** каталог содержит больше 1000 иконок
- **THEN** в DOM MUST находиться только карточки видимой части сетки с запасом, а запросов SVG MUST быть не больше, чем отрисованных карточек.

### Requirement: Пикер иконки в панели свойств

Для свойства типа `icon` панель свойств компонента SHALL показывать поле выбора в стиле остальных полей-пикеров (миниатюра иконки, ограниченная высотой строки, и имя без подписи над полем) и открывать контекстное окно под полем, а не модальное окно, с теми же поиском и фильтрами категории, начертания и размера, что страница каталога. При выборе иконки клиент MUST сохранять значение строкой старого формата (`<legacyKey>.<size>`) через существующее автосохранение. Пикер MUST предлагать только иконки и размеры каталога. Выбранная иконка MUST иметь действие «Очистить».

#### Scenario: Выбор иконки

- **WHEN** пользователь открывает пикер для `closedIcon` и выбирает `DisclosureDownFill` размера `16`
- **THEN** клиент MUST записать значение `disclosure.down.fill.16` и показать выбранную иконку.

#### Scenario: Значения нет в каталоге

- **WHEN** сохранённое значение отсутствует в каталоге
- **THEN** панель MUST показать значение строкой с пометкой «нет в каталоге» и позволить выбрать иконку из каталога.

#### Scenario: Ошибка unknown_icon

- **WHEN** бэкенд отклонил запись кодом `unknown_icon`
- **THEN** клиент MUST вернуть прежнее значение и показать сообщение, что иконка не найдена в каталоге.

#### Scenario: Очистка

- **WHEN** пользователь нажимает крестик внутри поля выбора (без текстовой подписи)
- **THEN** значение MUST быть удалено, а превью MUST рисоваться без иконки.
