## Why

Плагин работает только в Android Studio, и значения токенов имеют смысл для него только на платформе `android`. Экран выбора платформы (ANDROID / WEB / IOS) — лишний шаг: пользователь всегда выбирает первый пункт, а WEB и IOS показывают значения, которые в этой среде не нужны.

## What Changes

- Удаляется шаг `PickPlatform` из навигации: после выбора tenant сразу показывается список токенов.
- Платформа зашита как `android` (`TOKENS_PLATFORM` в `MainScreen.kt`); из `Step.ShowTokens` и хлебных крошек она убирается.
- Действие «Копировать код» показывается всегда, а не только для платформы Android.
- **BREAKING (поведение):** из плагина пропадает возможность посмотреть токены `web`/`ios`.
- Слой данных не меняется: `TokenPlatform`, парсер значений и `GetDesignSystemTokensUseCase` по-прежнему принимают платформу. Их чистка — отдельная задача при необходимости.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `ide-plugin-token-browser`: плагин работает только с платформой `android`; убраны выбор платформы, сценарии `web`/`ios`, платформа в крошках и в сохраняемой навигации; действие «Копировать код» не зависит от платформы; добавлено требование об отсутствии экрана выбора платформы.

## Impact

- `frontend-kt/plugins/android-studio`: `ui/MainScreen.kt`. Тесты слоя данных не затронуты.
- `backend-kt` и `js` не затрагиваются; REST API по-прежнему получает `platform=android`.
