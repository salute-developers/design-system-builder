## ADDED Requirements

### Requirement: Запуск в Pixso

Плагин SHALL собираться для Pixso из тех же исходников окна, что и для Figma. Сборка Pixso MUST содержать манифест с `name`, `id`, `main`, `ui` и `editorType: ["pixso"]`, основной поток с вызовами `pixso.*` и окно плагина.

#### Scenario: Открытие плагина

- **WHEN** пользователь запускает плагин в Pixso
- **THEN** плагин MUST открыть окно размером 400×600
- **THEN** окно MUST прочитать сохранённую сессию через `pixso.clientStorage`

#### Scenario: Сборка Figma не меняется

- **WHEN** плагин собирается для Figma
- **THEN** манифест и основной поток MUST использовать только `figma.*`
- **THEN** поведение плагина в Figma MUST остаться прежним

### Requirement: Открытие браузера в Pixso

Плагин SHALL открывать адрес подтверждения входа в браузере и в редакторе без `openExternal`. Требование действует для десктопного Pixso, веб-версия не поддерживается. Если API редактора предоставляет `openExternal`, основной поток MUST использовать его. Иначе он MUST передать адрес окну, а окно MUST открыть его через `window.open`. Окно MUST открывать только адреса `http` и `https`.

#### Scenario: Редактор без openExternal

- **WHEN** окно просит открыть адрес, а в API редактора нет `openExternal`
- **THEN** основной поток MUST отправить окну сообщение с адресом
- **THEN** окно MUST вызвать `window.open` с этим адресом

#### Scenario: Адрес с другой схемой

- **WHEN** окно получает адрес, схема которого не `http` и не `https`
- **THEN** окно MUST NOT вызывать `window.open`

#### Scenario: Редактор с openExternal

- **WHEN** окно просит открыть адрес, а API редактора предоставляет `openExternal`
- **THEN** основной поток MUST вызвать `openExternal` и MUST NOT отправлять адрес окну

### Requirement: Вход и токены в Pixso

Плагин в Pixso SHALL работать по требованиям `figma-plugin-authentication`, `figma-plugin-token-browser` и `figma-plugin-shared-core` с четырьмя отличиями: браузер открывается по требованию «Открытие браузера в Pixso», хранилищем служит `pixso.clientStorage`, тема редактора не отслеживается и действуют значения по умолчанию из `styles.css`, а манифест не содержит `networkAccess`: адрес gateway задаётся только сборкой. Окно в сборке Pixso MUST быть тем же файлом, что и в сборке Figma, поэтому все запросы к gateway выполняются общими Kotlin-модулями.

#### Scenario: Вход и просмотр токенов

- **WHEN** пользователь подтверждает вход в браузере
- **THEN** плагин MUST показать выбор контекста и токены выбранной темы

#### Scenario: Общая интеграция с бэкендом

- **WHEN** собирается плагин для Pixso
- **THEN** `ui.html` сборки Pixso MUST совпадать с `ui.html` сборки Figma
- **THEN** сборка MUST завершиться ошибкой, если основной поток Pixso обращается к сети или использует `figma`

#### Scenario: Сессия после перезапуска

- **WHEN** пользователь повторно открывает плагин на том же компьютере
- **THEN** плагин MUST восстановить сессию из `pixso.clientStorage`

### Requirement: Локальный запуск в отладчике Pixso

Плагин SHALL иметь команду, которая отдаёт готовую сборку Pixso отладчику редактора через WebSocket `ws://localhost:5201/plugin`. Окно MUST загружаться как готовый HTML, чтобы его origin был `null`, который разрешает gateway.

#### Scenario: Подключение отладчика

- **WHEN** отладчик Pixso подключается к серверу
- **THEN** сервер MUST отправить сообщения `manifest`, `main` и `ui` в формате `{ name, content }`

#### Scenario: Нет сборки

- **WHEN** команда запущена до сборки Pixso
- **THEN** она MUST завершиться с понятной ошибкой и кодом, отличным от нуля

### Requirement: Экспорт в Pixso

Плагин в Pixso SHALL экспортировать тему по требованиям `figma-token-export` тем же планом общего модуля `:plugins:figma-core`. Окно MUST называть редактор: действие «Экспортировать в Pixso», а тексты отчёта MUST называть Pixso вместо Figma. Отличия Pixso:

- значение режима со ссылкой на палитру и прозрачностью MUST записываться цветом RGBA, вычисленным по значениям плана, а отчёт MUST содержать одну оговорку с числом таких значений;
- каждый градиент MUST описываться парой стилей заливки `Light/<имя>` и `Dark/<имя>` со значениями своего режима без переменных стопов, а отчёт MUST содержать одну оговорку с числом таких градиентов; цвет тени MUST привязываться к переменной, как в Figma;
- если у текстового стиля нет привязки к переменным, стиль MUST создаваться со значениями из плана без привязки, а отчёт MUST содержать одну оговорку;
- совет про Figma Font Installer MUST NOT показываться;
- ключи созданных объектов MUST храниться в данных документа по `id` объекта, потому что Pixso не сохраняет данные плагина у переменных, коллекций и стилей;
- отказ Pixso создать коллекцию MUST останавливать экспорт с причиной, называющей коллекцию и лимит тарифа, а коллекция MUST NOT считаться созданной.

#### Scenario: Ссылка с прозрачностью в Pixso

- **WHEN** значение режима Dark ссылается на `Neutral/Gray/950` с прозрачностью 16, а значение ступени — непрозрачный цвет
- **THEN** значение переменной темы в режиме Dark MUST быть этим цветом с альфой 0,16
- **THEN** значение режима Light без прозрачности MUST остаться ссылкой на `Neutral/Gray/950`

#### Scenario: Градиент в Pixso

- **WHEN** у токена градиента совместимые слои в режимах Light и Dark
- **THEN** план MUST содержать стили `Light/<имя>` и `Dark/<имя>` и MUST NOT содержать переменных `GradientStops/<имя>/…`
- **THEN** стиль `Dark/<имя>` MUST содержать стопы режима Dark

#### Scenario: Повторный экспорт после перезагрузки

- **WHEN** пользователь экспортировал тему в Pixso, закрыл и снова открыл файл и повторил экспорт
- **THEN** экспорт MUST найти созданные коллекции, переменные и стили и обновить их без дубликатов

#### Scenario: Лимит коллекций

- **WHEN** Pixso отказывает в создании коллекции `01. Theme`
- **THEN** отчёт MUST содержать причину с именем коллекции и словами о лимите тарифа
- **THEN** число созданных коллекций MUST NOT включать `01. Theme`

#### Scenario: Текстовый стиль без привязки

- **WHEN** экспорт создаёт текстовый стиль `Header/H1 B` в Pixso без привязки к переменным
- **THEN** стиль MUST получить шрифт, размер, высоту строки и интервал из плана
- **THEN** отчёт MUST содержать одну оговорку «Текстовые стили» с числом таких стилей

#### Scenario: Сборка Figma не меняется

- **WHEN** экспорт выполняется в Figma
- **THEN** ссылки с прозрачностью, переменные и привязки стопов и привязки текстовых стилей MUST записываться, как требует `figma-token-export`
- **THEN** действие MUST называться «Экспортировать в Figma»
