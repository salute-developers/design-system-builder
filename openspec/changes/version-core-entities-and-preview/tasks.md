- [ ] 3.1 Реализовать общий серверный CoreContextResolver для черновика и опубликованной границы с согласованным набором релизов по платформам.

- [ ] 3.4 Реализовать CompatibilityChecker по сохранённым invariant/variation/combination активных компонентов выбранной границы, состояниям, токенам и вложенным ссылкам с разделением предупреждений и блокирующих проблем; исключить собственные настройки скрытых компонентов из блокировки и counts, проверять активные ссылки на скрытую цель, возвращать настройки в проверку после восстановления связи.

Импорт Core сам не публикует ДС, не меняет draftRevision/предметный журнал и не запускает публикацию пакета; пустой журнал блокирует отдельную явную публикацию и после смены Core.

- [ ] 3.8 Перевести обычное создание/изменение значений на тип и ограничения текущего Core, сохранив системные состояния, права и revision; согласовать проверку/запись с импортом и разрешить исправление отдельного назначения при остальных конфликтах ДС.
