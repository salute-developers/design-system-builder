## ADDED Requirements

### Requirement: Связь с существующим реестром preview

Сервер MUST связывать существующие buildId/platform/libraryVersion/metaSha256 с Core-релизом без второго реестра сборок. Мета архива MUST совпадать с релизом; сборка другого релиза MUST NOT использоваться как замена.

#### Scenario: Совместимая сборка

- **WHEN** версия библиотеки и SHA-256 меты совпадают с A
- **THEN** сборка MUST зарегистрироваться для A

#### Scenario: Другой хеш

- **WHEN** при тех же координатах архив содержит иную мету
- **THEN** операция MUST быть отклонена без замены Core или закреплённой сборки

### Requirement: Фиксация и позднее поступление preview

Публикация MUST фиксировать точный buildId совместимой доступной сборки либо ожидающий слот закреплённого Core. Первая поздняя совместимая сборка MUST заполнять пустой слот однократно; последующие MUST NOT менять preview опубликованной ДС. Черновик MUST выбирать последнюю зарегистрированную сборку своего Core.

#### Scenario: После нового Core

- **WHEN** V1 закрепила A и buildA, черновик перешёл на B
- **THEN** V1 MUST использовать buildA; черновик MUST NOT подставлять его вместо отсутствующего buildB

#### Scenario: Поздний preview

- **WHEN** V1 опубликована без сборки A, затем пришли A1 и A2
- **THEN** пустой слот MUST закрепить A1 атомарно; A2 MUST NOT заменить A1 у V1

#### Scenario: Очистка

- **WHEN** сборка перестала быть глобально активной, но закреплена у V1
- **THEN** очистка MUST сохранить её объекты и проверенную мету

### Requirement: Системное разрешение и кеш preview

Адрес preview MUST разрешаться по DS/version/platform и возвращать buildId/Core/хеш меты. Обязательный coreReleaseId во входе MUST NOT требоваться. Кеш и iframe MUST учитывать выбранный контекст, а локальный прямой URL MUST оставаться явно обозначенным режимом разработки.

#### Scenario: Смена версии

- **WHEN** пользователь переключает V1/A на V2/B
- **THEN** клиент MUST получить соответствующую сборку, сбросить прежний iframe и игнорировать старый ответ

#### Scenario: Прямой адрес

- **WHEN** задан локальный VITE URL
- **THEN** UI MUST обозначить режим разработки без утверждения соответствия закреплённому Core
