## ADDED Requirements

### Requirement: Локальный setup регистрирует Core перед публикацией preview

Обычный локальный setup в Bash и PowerShell MUST регистрировать Core для Web и Compose под
локальным системным администратором до публикации соответствующего плагина через учётку publisher.
Публикация и регистрация Core из ZIP MUST использовать одни и те же координаты, канал и байты меты.

#### Scenario: Первый запуск с комплектными ZIP

- **WHEN** setup запущен на чистом контуре с комплектными ZIP
- **THEN** оба Core-релиза MUST быть доступны в канале `dev`, а оба preview MUST публиковаться в локальный MinIO
- **AND** setup MUST NOT создавать демонстрационные дизайн-системы и темы без явного пакета компонентов

#### Scenario: ZIP поступает из файла или по URL

- **WHEN** при обычном запуске мета берётся из ZIP, выбранного для публикации
- **THEN** регистрация Core и публикация preview MUST читать одну локальную копию этого ZIP
