## ADDED Requirements

### Requirement: Core-контекст экспорта

Fetch/export MUST использовать Core выбранной границы и сохранять его происхождение в локальных метаданных без изменения формата конфигурации для генератора. Сервер MUST проверять совместимость конфигурации относительно Core выбранной версии или черновика при получении нового экспорта.

#### Scenario: Экспорт V1

- **WHEN** импортирован B, но CLI получает V1 на A
- **THEN** конфигурация и метаданные MUST соответствовать A

#### Scenario: Отказ в получении нового экспорта

- **WHEN** CLI запрашивает новый экспорт и сервер возвращает CORE_COMPATIBILITY_CONFLICT
- **THEN** CLI MUST показать причину и завершить операцию с ошибкой без запуска генератора с результатом этого запроса и без незаметной подстановки ранее сохранённого снимка

### Requirement: Независимая генерация из сохранённого снимка

CLI MUST разрешать локальную генерацию из выбранного сохранённого снимка ДС без обязательного обращения к серверу, проверки актуальности серверного контекста или совпадения Core снимка с локальными исходниками и зависимостями. Метаданные Core MUST сохранять происхождение снимка и MUST NOT служить требованием обновить его перед генерацией. CLI MUST NOT автоматически обновлять снимок из-за изменения серверного состояния или локальной версии Core. Совместимость с локальными исходниками и зависимостями MUST проверяться локальной сборкой и тестами, а не выводиться из равенства версий Core.

#### Scenario: Серверный черновик изменился

- **WHEN** после сохранения снимка изменились серверный черновик, его отпечаток или Core, в том числе появились блокирующие конфликты
- **THEN** CLI MUST разрешать генерацию из выбранного сохранённого снимка без требования обновить данные или проверить актуальный серверный контекст

#### Scenario: Сервер недоступен

- **WHEN** выбранный снимок и необходимые локальные средства генерации доступны, а сервер недоступен
- **THEN** CLI MUST разрешать генерацию без серверной проверки совместимости или актуальности

#### Scenario: Разработка следующего Core в том же репозитории

- **WHEN** снимок ДС относится к опубликованному Core A, а локальные исходники или зависимости используют ещё не выпущенный Core B
- **THEN** CLI MUST разрешать генерацию из снимка A без требования совпадения версий или публикации B; совместимость результата с B MUST проверяться локальной сборкой и тестами

#### Scenario: Новый экспорт отклонён после сохранения снимка

- **WHEN** сервер отклонил новый экспорт из-за конфликтов, а пользователь отдельно запускает генерацию из ранее сохранённого снимка A
- **THEN** CLI MUST разрешать эту локальную генерацию без повторной проверки конфликтного серверного состояния
