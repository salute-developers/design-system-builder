## MODIFIED Requirements

### Requirement: Клиент получает адрес web-плагина от бэкенда

Без прямого адреса в `VITE_WEB_PREVIEW_PLUGIN_URL` клиент SHALL запрашивать системный маршрут web-preview выбранной ДС и загружать web-плагин из `pluginUrl` ответа. Кеш MUST учитывать проект, ДС, границу, Core и buildId; неудачный запрос MUST NOT кешироваться. Адрес MUST соответствовать Core и закреплённой сборке выбранной версии ДС. Запрос MUST выполняться только когда в разделе есть web-компоненты.

#### Scenario: Опубликованный билд

- **WHEN** переменная не задана, а бэкенд отдаёт `pluginUrl` совместимого закреплённого web-билда
- **THEN** превью web-компонента MUST загружаться из этого адреса

#### Scenario: Смена компонента

- **WHEN** пользователь переключается между web-компонентами в одном подтверждённом Core-контексте
- **THEN** клиент MUST NOT запрашивать адрес повторно

#### Scenario: Другая версия ДС

- **WHEN** выбрана граница с другим Core или buildId
- **THEN** клиент MUST разрешить новый адрес и MUST NOT использовать прежний iframe как актуальный
