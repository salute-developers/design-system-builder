## ADDED Requirements

### Requirement: Релизный контекст системной модели

Системные чтения компонентов, свойств, состояний, параметров, зависимостей, оформления и экспорта MUST разрешать Core по существующему DS/version селектору. Отдельный обязательный coreReleaseId MUST NOT требоваться. Глобальные catalog-входы сохраняются для реестра и MUST NOT использоваться клиентом как модель опубликованной ДС.

#### Scenario: Исторические данные

- **WHEN** запрос содержит versionId V1 на A
- **THEN** все API-описания MUST соответствовать A независимо от текущего каталога

#### Scenario: Чужая версия

- **WHEN** versionId относится к другой ДС/проекту
- **THEN** сервер MUST вернуть 404 без раскрытия API и настроек

#### Scenario: Смена Core между чтениями

- **WHEN** клиент продолжает согласованное чтение с устаревшим отпечатком Core
- **THEN** сервер MUST потребовать повторное разрешение, не смешивая A и B
