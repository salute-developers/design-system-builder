## Why

Prod-сиды db-service описывают веб-компоненты, но в них остались сопоставления с нативными платформами (`xml`, `compose`, `ios`) из времён, когда один компонент был общим для всех платформ. Сидер их уже не записывает: нативные компоненты заводит `dsbuilder components import-api` по метам платформ. Но данные в сидах путают при чтении и правке. Вдобавок в веб-компонентах остались 22 свойства без web-параметра. В web они ни на что не ссылаются, а в базе выглядят как свойства веб-компонента: так, в dry run импорта веб-меты они попадают в `Absent from meta`.

## What Changes

- Из `params` свойств сидов удаляются `xml`, `compose` и `ios`, остаётся только `web`.
- Удаляются 22 свойства, у которых нет `web` в `params`, вместе с их значениями, инвариантами и сочетаниями во всех appearance: `Button` (6), `Checkbox` (7), `IconButton` (4), `Radiobox` (5).
- Из `adjust` значений удаляются поправки нативных платформ (66 записей в трёх компонентах).
- Тип сида сужается: в `params` и `adjust` допустима только платформа `web`, а у свойства обязателен `web`. Нативное сопоставление или свойство без web-параметра становится ошибкой проверки типов, а не тихо пропущенными данными.
- Фильтр `ownPlatform` в сидере становится не нужен и удаляется.
- Из снимка `component-seeds.json` в ds-service удаляются ссылки на те же 22 свойства (привязки к вариациям, значения, инварианты). Иначе на базе без этих свойств `GeneratedDesignSystemComponentInitializer` не найдёт метаданные и молча не создаст компоненты темы.

Не входит:
- базы стендов, потому что сидер только дописывает строки; удаление этих свойств на стендах — отдельная SQL-правка;
- зависимости компонентов `component_deps` с типом `compose`: это тип связи, а не платформа;
- нативные компоненты в базе.

## Capabilities

### New Capabilities
Нет.

### Modified Capabilities
- `component-seed-format`: сид компонента содержит только web-сопоставления, и у каждого свойства есть web-параметр.
- `design-system-model-api`: снимок компонентов ds-service не ссылается на свойства без web-параметра.

## Impact

- **js/db-service**:
  - `src/db/seeds/prod/component-seed.ts` — типы `PropertySeed`, `AdjustSeed` и фильтр платформы;
  - `components/*/properties.ts` всех 63 компонентов;
  - `values.ts` компонентов `Button`, `Checkbox`, `IconButton`, `Radiobox` и компонентов с нативными `adjust`;
  - `component-seed-writer.ts` — выгрузка пишет то же, что в базе: в web-компонентах только web, так что изменений не требуется, это проверяется.
- **Данные**: на чистой базе после сида у веб-компонентов 1505 свойств вместо 1527. Стенды не меняются.
- **backend-kt/ds-service**: снимок `feature-components/src/main/resources/component-seeds.json` и его тест `ComponentSeedsResourceTest` (хэш и проверка отсутствия удалённых свойств).
- **frontend-kt**: не затрагивается.
