## ADDED Requirements

### Requirement: Согласие и срок сессии

Клиент Keycloak `dsbuilder-figma-plugin` MUST требовать согласия пользователя, чтобы страница подтверждения device-кода называла приложение, которое просит доступ. Офлайн-сессия плагина MUST истекать после 30 дней без обновления и MUST NOT длиться больше 90 дней. Настройка SHALL быть одинаковой в локальном realm и в скрипте настройки стендов.

#### Scenario: Вход по присланной ссылке

- **WHEN** пользователь открывает ссылку подтверждения device-кода клиента `dsbuilder-figma-plugin`
- **THEN** Keycloak MUST показать экран согласия с названием «DS Builder для Figma» до выдачи токенов

#### Scenario: Сессия старше 90 дней

- **WHEN** refresh token плагина выдан больше 90 дней назад
- **THEN** обновление MUST завершиться `invalid_grant`, и плагин MUST показать экран входа
