## ADDED Requirements

### Requirement: Записи журнала можно откатить пакетом

`POST /api/ds/design-systems/{id}/changes/revert` SHALL принимать тело
`{ "changes": [{ "changeId", "expectedRevision" }] }` и откатывать записи активного черновика целиком одной
транзакцией в присланном порядке (от новой записи к старой) тем же откатом, что одиночный маршрут. Маршрут SHALL
требовать право `design-systems:write` и один `Idempotency-Key` на весь пакет; хэш повторяемости SHALL включать
все пары «изменение — редакция» в присланном порядке. `expectedRevision` берётся из одного снимка журнала и SHALL
сверяться с состоянием до пакета.

#### Scenario: Откатываются все записи пакета

- **WHEN** каждая запись пакета существует в активном черновике с ожидаемой редакцией
- **THEN** API MUST откатить все записи и вернуть `200` с `{ "ok": true }`
- **THEN** повтор с тем же ключом и телом MUST вернуть сохранённый ответ без повторного отката

#### Scenario: Откат записи пакета меняет другую запись того же пакета

- **WHEN** откат одной записи сам меняет редакцию следующей записи пакета (откат значения цветового токена
  пересчитывает тип семейства и создаёт ревизию определения) или снимает её отличие
- **THEN** API MUST откатить следующую запись по её текущей редакции в той же транзакции, а исчезнувшую из журнала
  запись MUST считать отменённой
- **THEN** API MUST NOT возвращать `DRAFT_CHANGE_STALE` из-за изменений самого пакета

#### Scenario: Запись пакета устарела или откат не удался

- **WHEN** редакция хотя бы одной записи до пакета не совпадает с ожидаемой, записи нет или откат записи отклонён
- **THEN** API MUST вернуть отказ первой такой записи с тем же кодом, что одиночный откат (`DRAFT_CHANGE_STALE`,
  `REVERT_DEPENDENCY_CONFLICT`, `404`, `JOURNAL_LIMIT_EXCEEDED`), у конфликтов — с позицией записи в
  `details.changeIndex`
- **THEN** ни одна запись пакета MUST NOT остаться откаченной

#### Scenario: Пакет некорректен

- **WHEN** список пуст, содержит больше 200 записей или повторяет `changeId`
- **THEN** API MUST вернуть `400` с кодом `REVERT_BATCH_EMPTY`, `REVERT_BATCH_TOO_LARGE` или
  `REVERT_BATCH_DUPLICATE_CHANGE` без обращения к данным
