## Why

Ревью PR #153 («Редактор компонентов: Раздел Стилизация») и ручная проверка нашли ошибки нового инспектора. Самая
серьёзная — инспектор неверно определяет, к какому источнику относится свойство: на web связи свойств с вариациями
приходят именами вариаций, а инспектор сравнивает их с ID вариации; на Compose связи до клиента не доходят вовсе. Из-за этого на
Compose появляются пары пустых и заполненных строк, и значение можно записать не в тот источник, а на web у стиля не
строятся пустые строки его свойств. Остальное — поведение пикеров, дубли стилей в «Variants», тексты и мелкая
вёрстка, а на сервере — пустая запись значения свойства после `PATCH`.

## What Changes

- **Источник свойства.** Связь свойства с вариацией узнаётся по имени или ID вариации. Связи свойств с вариациями
  (`property-variations`) загружаются и для Compose: бандл редактора и клиент больше не ограничивают их web. Если у
  компонента связей нет совсем, свойство без вариаций не считается инвариантом: пустые строки не строятся,
  показываются только заданные значения.
- **Дубли стилей.** Значения пересечений вариаций (с `targets` в выгрузке) больше не становятся отдельными стилями:
  в «Variants» у `Shape` один `pilled`.
- **Пикеры.** Открыт только один пикер цвета: открытие другого закрывает предыдущий. Клик по холсту превью (он
  внутри `iframe`) закрывает открытые пикеры и меню инспектора. `Escape` в списке типографики закрывает список и не
  открывает его снова при возврате фокуса.
- **Состояние цветового свойства.** Добавленное состояние сохраняется и остаётся после перечитывания компонента.
- **Тексты и вёрстка.** «Токены сабтем» → «Токены подтем»; индикатор сохранения убран из панели окружения превью (он
  есть в тулбаре); у списка типографики место под полосу прокрутки; галочка в меню состояний — глиф `check`.
- **`TyGlyph`** переезжает из раздела типографики в общие компоненты клиента.
- **`ds-service`.** `PATCH` вариационного и инвариантного значения свойства, после которого не остаётся ни токена,
  ни значения, отклоняется с `422 property_value_empty` (нарушение предметного правила, как остальные отказы редактора).

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `component-editor-workbench`: источник свойства и пустые строки, один пикер цвета, закрытие по клику по холсту,
  `Escape` типографики, сохранение состояния цвета, стили без пересечений, тексты панели и библиотеки.
- `component-editor-operations`: `PATCH` значения свойства не оставляет пустую запись.

## Impact

- **js, `apps/client`:**
  - `pages/components/features/ComponentInspector/inspectorModel.ts` — источник свойства;
  - `api/componentRepository.ts` — значения с `targets` не превращаются в стили;
  - `features/InspectorControls` — пикер цвета, типографика, меню состояний, библиотека токенов;
  - `hooks/useDismiss.ts`, `pages/colors/ui/ColorPickerPopover.tsx` — закрытие по клику в `iframe`;
  - `PreviewEnvironmentBar`, стили инспектора;
  - `TyGlyph` → `components/TyGlyph`, импорты по клиенту.
- **backend-kt, `ds-service`:** `ExposedComponentEditorBundleRepository` — `propertyVariations` для всех платформ;
  `VariationPropertyValueRoutes`, `InvariantPropertyValueRoutes` (или общая проверка
  команды изменения), OpenAPI, интеграционный тест.
- **frontend-kt:** без изменений.
