## Контекст

Корень `/` обслуживает `Main`, а `<Navigate to="/projects" />` — его дочерний index-маршрут. `Main` рендерит `<Outlet />`
только когда `sectionLoading` ложен. `sectionLoading` вычисляется в `useDesignSystem` как
`Boolean(selection && sectionState?.key !== sectionKey)`. `Main` передаёт `selection` всегда, а `sectionState`
заполняет только загрузчик раздела, который создаётся при открытой теме. Без темы флаг остаётся истинным навсегда.

## Цели / Вне целей

**Цели:**
- Корень и `/:designSystemProjectId` снова ведут на `/projects`.

**Вне целей:**
- Перестройка маршрутов `App.tsx` и удаление устаревшего маршрута `/:designSystemProjectId`.

## Решения

### Условие в хуке, а не в маршрутах

`sectionLoading` учитывает контекст темы: `Boolean(designSystemProjectId && selection && sectionState?.key !== sectionKey)`.
Загрузка раздела без открытой темы невозможна, поэтому флаг без неё не имеет смысла, и любой вызывающий код получает
правильное значение.

Альтернатива — вынести редирект с `/` из-под `Main` под `ProtectedRoute`. Она лечит только корень и оставляет ту же
ловушку для `/:designSystemProjectId` и будущих маршрутов внутри `Main`.

## Риски / Компромиссы

- [Где-то полагаются на `sectionLoading = true` без темы] → поиском таких мест нет: флаг читает только `Main`, и без
  темы он скрывал единственный дочерний контент — редирект.
