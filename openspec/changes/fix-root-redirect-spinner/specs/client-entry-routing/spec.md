## ADDED Requirements

### Requirement: Корень клиента ведёт на список проектов
Клиент MUST перенаправлять авторизованного пользователя с корня приложения (`/` относительно `BASE_URL`) на
`/projects`. Индикатор загрузки раздела редактора MUST NOT показываться, пока в адресе не открыта тема.

#### Scenario: Авторизованный пользователь открывает корень
- **WHEN** авторизованный пользователь открывает `/` клиента
- **THEN** клиент показывает список проектов по адресу `/projects`, а не бесконечный индикатор загрузки

#### Scenario: Тема не открыта
- **WHEN** `useDesignSystem` вызван без контекста темы, но с выбранным разделом
- **THEN** `sectionLoading` равен `false`, и данные темы не запрашиваются

#### Scenario: Тема открыта
- **WHEN** открыт раздел редактора темы и его данные ещё не загружены
- **THEN** клиент показывает индикатор загрузки раздела, как раньше
