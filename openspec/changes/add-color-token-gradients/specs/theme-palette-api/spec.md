## MODIFIED Requirements

### Requirement: Ссылка значения токена на палитру

`ds-service` SHALL считать ссылкой на палитру цветовое значение токена в одной из двух форм: строку
`[<type>.<shade>.<step>]` с необязательным суффиксом прозрачности `[<opacity>]` в `value` (элемент
массива или скаляр) либо `palette_id` на строку общей палитры со значением `null`, `[]` или
`[<opacity>]`. Ссылкой SHALL также считаться строка той же формы на месте цвета внутри градиента: цвет стопа
web-градиента, элемент `colors` или `background` слоя `ios` и `android`. Пара `(type, shade)` ссылки SHALL
обозначать слот растяжки в группе токена; значение SHALL разрешаться по палитре темы.

#### Scenario: Обе формы ссылки

- **WHEN** у одного токена значение `["[general.amber.300][0.56]"]`, а у другого — `palette_id` на `general.amber.300` и `value = ["0.56"]`
- **THEN** оба значения MUST считаться ссылкой на ступень `300` слота `general.amber` с прозрачностью `0.56`

#### Scenario: Ссылка в стопе градиента

- **WHEN** у токена web-значение `["linear-gradient(90deg, [general.amber.300][0.56] 0%, #FFFFFFFF 100%)"]` и
  значение `android` `[{ "kind": "linear", "colors": ["[general.amber.300][0.56]", "#FFFFFFFF"], … }]`
- **THEN** оба значения MUST содержать ссылку на ступень `300` слота `general.amber` с прозрачностью `0.56`

### Requirement: Связанные токены растяжки

`ds-service` SHALL возвращать связи токенов темы со слотом через
`GET /api/ds/tenants/{tenantId}/palette/links` с параметрами `type`, `shade`, необязательными `groupId` и
`step`. Связью SHALL считаться и ссылка в стопе градиента.

#### Scenario: Связи в группе

- **WHEN** запрос содержит `type=general&shade=green&groupId=<id группы Accent>`
- **THEN** ответ MUST содержать `PaletteLink { tokenId, tokenName, displayName, groupId, mode, step, opacity, platforms }` только для токенов этой группы, ссылающихся на слот, уникальные по паре `(tokenId, mode)`

#### Scenario: Связи по ступени во всех группах

- **WHEN** запрос не содержит `groupId`, но содержит `step=500`
- **THEN** ответ MUST содержать связи всех групп со ступенью `500` слота

#### Scenario: Связь через стоп градиента

- **WHEN** единственная ссылка токена типа `gradient` на слот `general.green` — стоп градиента в режиме `dark`
- **THEN** ответ MUST содержать связь токена с `mode: dark`, ступенью и прозрачностью стопа

### Requirement: Удаление растяжки из группы

Редактор SHALL убирать растяжку из группы через
`DELETE /api/ds/tenants/{tenantId}/palette/groups/{groupId}/ramps/{type}/{shade}` с телом
`{ strategy?, replacement?, editRevision }`. Удаление MUST NOT оставлять ссылки токенов группы на
убранный слот, включая ссылки в стопах градиентов, и MUST выполняться атомарно.

#### Scenario: Удаление с заменой

- **WHEN** тело содержит `{ "strategy": "replace", "replacement": { "type": "additional", "shade": "h190" } }`
- **THEN** каждая ссылка токенов группы на слот MUST стать ссылкой на ту же ступень `additional.h190` с прежней прозрачностью, слот замены MUST входить в группу, ответ MUST содержать число переназначенных связей

#### Scenario: Удаление с сохранением как Custom

- **WHEN** тело содержит `{ "strategy": "detach" }`
- **THEN** каждая ссылка токенов группы на слот MUST стать текущим вычисленным HEX с учётом прозрачности

#### Scenario: Ссылки в стопах градиента

- **WHEN** токен группы ссылается на убираемый слот в стопе web-градиента и в `colors` слоя `android`
- **THEN** при замене и при сохранении как Custom MUST переписываться ссылки внутри строки и внутри слоя, а
  остальные стопы, позиции, угол и центр MUST NOT измениться
- **THEN** переписанные значения MUST записываться предметными редакциями значений активного черновика, а
  журнал MUST показывать их отдельными записями изменений токенов, как переписанные ссылки цветов

#### Scenario: Отмена ссылки в стопе требует растяжку

- **WHEN** пользователь отменяет изменение значения, которое возвращает ссылку стопа на растяжку, ещё не
  восстановленную в группе
- **THEN** сервер MUST отклонить отмену предметной ошибкой без изменения токена, как для ссылки цвета

#### Scenario: Ошибки удаления

- **WHEN** у токенов группы есть ссылки на слот, а `strategy` не передан
- **THEN** `ds-service` MUST вернуть `409` с кодом `PALETTE_RAMP_LINKED`
- **WHEN** у замены нет используемой ступени
- **THEN** `ds-service` MUST вернуть `409` с кодом `PALETTE_STEP_MISSING`
- **WHEN** запись любой ссылки завершилась ошибкой
- **THEN** все изменения операции MUST быть откатаны

### Requirement: Цвета палитры темы для потребителей

`GET /api/ds/tenants/{tenantId}/token-values` SHALL всегда заменять ссылки на палитру в цветовых значениях на
HEX, вычисленный по палитре темы с учётом группы токена, отдавать у таких значений `paletteId = null` и
добавлять поле `paletteRef` с исходной ссылкой. Ссылки внутри градиента SHALL заменяться так же, а исходное
значение со ссылками SHALL отдаваться в поле `sourceValue`. Прозрачность SHALL записываться альфа-каналом
`#RRGGBBAA`, где `AA = round(opacity * 255)`. Параметра, возвращающего ссылки вместо цветов, SHALL NOT быть:
раскрытие по общей палитре даёт неверные цвета темы с изменённой палитрой. Редактор берёт ссылку из
`paletteRef`, а градиент со ссылками — из `sourceValue`.

#### Scenario: Потребитель без поддержки палитры темы

- **WHEN** потребитель, раскрывающий `paletteId` по общей палитре (например, `dsbuilder` до этого изменения), читает значения темы с изменённой палитрой
- **THEN** у вычисленных значений `paletteId` MUST быть `null`, а `value` — HEX по палитре темы, так что потребитель MUST получить цвета темы без доработок

#### Scenario: Значение по палитре темы

- **WHEN** в группе Accent слот `general.green` заменён на `additional.h190`, а токен группы Accent имеет значение `[general.green.500][0.8]`
- **THEN** `value` MUST быть `["#RRGGBBCC"]` по ступени `500` растяжки `additional.h190` копии шаблона темы, а `paletteRef` — `"[general.green.500][0.8]"`
- **THEN** у токена группы Neutral с той же ссылкой значение MUST браться из копии шаблона темы для `general.green.500`

#### Scenario: Градиент со ссылками

- **WHEN** web-значение токена — `["linear-gradient(90deg, [general.green.500][0.8] 0%, #FFFFFFFF 100%)"]`, а
  значение `ios` содержит ту же ссылку в `colors`
- **THEN** `value` MUST содержать градиент, в котором ссылка заменена на `#RRGGBBCC` по палитре темы, а
  `sourceValue` — исходное значение со ссылкой
- **THEN** поле `paletteRef` MUST NOT отдаваться

#### Scenario: Градиент в опубликованной версии

- **WHEN** значения читаются с `versionId` опубликованной версии, а ступень, на которую ссылается стоп, позже
  изменена в черновике
- **THEN** ссылка стопа MUST раскрываться по палитре на границе выбранной версии

#### Scenario: Ссылка на отсутствующую ступень

- **WHEN** ссылка указывает на слот или ступень, которых нет в копии шаблона темы
- **THEN** значение MUST вернуться без изменений и без полей `paletteRef` и `sourceValue`
