## ADDED Requirements

### Requirement: Скорость экспорта

Экспорт SHALL запрашивать значения цветов и градиентов только выбранной платформы и web, а значения `fontFamily` — всех платформ: ссылки на файлы шрифтов есть только у iOS и Android. Повторный экспорт SHALL записывать в документ значение режима переменной, её имя и области применения, только если они отличаются от записанных; значения цвета MUST сравниваться с допуском на точность хранения Figma. Каждое начертание шрифта SHALL загружаться один раз за экспорт. Отчёт SHALL показывать время загрузки данных с построением плана и время записи в документ.

#### Scenario: Повторный экспорт без изменений

- **WHEN** тема экспортирована и экспорт выполнен снова без изменений в DS Builder
- **THEN** экспорт MUST NOT вызывать запись значения ни для одной переменной

#### Scenario: Изменилось одно значение

- **WHEN** после экспорта в DS Builder изменён цвет одной ступени палитры и экспорт выполнен снова
- **THEN** запись значения MUST произойти только у этой переменной

#### Scenario: Время в отчёте

- **WHEN** экспорт завершён
- **THEN** отчёт MUST показать время загрузки данных и время записи в Figma в секундах
