## ADDED Requirements

### Requirement: Блок подтем свёрнут по умолчанию

Секция «Подтемы» инспектора цветового токена SHALL быть свёрнута по умолчанию: значения подтем меняются вслед за
режимами по связи, и раскрывать их нужно, только чтобы переопределить значение.

#### Scenario: Токен открыт впервые

- **WHEN** пользователь открывает цветовой токен, а секцию «Подтемы» ещё не раскрывали
- **THEN** инспектор MUST показать только заголовок «Подтемы» со стрелкой и действием «Сбросить подтемы», без строк
  OnDark, OnLight и Inverse
- **THEN** заголовок MUST быть кнопкой с `aria-expanded="false"`

#### Scenario: Пользователь раскрывает секцию

- **WHEN** пользователь нажимает заголовок «Подтемы»
- **THEN** инспектор MUST показать подтемы с их значениями и переключателями связи
- **THEN** состояние раскрытия MUST сохраняться при выборе другого токена и после перезагрузки страницы

#### Scenario: Подтема с ошибкой значения

- **WHEN** значение хотя бы одной подтемы не проходит проверку
- **THEN** заголовок «Подтемы» MUST показывать отметку ошибки, чтобы проблема не скрылась в свёрнутой секции
- **WHEN** сохранение отклонено из-за значения подтемы
- **THEN** секция MUST раскрыться, чтобы поле с ошибкой было видно

### Requirement: Связь подтемы хранится явно

Связь подтемы OnDark, OnLight или Inverse с режимами SHALL храниться на сервере признаком `detached` каждого
значения подтемы (`PUT /api/design-systems/{designSystemId}/tenants/{tenantId}/color-tokens/{tokenId}/values`,
чтение — `GET /api/design-systems/{designSystemId}/tenants/{tenantId}/token-values`). Подтема SHALL считаться
связанной, пока ни одно её значение не отмечено `detached`: совпадение значений с режимами на связь не влияет. Признак входит в версию и журнал черновика путём `/detached`, переносится копией темы и откатом; правка
значения другим маршрутом его не снимает.

#### Scenario: Подтема сида с отличающимися значениями

- **WHEN** у существующей подтемы нет признака `detached`, а её значения отличаются от унаследованных значений режимов
- **THEN** инспектор MUST показать подтему связанной
- **THEN** значения подтемы MUST NOT меняться при открытии токена
- **WHEN** пользователь правит Light или Dark
- **THEN** связанная подтема MUST получить унаследованное значение режима

#### Scenario: Новая тема из профиля и её копия

- **WHEN** пользователь создаёт тему из профиля или копирует тему, где подтемы не отвязывали
- **THEN** инспектор новой темы MUST показать подтемы связанными

#### Scenario: Новый токен

- **WHEN** пользователь создаёт цветовой токен
- **THEN** его подтемы MUST быть связаны: значения подтем MUST совпадать с унаследованными, `detached` MUST быть `false`

#### Scenario: Пользователь отвязывает подтему

- **WHEN** пользователь нажимает переключатель связи связанной подтемы
- **THEN** значения подтемы MUST остаться прежними, а её значения MUST сохраниться с `detached: true`
- **THEN** последующие правки Light и Dark MUST NOT менять значения подтемы

#### Scenario: Пользователь восстанавливает связь

- **WHEN** пользователь нажимает переключатель связи несвязанной подтемы или «Сбросить подтемы»
- **THEN** значения подтемы MUST сохраниться с `detached: false` и MUST стать унаследованными значениями режимов
