## ADDED Requirements

### Requirement: Настройки дизайн-системы управляют темами

Настройки дизайн-системы SHALL содержать раздел «Темы» со списком тем дизайн-системы, в котором пользователь
переименовывает, дублирует и удаляет темы. Отдельного экрана настроек одной темы SHALL NOT быть.

#### Scenario: Раздел «Темы» открыт

- **WHEN** пользователь с разрешением `tenants:read` открывает раздел «Темы» настроек дизайн-системы
- **THEN** клиент MUST показать все темы дизайн-системы с названием, профилем и цветовым превью
- **THEN** у каждой темы MUST быть ссылка, открывающая её в редакторе

#### Scenario: Тема переименована

- **WHEN** пользователь с разрешением `tenants:write` меняет название темы в списке и подтверждает его Enter или
  уходом с поля
- **THEN** клиент MUST нормализовать название по правилам `theme-lifecycle` и вызвать `PATCH /tenants/{id}` с `name`
- **THEN** при конфликте или пустом названии поле MUST показать текст ошибки и MUST сохранить прежнее название
- **THEN** после успеха клиент MUST обновить кэш тем, чтобы переключатель тем и обзор показали новое название
- **WHEN** пользователь нажимает Escape в поле названия
- **THEN** поле MUST вернуть прежнее название без запроса

#### Scenario: Тема продублирована из настроек

- **WHEN** пользователь с разрешением `tenants:write` выбирает «Дублировать» у темы
- **THEN** клиент MUST показать диалог с полем названия, заполненным «<название> копия»
- **THEN** после подтверждения клиент MUST вызвать `POST /tenants/{id}/duplicates` и показать копию в списке

#### Scenario: Тема удалена из настроек

- **WHEN** пользователь с разрешением `tenants:delete` выбирает «Удалить» у темы
- **THEN** клиент MUST потребовать ввести точное название темы и только после этого вызвать `DELETE /tenants/{id}`
- **THEN** если удалена тема, открытая в редакторе, клиент MUST перейти к другой теме дизайн-системы, а при её
  отсутствии — к обзору дизайн-системы

#### Scenario: Права ограничивают действия

- **WHEN** пользователь без `tenants:write` открывает раздел «Темы»
- **THEN** клиент MUST показать список только для чтения, без полей переименования и действия «Дублировать»
- **WHEN** пользователь без `tenants:delete` открывает раздел «Темы»
- **THEN** клиент MUST NOT показывать действие «Удалить»

#### Scenario: Открыта опубликованная версия

- **WHEN** настройки открыты из редактора с `versionId` опубликованной версии
- **THEN** раздел «Темы» MUST быть только для чтения

#### Scenario: Старый адрес настроек темы

- **WHEN** пользователь открывает `.../themes/{tenantId}/settings`
- **THEN** клиент MUST перенаправить его в раздел «Темы» настроек дизайн-системы и выделить тему `tenantId`
- **THEN** параметр `?section=delete` MUST открыть подтверждение удаления этой темы

### Requirement: Шестерёнка редактора открывает настройки дизайн-системы

Кнопка настроек в рейле редактора темы SHALL открывать настройки дизайн-системы внутри оболочки редактора.

#### Scenario: Настройки открыты из редактора

- **WHEN** пользователь нажимает шестерёнку в рейле редактора
- **THEN** клиент MUST показать настройки дизайн-системы в оболочке редактора с разделами «Основное», «Темы» и, при
  наличии прав, «Перенос» и «Опасная зона»
- **THEN** подсказка и доступное имя кнопки MUST быть «Настройки дизайн-системы»
- **THEN** раздел «Основное» MUST быть доступен для изменения только с разрешением `design-systems:write`, иначе
  только для чтения

#### Scenario: Возврат к теме

- **WHEN** пользователь открыл настройки из редактора и выбирает другой раздел рейла
- **THEN** клиент MUST открыть этот раздел текущей темы

### Requirement: Меню карточки темы ведёт к управлению темами

Меню карточки темы на обзоре дизайн-системы SHALL предлагать дублирование и SHALL вести переименование и удаление в
раздел «Темы» настроек дизайн-системы.

#### Scenario: Пункты меню карточки

- **WHEN** пользователь с разрешением `tenants:write` открывает меню карточки темы
- **THEN** меню MUST содержать «Переименовать» и «Дублировать», а при `tenants:delete` — «Удалить»
- **THEN** «Переименовать» MUST открывать раздел «Темы» с фокусом в поле названия этой темы
- **THEN** «Удалить» MUST открывать раздел «Темы» с подтверждением удаления этой темы

#### Scenario: Дублирование из карточки

- **WHEN** пользователь выбирает «Дублировать» в меню карточки
- **THEN** клиент MUST показать диалог с названием «<название> копия» и после подтверждения открыть копию в
  редакторе
