## ADDED Requirements

### Requirement: Переключатель тем в шапке редактора

Крошка «Тема» в шапке редактора SHALL открывать список тем дизайн-системы и SHALL переключать редактор на выбранную
тему без перехода на обзор дизайн-системы.

#### Scenario: Список тем открыт

- **WHEN** пользователь нажимает крошку с названием текущей темы
- **THEN** клиент MUST показать список всех тем дизайн-системы с названием и цветовым превью каждой
- **THEN** текущая тема MUST быть отмечена в списке
- **THEN** список MUST строиться из того же кэша `themes:${projectId}:${designSystemId}`, что и обзор
  дизайн-системы

#### Scenario: Тем много

- **WHEN** в дизайн-системе больше семи тем
- **THEN** список MUST содержать поле поиска по названию, которое получает фокус при открытии
- **THEN** список MUST прокручиваться внутри всплывающей панели, не увеличивая шапку

#### Scenario: Тема выбрана

- **WHEN** пользователь выбирает в списке другую тему
- **THEN** клиент MUST перейти на маршрут той же секции с `tenantId` выбранной темы
- **THEN** клиент MUST сохранить параметр `versionId`, если он был в адресе
- **THEN** на экранах цветов, размеров и типографики клиент MUST передать в адрес `tokenId` выбранного токена, чтобы в
  новой теме был выбран тот же токен
- **THEN** при переходе MUST выполняться требование `tenant-aware-theme-editor` о переключении тем: незавершённые
  сохранения прежней темы не теряются, устаревшие ответы игнорируются

#### Scenario: Управление с клавиатуры

- **WHEN** список открыт
- **THEN** стрелки MUST перемещать выделение по темам, Enter MUST выбирать тему, Escape MUST закрывать список и
  возвращать фокус на крошку

#### Scenario: В дизайн-системе одна тема

- **WHEN** в дизайн-системе только текущая тема
- **THEN** список MUST показать её и действие «Создать тему» пользователю с разрешением `tenants:write`

### Requirement: Экраны токенов открывают токен по адресу

Экраны цветов, размеров и типографики SHALL выбирать токен по параметру `tokenId` адреса, где `tokenId` —
идентификатор общего определения токена дизайн-системы.

#### Scenario: Адрес содержит существующий токен

- **WHEN** экран токенов открыт с `tokenId` определения, которое есть на этом экране
- **THEN** экран MUST выбрать этот токен, раскрыть его группу в дереве и прокрутить дерево к нему

#### Scenario: Адрес содержит неизвестный токен

- **WHEN** `tokenId` не принадлежит токенам экрана
- **THEN** экран MUST выбрать токен по обычным правилам и MUST NOT показывать ошибку

#### Scenario: Пользователь выбирает другой токен

- **WHEN** пользователь выбирает токен в дереве
- **THEN** экран MUST заменить `tokenId` в адресе без новой записи истории браузера
