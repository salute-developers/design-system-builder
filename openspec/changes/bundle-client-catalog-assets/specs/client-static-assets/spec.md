## ADDED Requirements

### Requirement: Картинки клиента учитывают подпуть публикации
Клиент DS Builder MUST загружать собственные картинки интерфейса (иконки боковой панели, заглушки пустых состояний,
картинку ошибки) по адресам внутри подпути, с которым собрано приложение (`BASE_URL`). Разметка клиента MUST NOT
ссылаться на собственные картинки путями от корня домена.

#### Scenario: Приложение опубликовано по подпути
- **WHEN** клиент собран с `BASE_URL=/dev/design-system-builder/client/` и открыт на стенде разработки
- **THEN** каждая картинка каталога запрашивается по адресу, начинающемуся с `/dev/design-system-builder/client/`,
  и сервер отдаёт её с типом картинки, а не HTML

#### Scenario: Приложение опубликовано из корня
- **WHEN** клиент собран с `BASE_URL=/` и открыт локально
- **THEN** картинки каталога загружаются так же, как раньше

### Requirement: Отсутствующая картинка обнаруживается при сборке
Каждая собственная картинка интерфейса клиента MUST подключаться так, чтобы отсутствие или переименование её файла
приводило к ошибке сборки клиента, а не к битой картинке в опубликованном приложении.

#### Scenario: Файл картинки удалён
- **WHEN** файл картинки, на которую ссылается компонент клиента, удалён или переименован
- **THEN** `npm run build` в `js` завершается ошибкой с указанием отсутствующего файла
