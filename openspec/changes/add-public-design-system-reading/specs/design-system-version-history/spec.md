## MODIFIED Requirements

### Requirement: Предметные API читают опубликованную версию

Предметные методы чтения SHALL принимать необязательный `versionId` и возвращать состояние указанной временной
границы без изменения формы предметных данных. Без селекторов версии проектный доступ с правом черновика SHALL читать черновик, публичный доступ — последнюю поддерживаемую публикацию.

#### Scenario: Параметр версии отсутствует

- **WHEN** участник с правом чтения черновика вызывает предметный метод без `version` и `versionId`
- **THEN** API MUST вернуть состояние активного черновика

#### Scenario: Указана опубликованная версия

- **WHEN** клиент передаёт `versionId` опубликованной версии той же дизайн-системы
- **THEN** API MUST вернуть состояние на временной границе этой версии
- **THEN** редактор MUST использовать ответ только для чтения

#### Scenario: Версия принадлежит другой дизайн-системе

- **WHEN** `versionId` не принадлежит запрошенной дизайн-системе
- **THEN** API MUST вернуть `404 Not Found`

#### Scenario: Публичное чтение без выбора версии
- **WHEN** гость либо пользователь вне проекта читает явно выбранную публичную ДС без селекторов
- **THEN** API MUST вернуть последнюю поддерживаемую опубликованную границу либо `404`, если публикаций нет
- **THEN** явный `draft` MUST вернуть `403` без перехода на публикацию
