# Публикация и установка CLI

## Зачем

Пользователям нужны готовые CLI для macOS и Windows, а CI plasma-android — совместимый JVM-дистрибутив. Единый выпуск в S3 и установка одной командой устранят ручной выбор и перенос архивов.

## Изменения

- Выпускать macOS arm64/x64, Windows x64 и JVM по тегу `cli-vX.Y.Z`, сохраняя ручной запуск для существующего тега.
- Публиковать архивы, SHA-256 и указатель стабильного выпуска в S3; сохранять JVM-архив в GitHub Releases.
- Добавить сетевые установщики shell/PowerShell поверх локальных установщиков; сохранить установку без сети для локального контура.
- Переиспользовать существующие AWS secrets публикации клиента; отдельно задать префикс `CLI_S3_PREFIX` и публичный адрес загрузки `CLI_DOWNLOAD_BASE_URL` через GitHub vars.
- Связать `--version` с версией выпуска.

## Возможности

### Новые возможности

- `cli-release-delivery`: согласованный выпуск четырёх дистрибутивов и установка из сети либо локальных файлов.

### Изменяемые возможности

Нет. Существующий Windows-дистрибутив и его установка сохраняются.

## Влияние

Изменяются `.github/workflows/publish-cli-release.yml`, упаковка и версия `frontend-kt/cli`, `frontend-kt/cli/distribution/`, при необходимости локальные сценарии установки. backend-kt, js, API и базы данных не меняются. Новых библиотек Kotlin не требуется. Настройка nginx, конкретное размещение в S3 и пользовательская инструкция относятся к другим работам. Change независим от выбора контекста CLI/MCP.
