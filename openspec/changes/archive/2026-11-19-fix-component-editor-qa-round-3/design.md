## Контекст

- `NumberControl` записывает значение по `Enter` вызовом `commit()`, фокус остаётся в поле. Аргументы story пишутся
  на каждый ввод, `Enter` ничего не делает.
- Ширину числового поля задаёт `field-sizing: content` при `width: auto`. Safari до 26 его не поддерживает: поле
  получает свою ширину по умолчанию, ужимается flex-раскладкой, и в фокусе текст прокручивается к курсору — первая
  цифра уходит за край.
- Ошибку загрузки компонента `Components.tsx` рисует строкой «Не удалось загрузить компонент» с кнопкой. Заглушка из
  макета уже есть у каталога проектов (`Catalog.State`, `catalog-error-state`, `error-state.png`).
- В «Библиотеке» значок поиска — символ `⌕`; поле поиска и `select` формата в фокусе получают обводку браузера.

- В режиме только чтения `Workspace` ставит `inert` на меню и рабочую область. В разделе компонентов из-за этого
  просмотрщик не может открыть другой компонент, сменить платформу превью и вариации. Сам раздел уже закрывает
  правку: каталог `editable = false`, без вкладки «Структура», автосохранение не запускается.

## Решения

### Только чтение в разделе компонентов

`Workspace` получает `inertWhenReadOnly` (по умолчанию `true`, остальные разделы не меняются); раздел компонентов
передаёт `false`. Плашка «Только просмотр» остаётся. Неактивными (`inert`) становятся только секции свойств
инспектора: иначе просмотрщик менял бы значения в модели, а автосохранение их не отправило бы.


### `Enter` снимает фокус

`Enter` вызывает `blur()`, а запись идёт обработчиком ухода из поля: одна запись вместо двух. Так же для текстового
аргумента story.

### Ширина числового поля без `field-sizing`

Если `CSS.supports('field-sizing', 'content')` ложно, поле получает `width: calc(<длина значения>ch + 2px)` (минимум
1 символ). Где `field-sizing` есть, поведение прежнее.

### Общая заглушка ошибки

Разметка ошибки `Catalog.State` выносится в `LoadErrorState` (картинка, заголовок, текст, «Повторить»). Каталог
использует её как раньше, `Components.tsx` — вместо строки ошибки, по центру рабочей области (модификатор
`is-workspace` без верхнего отступа каталога).

### Значения токенов в px по правилу экранов токенов

Подсказки `getShapeTokenOptions` (`× 16 px`) и `getTypographyTokenOptions` (`fontSize × 16`) умножали любое значение
на 16, считая его rem: значение в px давало неверное число. Подсказки берут `cssPx` из
`modules/sizeTokens/domain/platformValues.ts`, как экраны токенов: px — как есть, rem — × 16. Формат прежний:
`12 px` у формы, `16` у типографики.

### Неподвижная «Variants»

`position: sticky` давал рывки при прокрутке колесом. Вкладка «Стилизация» — колонка из неподвижной части
(`component-inspector-pinned`, «Variants», не выше половины панели, со своей прокруткой при множестве вариаций) и
прокручиваемой (`component-inspector-scroll`: Preview, ошибки, секции свойств; на ней `container-type`
для ширины списков токенов).

### Поиск и формат в пикере

Значок поиска — `TyGlyph name="search"`. Поле поиска и `select` формата в фокусе: без `outline`, рамка акцентного
цвета, как у полей инспектора.
