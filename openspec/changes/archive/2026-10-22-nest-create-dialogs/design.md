## Context

Маршруты клиента (`App.tsx`) объявлены плоско: `projects` рисует `ProjectsPage`, а `projects/new` — отдельный `CreateProjectPage`, который повторяет каталог проектов (`CatalogPage`, сортировка, `ProjectCards`) и добавляет окно; так же `projects/:projectId/design-systems/new` рисует `CreateDesignSystemPage`, повторяющий шапку и карточки страницы проекта. Данные проекта и списка дизайн-систем обе страницы читают через `useLoad` с одинаковыми ключами кэша (`project:<id>`, `systems:<id>`).

## Goals / Non-Goals

**Goals:** один каталог проектов и одна страница проекта; окна создания проекта, создания и импорта дизайн-системы — дочерние маршруты; прежние адреса и поведение.

**Non-Goals:** изменение вида окон, адресов и прав; создание темы — отдельная страница без копии.

## Decisions

### 1. Вложенный маршрут с `Outlet`

```tsx
<Route path="projects" element={<ProjectsPage />}>
    <Route path="new" element={<CreateProjectDialog />} />
</Route>
<Route path="projects/:projectId" element={<ProjectPage />}>
    <Route path="design-systems/new" element={<CreateDesignSystemDialog />} />
</Route>
```

`ProjectsPage` и `ProjectPage` рисуют каталог как сейчас и `<Outlet />` внутри `CatalogPage`; `ProjectPage` передаёт окну загруженный проект через контекст `Outlet`. Окну проекта контекст не нужен. Под открытым окном каталоги выглядят как раньше: все проекты одной сеткой без раздела «Архивные», а пустой проект — пустой сеткой без заглушки «Дизайн-систем пока нет»; окно дизайн-системы появляется после загрузки списка дизайн-систем. Для этого страницы проверяют `useOutlet()`. Остальные маршруты дизайн-системы (`design-systems/:designSystemId`, настройки, темы) остаются отдельными страницами: статический сегмент `new` в React Router имеет приоритет над `:designSystemId`.

Альтернатива — модалка по состоянию страницы проекта без адреса. Отвергнута: пропадают прямая ссылка на создание и «назад» браузера, которые требует `add-projects-workflow`.

### 2. Окно получает проект из контекста `Outlet`

`CreateDesignSystemDialog` берёт загруженный проект через `useOutletContext`. Окно появляется только после загрузки проекта: пока `ProjectPage` показывает «Загружаем проект…», дочерний маршрут не рисуется. Это сохраняет поведение «форма не показывается до загрузки прав».

### 3. Отказ в доступе — окном

Без права `designSystems:write` или в архивированном проекте окно показывает «Нет доступа» с кнопкой «Закрыть», ведущей на страницу проекта; запрос создания не отправляется. Раньше это была отдельная страница `State` без каталога.

## Risks / Trade-offs

- [Тесты рендерят `CreateDesignSystemPage` отдельно от страницы проекта] → тесты переводятся на вложенный маршрут; проверяется, что под окном одна шапка и одна сетка карточек.
