## Реализовано

- ADR и единая ER-схема включают палитру и группы. V1–V6 dev неизменны; одна V7 переводит
  версии, SSE, палитру и группы в предметные редакции с устойчивыми UUID.
  Группа и порядок токена находятся в token_revisions. Копия шаблона темы неизменяема.
- Чтение выбранной границы без ленивой инициализации; многошаговое чтение использует REPEATABLE READ.
  Запись палитры сохраняет различия, а не заменяет весь состав.
- Новые операции используют доверенный контекст, предметные блокировки и метаданные.
  POST сохраняет точный ответ повторяемой команды в той же транзакции. Общий счётчик темы
  не служит условием записи. Цветовые значения принимают отдельную базовую редакцию платформы/режима.
- Начальные группы/раскладка создаются в исходном состоянии ДС до первого черновика.
  Значения темы записываются пакетно с локальной точкой сравнения, без тысяч строк журнала.
- Удаление семейства пакетно помечает значения удалёнными, очищает привязки палитры
  и текущие ссылки свойств компонентов через редакции, сохраняя опубликованные данные.
- Отмена проверяет отложенные ограничения до ответа. Занятое имя и нарушенные зависимости
  возвращают REVERT_DEPENDENCY_CONFLICT с откатом всей попытки. Сначала восстанавливается токен/растяжка,
  затем значение или компонентная ссылка. Частичная отмена сохраняет соседние правки.
- Обработчики палитры/групп зарегистрированы; местоположение растяжки/ступени дополняется пакетным
  запросом. Изменение только вычисленного цвета не создаёт строк токенов.
- В клиенте восстановлены новый UI цветов/палитры, группы, Compose, исходные ссылки и выбранная версия.
  Новые операции учитываются в общей активности автосохранения и времени успешной записи.
- Очередь подтверждает отправленный снимок, а не новый ввод. Отправляет только изменённые
  платформы/режимы. Наложение неподтверждённых значений переживает перечитывание.
- Редакции применяются вместе с принятыми данными; запоздавший GET групп не возвращает старые
  значения/редакции. Перечитывание обнаруживает даже полностью завершившуюся за время GET запись.
- Отмена палитры/групп перечитывает область токенов, не компоненты и не весь редактор.
  Палитровые редакции отправляют существующую SSE-область theme-tokens.
