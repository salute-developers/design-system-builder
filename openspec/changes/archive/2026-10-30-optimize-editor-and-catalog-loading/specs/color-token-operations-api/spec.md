## ADDED Requirements

### Requirement: Команда возвращает подтверждённое адресное состояние

Color-token API SHALL возвращать JSON-подтверждение из той же транзакции команды: update — текущие значения семейства только своей темы с полными ID/редакциями и формой обычного чтения; create — определения и начальные значения своей темы; move/delete — определения/удалённые ID и позиции изменённых соседей. API SHALL сохранять действующие проверки доступа, ID и ссылок, конфликты редакций и нормализацию. Полный ответ SHALL сохраняться для идемпотентного повтора.

#### Scenario: Метаданные превышают размер заголовка
- **WHEN** технический заголовок mutation metadata обрезан до транспортного лимита
- **THEN** подтверждённые значения и структура в JSON MUST оставаться полными для области команды
- **AND** значения чужой темы MUST NOT попадать в ответ update/create

#### Scenario: Повтор уже выполненной команды
- **WHEN** клиент повторяет запрос с тем же ключом и телом
- **THEN** сервер MUST вернуть сохранённое подтверждение без повторной предметной записи
