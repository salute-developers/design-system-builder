## Why

Ревью PR #185 нашло четыре ошибки в доработках редактора компонентов: web-превью отклоняет CSS-выражения, которые редактор разрешает сохранять, переход из «Доступности» сбрасывает выбор после каждого сохранения, импорт ставит вариацию `view` не последней, а режим просмотра блокирует фильтры и сворачивание секций. Исправить их нужно до влития PR. Кроме того, после дублирования или удаления конфигурации список конфигураций не обновлялся до перезагрузки страницы, а удаление следующей конфигурации падало с ошибкой: ошибка пришла из `dev` и мешает проверке PR. По итогам проверки PR вкладка «Стилизация» также получает русские заголовки, пункт «Все варианты» вместо «—» и отдельный блок выбора конфигурации.

## What Changes

- Web-плагин пропускает CSS-выражения (`calc`, `var`, `min`, `max`, `clamp`) в строковых литералах числовых свойств и разрешает их шаблоны токенов ядра. Строки с единицами (`3rem`, `12px`) у таких свойств по-прежнему отклоняются `invalid_payload` как старый формат.
- Поле числа в инспекторе записывает `12px` и `0.75rem` числом в px (`rem` × 16), чтобы редактор не сохранял значения, которые превью отклоняет.
- Переход из «Доступности» цветовых токенов выбирает стиль пары один раз, при первой загрузке компонента; перечитывание конфигурации после сохранения выбор не меняет.
- Импорт конфигурации компонента добавляет вариацию `view` после всех вариаций пакета, включая заданные только в `targets`.
- Список конфигураций обновляется сразу после дублирования, переименования и удаления: перечитанный компонент заменяет прежний экземпляр, если изменился состав конфигураций, имена вариаций или пересечения, а не только значения открытой конфигурации.
- Пункт «не выбрано» в списках вариаций называется «Все варианты» вместо «—».
- Выбор конфигурации — отдельный закреплённый блок «Конфигурация» над блоком вариаций.
- Технические заголовки вкладки «Стилизация» (блоки, секции, группы цветовых токенов) — по-русски; имена из базы и story не меняются.
- В режиме только чтения неактивны только поля значений свойств: фильтр «только заполненные», сворачивание секций и значения остаются доступны, в том числе для скринридера.

### Modified Capabilities
- `web-preview-plugin`: старый формат WEB не включает CSS-выражения у числовых свойств.
- `component-editor-workbench`: переход из «Доступности» применяется один раз; режим только чтения не блокирует фильтры и сворачивание секций; «Все варианты», отдельный блок «Конфигурация», русские заголовки вкладки «Стилизация».
- `component-editor-configurations`: список конфигураций обновляется без перезагрузки страницы.
- `design-system-component-templates`: импорт конфигурации добавляет `view` последней вариацией.

## Impact

- `js/apps/preview-web-plugin`: `src/resolve/index.ts` (`findPreconvertedCss`), тест через `parseWebPayload`, подъём версии в `package.json` и `package-lock.json`, пересборка архива в `local-dev/web-preview`.
- `js/apps/client`: `ComponentEditor.tsx`, `ComponentInspector.tsx`, строка свойства инспектора, `features/themeEditor/keepLoadedComponents.ts`.
- `backend-kt/ds-service`: `ComponentConfigImporter.withViewAxis`, интеграционный тест импорта. API и схема БД не меняются.
