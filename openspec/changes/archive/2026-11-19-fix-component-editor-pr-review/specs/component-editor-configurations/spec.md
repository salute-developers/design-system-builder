## ADDED Requirements

### Requirement: Список конфигураций обновляется без перезагрузки

После создания, дублирования, переименования или удаления конфигурации редактор SHALL показывать новый список конфигураций сразу после перечитывания компонента, без перезагрузки страницы, даже если значения открытой конфигурации не изменились.

#### Scenario: Дублирование

- **WHEN** пользователь дублирует конфигурацию `default` у Button
- **THEN** в списке «Конфигурации» MUST сразу появиться `default-copy`, и она MUST открыться

#### Scenario: Удаление подряд

- **WHEN** пользователь подряд удаляет несколько копий
- **THEN** каждая удалённая копия MUST сразу пропадать из списка, и удаление следующей MUST NOT завершаться ошибкой
