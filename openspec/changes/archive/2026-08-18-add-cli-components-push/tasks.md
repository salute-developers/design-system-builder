## 14. Открытое к решению

- [ ] 14.1 Разобраться с ненулевым кодом возврата `db:migrate` при накате поверх непустой базы. На чистой базе `drizzle-kit` завершается с кодом 0; код 1 наблюдался только при накате на базу с данными, причём SQL применялся полностью и результат в базе был верным, а тот же SQL через `psql` проходил без ошибок. Диагностики инструмент при этом не печатает. Пока не воспроизведено надёжно, поэтому неясно, в каких условиях CI сочтёт миграцию упавшей. Прежде инструмент уже требовал TTY для интерактивных подсказок.
- [x] 14.2 Нормализовать форму имён в `component_states`. `uikit-api-meta.json` даёт две формы: 11 значений с `configName` уже в kebab-case, 28 — однословные в PascalCase.
