## Зачем

`dsbuilder ds generate --platform react` без `--output` кладёт результат в `js/cli/output` — каталог
генератора, а не проекта: делегат не передаёт `--out`, а `npm` запускается из `js/cli`, где у генератора
своё умолчание. Разработчик ищет сгенерированный пакет рядом со своим `.sdds` и не находит его.

## Что меняется

- Web-делегат всегда передаёт генератору `--out`: заданный `--output` или `<рабочая копия>/output`,
  где рабочая копия — родитель найденного `.sdds`.
- Прямой запуск `npm run generate:*` в `js/cli` не меняется: его умолчание остаётся `js/cli/output`.

## Возможности

### Новые возможности

Нет.

### Изменяемые возможности

- `platform-web-delegate`: каталог результата по умолчанию — `output` в рабочей копии.

## Влияние

- `frontend-kt/platform-web`: `WebNpmDelegate` и его тест.
- `js/cli`, `backend-kt`, API и хранение данных не затрагиваются.
