## Контекст

`WebNpmDelegate` запускает `npm run generate:*` с рабочим каталогом `js/cli` и добавляет `--out` только
при заданном `--output`. Без него генератор берёт своё умолчание `js/cli/output`.

## Решения

### Умолчание — `<рабочая копия>/output`, а не сама рабочая копия

Генератор заменяет в каталоге результата `src/theme`, `src/components` и `src/index.ts`. Корень
рабочей копии обычно и есть React-проект со своим `src/index.ts`, поэтому запись прямо в него стёрла бы
файл проекта. Подкаталог `output` безопасен и совпадает по имени с умолчанием `js/cli`.

Альтернатива — переводить в абсолютный путь относительный `--out` из аргументов после `--` —
отклонена пользователем: она не меняет поведение без флагов, а именно оно сбивает с толку.

### Где решается

Умолчание задаёт делегат, а не общий `PlatformCapabilityRunner`: у iOS и Android каталог результата
по умолчанию выбирает сам инструмент, и это поведение не меняется.

## Риски / Компромиссы

- [В рабочей копии появляется каталог `output`, который может попасть в Git] → проект сам решает,
  добавить ли его в `.gitignore`; путь виден в выводе `Generated <путь>`.
