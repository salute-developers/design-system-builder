## ADDED Requirements

### Requirement: Чтение индекса компонентов не заменяет загруженные компоненты

Чтение краткого списка компонентов без выбранного компонента SHALL обновлять только состав списка. Оно добавляет новые компоненты и убирает пропавшие. Уже загруженные экземпляры компонентов MUST NOT заменяться данными из этого чтения. Полное чтение выбранного компонента SHALL заменять его экземпляр, как и прежде.

#### Scenario: Две правки подряд

- **WHEN** пользователь меняет свойство компонента, правка подтверждена, затем он меняет его ещё раз, и чтение индекса по сигналу после первого сохранения завершается после подтверждения второй правки
- **THEN** поле MUST продолжать показывать значение второй правки
- **THEN** экземпляр открытого компонента MUST NOT заменяться данными из чтения индекса

#### Scenario: Компонент возвращён в дизайн-систему

- **WHEN** чтение индекса нашло компонент, которого не было в списке
- **THEN** компонент MUST появиться в списке

#### Scenario: Компонент скрыт

- **WHEN** компонента больше нет в индексе
- **THEN** он MUST исчезнуть из списка
