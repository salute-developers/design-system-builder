## Контекст

Изменение уточняет экспорт из `add-figma-token-export` по итогам показа дизайнеру и добавляет копирование в просмотр токенов. Архитектура не меняется: план строит `:plugins:figma-core`, основной поток его применяет.

## Решения

### Состояния цвета

Суффикс состояния становится частью листа имени в PascalCase: `text.default.primary-hover` → `Text&Icons/Default/General/PrimaryHover`, `surface.default.transparent-accent-active` в «Accent / Transparent» → `Surfaces/Default/Accent/Transparent/AccentActive`. Так названы переменные в библиотеке дизайнеров SDS 2.0. Подтемы и стили градиентов строятся тем же правилом, поэтому у каждого состояния есть своя переменная подтемы. Состояния не скрываются из выбора: в библиотеке дизайнеров они тоже в общем списке.

Альтернатива — отдельная папка `States` — отклонена: дизайнеры кладут состояния рядом с основным цветом.

### Скругления

Набор скруглений повторяет образец `DS BUILDER | STYLES` и библиотеку дизайнеров: `cR` и хвост имени токена (`round.m` → `cRm`), `null` = 0 всегда, полное скругление — `Rounded` = 1000. Внутренние радиусы `calc:[cR<размер>-2]` для вложенных элементов в DS Builder не хранятся: экспорт выводит их из `cRxxs`, `cRm`, `cRl`, `cRxl` (значение минус 2) — ровно тот список, что есть в образце. Ключ внутреннего радиуса строится от ключа основного, поэтому повторный экспорт обновляет его на месте.

### Недостающие шрифты

Основной поток собирает семейства, которых нет среди доступных шрифтов Figma, в поле отчёта `missingFonts`. Окно показывает по нему подсказку, не разбирая текст причин пропуска. Figma desktop видит шрифты, установленные в системе, поэтому у дизайнера с SB Sans стили создаются без дополнительных действий.

### Копирование в просмотре

Каждое показанное имя и значение — кнопка, которая копирует свой текст. Окно плагина работает с origin `null`, где `navigator.clipboard` может быть недоступен, поэтому копирование идёт через скрытое поле и `document.execCommand('copy')`, а `navigator.clipboard` — запасной путь. Подтверждение «Скопировано» показывается в окне.

## Риски / Компромиссы

- [Число переменных растёт: в теме Malachite примерно 866 вместо 280] → это структура библиотеки дизайнеров; повторный экспорт по ключам обновляет добавленные переменные без дубликатов.
- [Начертания SB Sans могут называться не так, как в таблице насыщенностей] → такой стиль пропускается с насыщенностью в причине; таблица дополняется по отчёту.
