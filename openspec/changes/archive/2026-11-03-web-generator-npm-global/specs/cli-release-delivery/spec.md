## MODIFIED Requirements

### Requirement: Локальная установка без сети

Каждый архив SHALL содержать локальный установщик, устанавливающий CLI без скачивания. Локальный контур SHALL переиспользовать этот уровень установки; установка SHALL поддерживать пользовательский каталог без административных прав. Установка web-генератора SHALL быть отдельным необязательным шагом, которому нужны сеть и npm; его неудача SHALL NOT отменять установку CLI.

#### Scenario: Готовые локальные файлы
- **WHEN** локальный установщик получает распакованный дистрибутив без доступа к сети
- **THEN** он MUST установить CLI и обеспечить команду через ссылку либо пользовательский PATH
- **THEN** повторная установка MUST NOT дублировать запись PATH
- **THEN** при недоступном npm-реестре установщик MUST вывести предупреждение о пропуске web-генератора и завершиться с кодом 0

#### Scenario: Каталог с пробелами
- **WHEN** архив и каталог установки имеют пробелы в пути
- **THEN** локальная установка MUST сохранить работоспособную команду и остальные файлы пользователя

## ADDED Requirements

### Requirement: Установка web-генератора вместе с CLI

Локальные установщики macOS, JVM и Windows SHALL после успешной установки CLI вызывать установленный
`dsbuilder toolchain install web`. Сетевые установщики SHALL передавать локальному установщику флаг отказа от
этого шага.

#### Scenario: Node.js установлен

- **WHEN** пользователь запускает `install.sh` или `install.ps1`, и `npm` есть в `PATH`
- **THEN** установщик MUST установить CLI, затем последнюю версию `@sddsjs/design-system-builder-generator` в `~/.dsbuilder/toolchains/web`
- **THEN** установщик MUST напечатать установленную версию генератора

#### Scenario: Node.js не установлен

- **WHEN** `npm` нет в `PATH`
- **THEN** установщик MUST установить CLI и завершиться с кодом 0
- **THEN** установщик MUST вывести предупреждение, что для генерации React нужны Node.js 22+ и `dsbuilder toolchain install web`

#### Scenario: Системный Node.js без прав на глобальный каталог

- **WHEN** глобальный каталог npm недоступен пользователю для записи
- **THEN** установщик MUST установить генератор без `sudo` и без изменения настроек npm

#### Scenario: Ошибка установки генератора

- **WHEN** `dsbuilder toolchain install web` завершается ошибкой
- **THEN** установленный CLI MUST остаться на месте, а установщик MUST завершиться с кодом 0 и вывести причину и команду повтора

#### Scenario: Отказ от установки генератора

- **WHEN** пользователь передаёт `--without-web` в `install.sh` (локальный или сетевой) либо `-WithoutWeb` в `install.ps1`
- **THEN** установщик MUST NOT запускать npm
- **THEN** флаг MUST сочетаться с `--without-ios` в любом порядке
