## Why

Ревью PR #155 («Редактор компонентов: Раздел Структура») нашло ошибки вкладки «Структура» и связанных с ней частей.
Самая серьёзная — правка инварианта в одной конфигурации может записаться в инвариант другой конфигурации того же
компонента. Кроме того, «Дерево вариаций» при ручной проверке ожидали увидеть строгой иерархией вариаций
(`size → shape → view`, цветовая схема только в листьях), а не корнем из значений всех вариаций. Генератор web-пакета
может получить два допустимых имени конфигураций с одним идентификатором (`dense-2` и `dense2`) и записать один
файл поверх другого.

## What Changes

- **Инварианты открытой конфигурации.** Автосохранение ищет существующее значение инварианта только среди значений
  открытой конфигурации.
- **Смена конфигурации во «Структуре».** Пока модель новой конфигурации не загружена, вариации прошлой не показываются
  и действия над ними недоступны; режим редактирования имени сбрасывается.
- **Перечитывание после структурной операции.** Перечитывается открытый компонент с его платформой (Compose — как
  Compose) и после неудачной операции тоже; ошибка операции по-прежнему показывается.
- **Справочник токенов при правке пересечения.** Литерал пишется без чтения справочника, справочник токенов
  переиспользуется между правками.
- **Дерево вариаций — строгая иерархия.** Уровни идут подряд в порядке вариаций, цветовая схема последней: в корне —
  значения первой вариации, под каждой веткой — значения следующей. Настроенные пересечения, которые пропускают
  уровень (например, `size: l` + `view: accent` без `shape`), показываются отдельным списком «Другие пересечения» под
  деревом: их можно открыть и удалить.
- **Имена конфигураций без коллизий в коде.** `ds-service` отклоняет имя, которое после удаления дефисов и без учёта
  регистра совпадает с именем другой конфигурации компонента (`dense-2` и `dense2`): `appearance_name_taken` в
  редакторских маршрутах и импорте, `409 APPEARANCE_NAME_CONFLICT` в `POST`/`PATCH /appearances`, как для занятого имени;
  сгенерированные имена (`new-2`) такие совпадения обходят. Web-генератор останавливается с ошибкой, если у
  компонента два имени дают один идентификатор.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `component-editor-workbench`: строгая иерархия дерева вариаций и список «Другие пересечения»; смена конфигурации во
  «Структуре»; перечитывание после операции.
- `component-editor-configurations`: уникальность имени с учётом идентификатора в коде; инварианты открытой
  конфигурации при автосохранении.
- `local-web-generation`: ошибка при совпадении идентификаторов конфигураций.

## Impact

- **js, `apps/client`:** `api/componentRepository.ts` (инварианты открытой конфигурации),
  `api/componentStructureRepository.ts` (справочник токенов), `pages/components/Components.tsx` (перечитывание),
  `ComponentStructure/ComponentStructurePanel.tsx` и `variationTree.ts` (смена конфигурации, дерево).
- **js, `cli`:** `generator/utils/appearanceName.ts`, `generator/generate.ts` — проверка совпадений.
- **backend-kt, `ds-service`:** `AppearanceEditorRules.kt` (`requireFree`, `freeName`), импорт конфигураций,
  интеграционный тест.
- **frontend-kt:** без изменений.
