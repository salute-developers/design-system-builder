## MODIFIED Requirements

### Requirement: Проверка manifest перед запуском
Клиент SHALL загружать `preview-plugin.json` из адреса плагина и MUST отклонять плагин, если manifest недоступен, не является корректным JSON, объявляет неподдерживаемую версию протокола или платформу, не содержит точки входа, не объявляет обязательных сообщений обмена либо не перечисляет компонент, для которого запрашивается preview. Платформа manifest SHALL совпадать с платформой компонента: `compose` для Compose-компонентов, `web` для web-компонентов. Проверка поддержки WebAssembly SHALL выполняться только для платформы `compose`.

#### Scenario: Совместимый плагин
- **WHEN** manifest объявляет платформу компонента, поддерживаемую версию протокола, точку входа, сообщения обмена и нужный компонент
- **THEN** клиент MUST продолжить загрузку точки входа в `iframe`

#### Scenario: Несовместимая версия протокола
- **WHEN** manifest объявляет версию протокола, которую клиент не поддерживает
- **THEN** клиент MUST не запускать плагин и MUST сообщить причину отказа

#### Scenario: Компонент не поддержан плагином
- **WHEN** нужный компонент отсутствует в списке компонентов manifest
- **THEN** клиент MUST не запускать Compose-preview для этого компонента

#### Scenario: Платформа manifest не совпадает с компонентом
- **WHEN** для web-компонента загружен manifest с `platform: "compose"` или наоборот
- **THEN** клиент MUST отклонить плагин для этого компонента

#### Scenario: Web-плагин без WebAssembly
- **WHEN** браузер не поддерживает WebAssembly GC, а загружается web-плагин
- **THEN** клиент MUST загрузить web-плагин без проверки WebAssembly
