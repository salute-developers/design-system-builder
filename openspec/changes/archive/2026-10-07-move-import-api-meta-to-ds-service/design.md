## Context

`import-api-meta` — единственная ручка ветки, которая не перенесена в `ds-service`: она лежала под `/api/admin/**`, а спека миграции оставляла весь `/api/admin/**` в `db-service`. После выхода `db-service` из эксплуатации это блокирует наполнение глобального слоя.

## Decisions

**Внутренний путь `/api/ds/admin/component-config/import-api-meta`.** Административная операция не принадлежит проекту, поэтому не попадает под `/api/projects/{projectId}/ds`. Она не входит в `route-manifest.json`, и OpenAPI проектных маршрутов её не описывает. Публичный путь для CLI остаётся прежним (`/api/admin/component-config/import-api-meta`), Gateway переписывает его на внутренний, поэтому клиенты не меняются.

**Служебный проект `global`.** Доверенный контекст `ds-service` (`TrustedProjectPrincipalFactory`) требует непустой `X-Project-Id`, даже для системного администратора. На административном маршруте Gateway выставляет `global` сам (клиентский заголовок перезаписывается), токен пользователя проверяется через `/_auth_user`, ключ проекта получает `401`. Значение совпадает с тем, что `ds-service` уже использует для глобальных операций в тестах.

**Роль проверяется дважды.** В маршруте — до разбора тела (отказ `403` без парсинга), в use case — повторно до обращения к репозиторию.

**Порт и реализация.** `ImportApiMetaUseCase` (`application`) → `ApiMetaRepository` → `ExposedApiMetaRepository` (`data`). Нормализация платформенных имён (`string | {name, deprecated}` и прежнее `platformName`) выполняется на границе `presentation` и сводится в доменный `ApiMetaAlias`. Dry run — `TransactionRunner.rollback`, отказ записи — `Failed` и ответ `422 Import failed`, как в прежней реализации.

**Идемпотентность и параллельные запросы.** Вставки используют `ON CONFLICT DO NOTHING` (`insertIgnore`), после чего строки перечитываются, так что строка, созданная параллельным запросом, не теряется.

**Удаление из `db-service`.** Дубликат реализации не оставляется: возможность не выпускалась, откат на `db-service` для неё не требуется.

## Risks / Trade-offs

- Служебное значение `global` — соглашение между Gateway и `ds-service`; его нарушение приведёт к `403`, а не к утечке прав: роль всё равно проверяется.
- Импорт строится построчными вставками (сотни компонентов и тысячи свойств за один запрос укладываются в секунды); пакетная вставка возможна позже без изменения контракта.
