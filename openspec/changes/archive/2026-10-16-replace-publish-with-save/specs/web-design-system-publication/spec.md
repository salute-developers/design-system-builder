## ADDED Requirements

### Requirement: Editor saves the design system with a Save button

Редактор веб-клиента SHALL сохранять дизайн-систему кнопкой «Сохранить» без отдельного окна. Сохранение
SHALL NOT запускать генерацию документации. Кнопка SHALL быть видна, когда у дизайн-системы есть локальный
черновик, она открыта не только для чтения и не открыто окно создания.

#### Scenario: Успешное сохранение

- **WHEN** пользователь нажимает «Сохранить» и сохранение завершается успешно
- **THEN** клиент MUST вызвать сохранение дизайн-системы и MUST NOT вызывать `POST /api/projects/{id}/docs/api/documentation/generate`
- **THEN** клиент MUST очистить локальный черновик и перезагрузить данные редактора
- **THEN** кнопка MUST скрыться, потому что черновика больше нет

#### Scenario: Черновик изменился во время сохранения

- **WHEN** пользователь меняет данные в редакторе, пока сохранение ещё выполняется, и сохранение завершается успешно
- **THEN** клиент MUST NOT очищать изменённый черновик и MUST перезагрузить данные, применив черновик поверх сохранённых
- **THEN** кнопка «Сохранить» MUST остаться видимой

#### Scenario: Видимость в редакторе темы

- **WHEN** пользователь открывает тему по маршруту `projects/{projectId}/design-systems/{designSystemId}/themes/{tenantId}` и у неё есть локальный черновик
- **THEN** кнопка «Сохранить» MUST быть видна

#### Scenario: Сохранение в процессе

- **WHEN** сохранение ещё выполняется
- **THEN** кнопка MUST показывать состояние сохранения
- **THEN** повторное нажатие MUST NOT отправлять второй запрос

#### Scenario: Ошибка сохранения

- **WHEN** сохранение завершается ошибкой, отличной от конфликта редактирования
- **THEN** клиент MUST показать причину ошибки рядом с кнопкой
- **THEN** локальный черновик MUST остаться, а кнопка MUST остаться доступной для повтора

#### Scenario: Конфликт редактирования

- **WHEN** сохранение возвращает `409` с кодом `TENANT_EDIT_CONFLICT`
- **THEN** клиент MUST сохранить локальный черновик и сообщить, что тема изменена в другой сессии
- **THEN** клиент MUST предложить действие загрузки актуальных данных, которое перезагружает редактор
- **THEN** клиент MUST NOT автоматически повторять отправку
- **THEN** кнопка «Сохранить» MUST быть скрыта, пока не загружены актуальные данные

#### Scenario: Окна публикации нет

- **WHEN** пользователь работает в редакторе
- **THEN** клиент MUST NOT показывать кнопку «Опубликовать» и окно публикации

## REMOVED Requirements

### Requirement: Publication window saves the design system and builds documentation

**Reason**: окно публикации заменено кнопкой «Сохранить»; документация строится вручную и при сохранении
не запускается.

**Migration**: сохранение — кнопкой «Сохранить» в редакторе; генерация документации — действием
«Опубликовать документацию» на странице Debug.
