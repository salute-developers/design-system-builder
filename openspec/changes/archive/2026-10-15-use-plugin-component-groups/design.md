## Context

`getComposeMenuItems(configs)` строит `groupByName` из каталога web (`componentList`) и таблицы `composeComponentGroups`, а
компоненту без записи даёт группу «Other». Меню строит `Components.tsx` синхронно из конфигураций, манифест плагина
(`loadComposePreviewManifest`, с кэшем) загружается асинхронно и нужен лишь для превью.

## Проверено на данных

- Сверка всех 79 компонентов api-меты с `CoreComponentName.group()` песочницы: 10 расхождений (см. Why) и один компонент
  (`ModalBottomSheet`), который в таблице клиента есть, а в таблице имён песочницы под другим ключом (`BOTTOMSHEET`).
- `StoryEntry.story.component.group` в реестре историй плагина знает группу каждого компонента, поэтому плагин может
  отдавать её без новых данных.

## Decisions

1. **Источник групп — манифест.** Клиент читает `manifest.groups`: `[{ "name": "Data Display", "components": ["Accordion", …] }]`.
   Формат парного change, поле необязательное; разбор терпим: невалидное `groups` отбрасывается целиком, манифест остаётся
   рабочим.
2. **Приоритет.** Группа из манифеста сильнее таблицы клиента; компонент, которого нет в `groups`, ищется как раньше
   (таблица клиента, каталог web, «Other»). Так старый плагин без `groups` и компонент вне манифеста работают как сейчас.
3. **Загрузка.** Страница компонентов запрашивает манифест (запрос общий с превью благодаря кэшу), пока он не пришёл,
   меню строится по таблице клиента и перестраивается, когда группы получены. Ошибка загрузки игнорируется.
4. **Порядок.** Меню сортирует группы по алфавиту для всех разделов; порядок песочницы (`ordinal`) не переносится.
5. **Таблица клиента остаётся.** Её удаление зависит от того, что плагин везде обновлён; отдельная задача после выкладки.

## Risks / Trade-offs

- Меню может один раз перестроиться после загрузки манифеста (компонент переезжает между группами); выбранный компонент
  при этом сохраняется, потому что выбор идёт по имени.
- Имена групп песочницы («AI Kit») отличаются от прежних клиентских («AI»): меню будет показывать имена песочницы.
