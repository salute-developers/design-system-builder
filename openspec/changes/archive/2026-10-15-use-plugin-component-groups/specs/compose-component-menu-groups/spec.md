## ADDED Requirements

### Requirement: Группы Compose-компонентов берутся из плагина

Клиент SHALL раскладывать Compose-компоненты в меню по группам из поля `groups` манифеста плагина, если оно есть и корректно.
Группа из манифеста MUST иметь приоритет над таблицей клиента. Компонент, которого нет в `groups`, SHALL получать группу по
прежним правилам (таблица клиента, каталог web, «Other»).

#### Scenario: Плагин отдаёт группы

- **WHEN** манифест содержит `groups`, где `CircularProgressBar` входит в «Data Display»
- **THEN** меню MUST показывать `CircularProgressBar` в группе «Data Display».

#### Scenario: Плагин без групп

- **WHEN** манифест не содержит `groups`
- **THEN** группы MUST определяться по таблице клиента, как раньше.

#### Scenario: Компонента нет в группах манифеста

- **WHEN** компонент отсутствует в `groups`
- **THEN** он MUST получить группу по таблице клиента или «Other».

### Requirement: Некорректные группы не ломают манифест

Клиент SHALL игнорировать поле `groups`, которое не соответствует формату, и MUST NOT считать из-за него манифест
недействительным.

#### Scenario: Группы неверного формата

- **WHEN** `groups` не массив или элемент без имени либо списка компонентов
- **THEN** манифест MUST оставаться действительным, а меню MUST использовать прежние правила.

### Requirement: Загрузка групп не мешает работе меню

Страница компонентов SHALL показывать меню по запасным правилам, пока манифест не загружен, и перестраивать его после
получения групп. Ошибка загрузки манифеста MUST NOT скрывать компоненты.

#### Scenario: Манифест недоступен

- **WHEN** манифест не загрузился
- **THEN** меню MUST остаться построенным по запасным правилам, а компоненты MUST открываться.
