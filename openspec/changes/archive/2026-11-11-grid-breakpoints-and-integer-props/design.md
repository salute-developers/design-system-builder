## Контекст

`getBaseGridView(breakpoints, view)` ядра строит медиазапросы по ширинам точек перелома: на каждой ширине — число колонок, отступы и ширина колонок `.plasma-grid-col-item`. Медиазапрос не принимает ширину из CSS-переменной, поэтому функции нужны готовые значения, и sdds-serv вызывает её прямо в конфиге вида. Импорт переносит только переменные. Число колонок хранится свойствами `integer`: тип есть в ds-service, но клиент и генератор знают только `float` и `dimension`.

## Решения

### `breakpointView` в манифесте, а не шаблон обёртки

Шаблон обёртки не знает значений ДС: ширины точек перелома живут в данных и меняются в редакторе. Генератор уже пишет эти значения в конфиг, поэтому вызов функции он строит из них же. Признак в манифесте описывает функцию и окончание параметров, без привязки генератора к Grid. Альтернатива — особый случай в генераторе по имени компонента — отвергнута.

### `integer` по образцу `float`

Значение пишется числом без единиц, как у `float`; в клиенте — отдельный класс свойства с числовым полем и числовым литералом в превью, чтобы целое число не превращалось в дробное. Переразметка в `float` отвергнута: тип в базе уже `integer`, а `import-api` не меняет тип заполненных свойств.

### Превью Grid

Стори строит вид той же функцией из переменных `--plasma-grid-*-min-width`, которые плагин кладёт на сцену из значений ДС: превью и пакет используют один механизм.

### Подписи

Разбиение слов — как `camelToKebab`: граница «строчная → заглавная» и «заглавная → заглавная со строчной»; слово из заглавных букв (`L`, `XXS`) остаётся заглавным, остальные — строчными.
