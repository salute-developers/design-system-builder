## MODIFIED Requirements

### Requirement: Настройки доступны из меню аватара

Меню аватара в rail SHALL сохранять сведения пользователя и выход и SHALL содержать действие «Настройки», открывающее `/settings`.

#### Scenario: Открытие настроек
- **WHEN** пользователь открывает меню аватара и нажимает «Настройки»
- **THEN** клиент MUST открыть настройки пользователя и закрыть меню
- **AND** настройки MUST работать без выбранного проекта

### Requirement: Структура настроек повторяет настройки дизайн-системы

Экран пользователя SHALL повторять структуру, стили, навигацию, интервалы и поведение настроек дизайн-системы, используя существующий общий каркас. Раздел «Общее» SHALL открываться по умолчанию, `Personal Access Token` SHALL оставаться отдельным разделом. Активный раздел SHALL определяться единым правилом по URL и доступным разделам с возвратом к первому при неизвестном значении. Пустая правая колонка «Общего» SHALL NOT показывать пояснения, предназначенные для настроек сущности.

#### Scenario: Прямой переход
- **WHEN** вошедший пользователь открывает URL настроек
- **THEN** клиент MUST показать rail, заголовок настроек пользователя и навигацию с разделами «Общее» и Personal Access Token; по умолчанию MUST показывать «Общее», а PAT MUST открываться при явном выборе
- **AND** MUST NOT требовать загрузки конкретного проекта или дизайн-системы
