## Context

`ComponentEditorPreview` собирает payload (`assembleComposePreviewPayload`) и передаёт его в `ComposePreviewFrame`, который
шлёт его в плагин. Debug-режим уже есть: `isDebugMode()` читает `localStorage.debug_mode` и скрывает отладочное меню
во всех окружениях, пока его не включат вручную.

## Decisions

1. **Условие показа.** `isDebugMode()` и Compose-renderer и наличие payload. Условие проверяется при каждом render: чтение
   `localStorage` дёшево, а перезагрузка страницы после включения режима не нужна.
2. **Что показывается.** Объект, который клиент передаёт в `ComposePreviewFrame` (`PreviewPayloadInput`). `requestId` не
   входит: он случайный и добавляется сессией при отправке, а для разбора важно содержимое.
3. **Дорогая часть откладывается.** JSON форматируется, только когда блок развёрнут; кнопка «Копировать» форматирует payload
   в момент нажатия, поэтому копировать можно и из свёрнутого блока.
4. **Копирование.** `navigator.clipboard.writeText`; без него (небезопасный контекст) запасной путь через временный
   `textarea`. Результат показывается рядом с кнопкой («Скопировано», «Не удалось скопировать»).
5. **Где лежит.** Отдельный компонент рядом с `ComponentEditorPreview`; в сам preview добавляется одно условие.

## Risks / Trade-offs

- Большой payload (десятки килобайт, много токенов) в развёрнутом виде делает блок длинным; высота ограничена прокруткой.
- Блок работает в режиме, который включается вручную, поэтому на пользователей PROM не влияет.
