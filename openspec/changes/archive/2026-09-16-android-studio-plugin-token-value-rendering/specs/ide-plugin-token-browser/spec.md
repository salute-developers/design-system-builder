## MODIFIED Requirements

### Requirement: Read-only token browsing

Плагин SHALL предоставлять только просмотр данных дизайн-системы через REST API DS Builder и SHALL NOT изменять файлы, зависимости или конфигурацию проекта пользователя. Для платформ `android` и `ios` плагин SHALL показывать превью значения токена, специфичное для его типа (`color`, `gradient`, `shadow`, `shape`, `spacing`, `typography`), вместо сырого JSON-текста.

#### Scenario: Просмотр доступных проектов

- **WHEN** пользователь авторизован
- **THEN** плагин запрашивает `GET /api/projects` и показывает только проекты, в которых пользователь состоит участником

#### Scenario: Пустой список проектов

- **WHEN** у авторизованного пользователя нет ни одного проекта с ролью `viewer` и выше
- **THEN** плагин показывает явное пустое состояние с пояснением, что владелец проекта должен добавить пользователя участником, а не выглядит как ошибка

#### Scenario: Единственный доступный вариант выбирается автоматически

- **WHEN** на шаге выбора проекта или дизайн-системы доступен только один вариант
- **THEN** плагин выбирает его автоматически, не заставляя пользователя явно кликать по единственному пункту списка, и не оставляет этот шаг в истории навигации

#### Scenario: Просмотр токенов выбранной дизайн-системы

- **WHEN** пользователь выбрал проект, дизайн-систему, версию и платформу
- **THEN** плагин запрашивает `GET /api/projects/{projectId}/ds/tokens` и `GET /api/projects/{projectId}/ds/token-values`
- **THEN** плагин показывает токены, сгруппированные по типу (`color`, `gradient`, `typography`, `spacing`, `shape`, `shadow`) во вкладках с поиском по имени токена внутри вкладки; тип `fontFamily` из просмотра исключён — его значение является именем шрифта и не несёт визуальной информации, полезной в этом UI

#### Scenario: Значение токена подбирается под выбранную тему

- **WHEN** пользователь выбрал светлую или тёмную тему просмотра токенов
- **THEN** плагин показывает значение токена, опубликованное для этой темы, если оно есть, иначе — значение, не зависящее от темы (например для `spacing`/`shape`)
- **THEN** выбор темы просмотра не зависит от текущей темы оформления самой IDE и может отличаться от неё

#### Scenario: Превью значения формы (`shape`) на android/ios

- **WHEN** выбранная платформа — `android` или `ios`, и значение токена типа `shape` разобрано как объект `{"kind":"round","cornerRadius":N}`
- **THEN** плагин показывает квадрат фиксированного размера, обрезанный по `RoundedCornerShape(N.dp)`, вместо сырого JSON-текста

#### Scenario: Превью значения отступа (`spacing`) на android/ios

- **WHEN** выбранная платформа — `android` или `ios`, и значение токена типа `spacing` разобрано как объект `{"value":N}`
- **THEN** плагин показывает полоску шириной `N.dp` рядом с числовой подписью значения, вместо сырого JSON-текста

#### Scenario: Превью значения градиента (`gradient`) на android/ios

- **WHEN** выбранная платформа — `android` или `ios`, и значение токена типа `gradient` разобрано как массив слоёв, каждый со своим `kind` (`linear`, `radial`, `angular` или `color`)
- **THEN** плагин показывает квадрат, залитый градиентной кистью, построенной из полей слоя (используя `com.sdds.compose.uikit.graphics.Gradients.Linear`/`Radial`/`Sweep` из уже подключённой `sdds-uikit-compose` для `linear`/`radial`/`angular` соответственно, или сплошной цвет `background` для `kind: "color"`), вместо сырого JSON-текста

#### Scenario: Превью значения тени (`shadow`) на android/ios

- **WHEN** выбранная платформа — `android` или `ios`, и значение токена типа `shadow` разобрано как массив из одного или нескольких слоёв (`color`, `offsetX`, `offsetY`, `spreadRadius`, `blurRadius`)
- **THEN** плагин показывает карточку с тенью, отрисованной по всем слоям (используя `com.sdds.compose.uikit.shadow.ShadowAppearance`/`Modifier.shadow` из уже подключённой `sdds-uikit-compose`), вместо сырого JSON-текста

#### Scenario: Превью значения типографики (`typography`) на android/ios

- **WHEN** выбранная платформа — `android` или `ios`, и значение токена типа `typography` разобрано в общую модель (размер, межстрочный интервал, начертание, трекинг) независимо от того, что имена полей в исходном JSON отличаются между `android` и `ios`
- **THEN** плагин показывает текст-сэмпл, отрисованный этим размером, межстрочным интервалом, начертанием и трекингом, вместо сырого JSON-текста

#### Scenario: Значения платформы `web` остаются текстом

- **WHEN** выбранная платформа — `web`
- **THEN** плагин показывает значение токена как текст (как для `color` сегодня — значение как есть), не пытаясь построить специфичное для типа визуальное превью

#### Scenario: Нераспознанная форма значения не ломает список

- **WHEN** значение токена не соответствует ожидаемой для его типа форме (например неизвестный `kind` у `shape`, или структура не совпадает с описанной для `android`/`ios`)
- **THEN** плагин показывает значение как текст, как это происходит для `web` сегодня, вместо падения с ошибкой или пустой строки

#### Scenario: Плагин не пишет в проект пользователя

- **WHEN** пользователь выполняет любое действие в любом экране плагина
- **THEN** плагин MUST NOT создавать директорию `.sdds` в открытом проекте
- **THEN** плагин MUST NOT записывать, изменять или удалять какие-либо файлы открытого проекта
- **THEN** плагин MUST NOT запускать генерацию кода дизайн-системы
