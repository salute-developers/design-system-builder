## Why

Диалог «+» в панели компонентов умеет только возвращать скрытые компоненты: тех, у кого уже есть конфигурация в дизайн-системе. Новый компонент или компонент, которого в дизайн-системе никогда не было, через интерфейс не добавить. Из-за этого дизайн-системы, созданные без компонентов (как сейчас на проде), нельзя наполнить из редактора.

## What Changes

- Новая ручка `GET /api/ds/component-templates`: web-компоненты, для которых в `ds-service` есть шаблон (`component-seeds.json`), с зависимостями по шаблону.
- Существующая ручка `POST /api/ds/design-system-components` получает флаг `fromTemplate`: с ним компонент без конфигурации создаётся в текущем черновике из шаблона вместе с отсутствующими зависимостями, а скрытый компонент лишь восстанавливает связь с прежними настройками. Без флага поведение прежнее.
- Применение шаблона к существующей дизайн-системе: запись шаблонов научится писать в черновик, а не только в базовую версию при создании ДС.
- Диалог «+» показывает и скрытые компоненты, и компоненты с шаблоном, которых в дизайн-системе ещё нет, по группам «Скрытые» и «Новые».
- Крестик и возврат скрытых компонентов не меняются: настройки при скрытии сохраняются.

## Capabilities

### New Capabilities
- `design-system-component-templates`: список шаблонов компонентов и добавление компонента в существующую дизайн-систему из шаблона.

### Modified Capabilities
- `component-catalog-panel`: диалог «+» добавляет новые компоненты из шаблонов вместе с возвратом скрытых.

## Impact

- `backend-kt/ds-service`, `feature-components`: выделение каталога шаблонов и записи шаблона из `GeneratedDesignSystemComponentInitializer`, запись в черновик, сценарий добавления, маршруты, `openapi/documentation.yaml`, интеграционные тесты. Миграций нет.
- `js/apps/client`: `api/componentRepository.ts`, `pages/components/Components.tsx`, `ui/ComponentRestoreDialog.tsx`.
- `frontend-kt`: не затрагивается.
