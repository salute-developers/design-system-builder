## MODIFIED Requirements

### Requirement: Просмотр токенов

Плагин SHALL показывать токены выбранной темы только для чтения в разделах «Цвета», «Типографика», «Размеры» со значениями платформы web. Плагин MUST NOT изменять данные DS Builder. Файл Figma плагин MUST изменять только по явному действию «Экспортировать в Figma».

#### Scenario: Цвета

- **WHEN** открыт раздел «Цвета»
- **THEN** токены `color` и `gradient` MUST показываться по группам с образцом и значением выбранного режима Light или Dark
- **THEN** значения MUST браться разрешёнными из `tenants/{id}/token-values`, а не из глобальной палитры

#### Scenario: Типографика

- **WHEN** открыт раздел «Типографика»
- **THEN** стили MUST показываться по группам и выбранному экрану с размером, высотой строки, весами и семейством

#### Scenario: Размеры

- **WHEN** открыт раздел «Размеры»
- **THEN** радиусы, отступы и тени MUST показываться со значением в px, тени — со слоями

#### Scenario: Значение не разобрано

- **WHEN** значение токена не удалось разобрать
- **THEN** строка MUST показать исходное значение и пометку, а остальные токены MUST показываться

#### Scenario: Просмотр без экспорта

- **WHEN** пользователь открывает разделы и ищет токены, не нажимая «Экспортировать в Figma»
- **THEN** плагин MUST NOT создавать и изменять переменные, стили и узлы документа
