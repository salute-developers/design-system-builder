## Purpose

Закрепить регресс связей палитры, наследования цветов и изоляции значений тем и платформ третьей волной UI E2E.

## ADDED Requirements

### Requirement: Палитровые связи и прозрачность
Набор MUST проверять сохранение ссылки при изменении прозрачности, выборе другой ступени и замене источника растяжки.

#### Scenario: T615 и T777 сохраняют ссылку
- **WHEN** пользователь меняет прозрачность связанного цвета или выбирает другую ступень
- **THEN** сохраняются адрес палитры и выбранная прозрачность после повторного открытия, а исходные ступени не меняются

#### Scenario: T775 заменяет источник
- **WHEN** пользователь заменяет источник растяжки
- **THEN** меняются её цвета, сохраняются ссылки, другие группы неизменны, журнал отражает замену

### Requirement: Удаление растяжек
Набор MUST проверять безопасное удаление с переназначением, отмену удаления и удаление без зависимостей.

#### Scenario: T591 переназначает зависимости
- **WHEN** пользователь выбирает замену и подтверждает удаление связанной растяжки
- **THEN** растяжка удалена, зависимости переназначены, результат сохраняется после перезагрузки

#### Scenario: T606 отменяет удаление
- **WHEN** пользователь отменяет удаление связанной растяжки
- **THEN** палитра, значения токенов и журнал не меняются

#### Scenario: T590 удаляет без зависимостей
- **WHEN** пользователь подтверждает удаление неиспользуемой растяжки
- **THEN** она исчезает, значения токенов и остальные группы сохраняются

### Requirement: Наследование и изоляция
Набор MUST проверять ручную подтему, общий каталог токенов и независимость тем и платформ типографики.

#### Scenario: T783 восстанавливает наследование
- **WHEN** пользователь изменяет подтему вручную, меняет основной цвет и восстанавливает связь
- **THEN** ручной цвет сохраняется до восстановления, затем подтема наследует основной цвет

#### Scenario: T787 создаёт общее определение
- **WHEN** пользователь создаёт цветовой токен в теме A и переходит в B
- **THEN** определение доступно в B, изменения значения A не изменяют значения B

#### Scenario: T698 изолирует темы типографики
- **WHEN** пользователь меняет Body M в A и переходит между A и B
- **THEN** только A сохраняет новое значение, B сохраняет исходное

#### Scenario: T798 изолирует платформы
- **WHEN** пользователь задаёт свой Size iOS, меняет Web и сбрасывает свой Size Android
- **THEN** iOS сохраняет собственный размер, Android снова наследует Web после перезагрузки
