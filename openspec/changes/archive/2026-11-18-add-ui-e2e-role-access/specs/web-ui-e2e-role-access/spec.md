# Ролевые UI E2E

## Purpose

Подтверждать реальные возможности Editor и ограничения Viewer независимыми браузерными сценариями с воспроизводимыми исходными данными.

## ADDED Requirements

### Requirement: Реальные независимые роли

Ролевой набор SHALL использовать отдельные обычные учётные записи Owner и участника; API MUST подтверждать effectiveRole участника до проверяемых UI-действий. Отсутствие credentials MUST завершать подготовку ошибкой, без пропуска теста.

#### Scenario: Подготовка Viewer или Editor

- **WHEN** начинается ролевой сценарий
- **THEN** Owner подготавливает отдельную ДС, а браузер использует сессию другого пользователя с требуемой ролью
- **AND** существующие Owner-тесты не требуют credentials участника

### Requirement: Вторая волна ролевых сценариев

Набор SHALL содержать десять независимых сценариев с полными названиями и ключами T767, T695, T531, T535, T557, T558, T631, T759, T709, T593 из актуального Excel. Наличие файла MUST NOT считаться подтверждением полного покрытия или прохождения.

#### Scenario: Создание и нормализация темы

- **WHEN** Editor создаёт тему Malachite с крайними и повторными пробелами в имени
- **THEN** одна новая тема имеет нормализованное имя, сохраняется после reload и имеет инициализированные Light/Dark без отдельной версии темы

#### Scenario: Изоляция экранов типографики

- **WHEN** Editor меняет Body M крупных экранов на размер 22, высоту 25 и трекинг 0.2em
- **THEN** борд отражает изменения и значения сохраняются после reload
- **AND** средние экраны остаются 15/20/0, мелкие — 14/18/0

#### Scenario: Viewer проекта

- **WHEN** Viewer открывает проект, ДС и цвета темы
- **THEN** данные доступны, управление проектом и создание ДС недоступны, редактор цветов открыт только для чтения

#### Scenario: Прямой URL настроек

- **WHEN** Viewer открывает URL настроек проекта
- **THEN** показано отсутствие доступа, изменяемая форма отсутствует и запросы записи проекта не отправляются

#### Scenario: Viewer темы

- **WHEN** Viewer выбирает textAccent и проверяет редактирование, picker, создание и удаление
- **THEN** мутации недоступны, запросов записи нет и после reload Light=#171717 и Dark=#F5F5F5 сохранены

### Requirement: Достоверность результатов и сохранность данных

Набор MUST сохранять исходные данные проекта, не повторять мутации и не скрывать ошибки подготовки/teardown. При неуспешном сценарии ДС SHALL сохраняться по действующей политике для диагностики.

#### Scenario: Передача запуска пользователю

- **WHEN** агент подготовил код десяти сценариев без их запуска по запросу пользователя
- **THEN** результат обозначается как непроверенный исполнением и передаётся точная команда запуска
- **AND** задачи браузерного прогона остаются открытыми до получения реального отчёта

### Requirement: Права Editor и Viewer в редакторах

Набор SHALL сохранять все согласованные проверки вторых пяти кейсов, включая независимые исходные значения и отсутствие запрещённых запросов записи.

#### Scenario: T558 — Editor редактирует, но не удаляет тему

- **WHEN** Editor меняет Light textAccent в Theme A через UI и подтверждает ввод Enter
- **THEN** сохранение подтверждено не дольше10s, результат переживает reload, Theme B сохраняет исходные значения
- **AND** в меню темы нет удаления, обе темы остаются, DELETE не отправляется

#### Scenario: T631 — Viewer просматривает цветовые токены

- **WHEN** Viewer выбирает textAccent, подтемы, другой токен и согласованную плитку цветов вместо старого Button
- **THEN** Light/Dark и связи доступны для чтения, редактирование/переименование/перетаскивание/создание/удаление недоступны
- **AND** выбор через дерево и борд работает без мутаций и изменения исходных значений

#### Scenario: T759 — Viewer просматривает радиусы, отступы и тени

- **WHEN** Viewer открывает RSS-BASE и последовательно выбирает радиус, отступ и тень
- **THEN** дерево, борд, инспектор и значения доступны, изменяющие поля и действия недоступны
- **AND** выбор через дерево и борд не изменяет данные и редакции; запросы записи отсутствуют

#### Scenario: T709 — Viewer просматривает типографику

- **WHEN** Viewer открывает Body M с FIX-BASE, включая собственный Size iOS=17 при web=16 на крупных экранах
- **THEN** дерево, борд, инспектор и собственные значения доступны для чтения
- **AND** Size, Line Height, Letter Spacing, Font Family и Weight недоступны для изменения; исходные значения и редакции сохраняются

#### Scenario: T593 — Viewer просматривает палитру и подготовленные связи

- **WHEN** Viewer выбирает Accent Green/Hue130 #500 с подготовленной связью семантического токена
- **THEN** данные и подготовленная связь видны, поиск Green и его очистка работают, переход открывает связанный токен
- **AND** количество связей может быть любым, фиксированное число восемь не требуется по согласованию пользователя от 18.11.2026
- **AND** после возврата в палитру изменяющие действия скрыты или недоступны, мутаций и изменения данных нет
