# Вторая волна UI E2E: Editor и Viewer

## Зачем

Прежний набор работал преимущественно под Owner и не подтверждал права Editor и ограничения
Viewer. Вторая волна добавляет десять независимых сценариев проектов, тем и редакторов токенов.

## Что меняется

- Настоящие Owner/member-сессии, подтверждённые сервером роли и изолированная подготовка данных.
- Десять сценариев: T767, T695, T531, T535, T557, T558, T631, T759, T709, T593.
- API helpers и Page Objects для актуальных project-scoped маршрутов, готовности UI и наблюдения записей.
- README/ROADMAP и публичный пример конфигурации для двух учётных записей.

## Возможность

- `web-ui-e2e-role-access`: реальные роли Editor/Viewer, просмотр, разрешённое редактирование и запрет мутаций.

## Границы

Продуктовые UI, API, ролевая политика и backend не меняются. Версии зависимостей, Strictacode
baseline/thresholds/policy и глобальные E2E timeout/retries не меняются. Диагностические данные и
credentials остаются вне Git. Сценарии используют собственные ДС; проект и ролевое членство
выделенной тестовой учётки переиспользуются. Неуспешная попытка сохраняет ДС по действующей политике.

## Итоговая проверка

Пользователь подтвердил прохождение полного набора: 30/30 E2E.
Агент выполнил types/discovery, OpenSpec validation, Strictacode и штатные FAST/FULL JavaScript-контура.
CLI: 95/95 unit; Figma-плагин: 150/150 тестов в 11 файлах; сборки прошли.

Примечание к проверкам: FAST/FULL ранее прошли с Windows-фиксами CLI. Эти фиксы и подъём
версии убраны; исходный CLI проверен отдельно в WSL: typecheck и 95/95 тестов прошли.
FAST/FULL после отката целиком не повторялись. Логи: outputs/cli-wsl-original-2026-11-18/.
