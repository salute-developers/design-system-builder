## MODIFIED Requirements

### Requirement: Выбор цвета: вид значения, «Вручную», «Палитра» и редактор градиента

Выбор цвета SHALL открываться у поля значения и SHALL содержать переключатель вида значения ▣ / ◇, вкладки
«Вручную» и «Библиотека» для цвета и редактор градиента для градиента. Выбор цвета SHALL NOT показывать элементы без
действия.

#### Scenario: Вкладка «Вручную»

- **WHEN** пользователь двигает поле насыщенности и яркости, ползунок тона или прозрачности
- **THEN** превью MUST обновляться во время движения, а значение MUST записываться и ставиться в очередь
  автосохранения при отпускании
- **THEN** стрелки клавиатуры на ползунках MUST менять значение и ставить его в очередь автосохранения
- **THEN** под ползунками MUST быть переключатель формата Hex, RGB или HSL и поля значения в выбранном формате: одно
  поле HEX или три поля каналов; каждое поле MUST принимать ввод, а HEX MUST копироваться в буфер обмена

#### Scenario: Тон белого, чёрного и почти серого цвета

- **WHEN** указатель поля стоит в левом верхнем или левом нижнем углу, и пользователь двигает ползунок тона
- **THEN** после записи ползунок тона MUST остаться там, где его отпустили, хотя HEX такого цвета не хранит тон
  точно; положение восстанавливается из HEX только после изменения цвета извне

#### Scenario: Вкладка «Библиотека»

- **WHEN** пользователь открывает вкладку «Библиотека»
- **THEN** вкладка MUST показать растяжки палитры темы со ступенями, вычисленными для группы палитры токена
- **THEN** выбор ступени MUST записать ссылку `[type.shade.step]` с текущей прозрачностью
- **THEN** поиск MUST фильтровать растяжки по имени

#### Scenario: Градиентное значение

- **WHEN** пользователь открывает градиентное значение
- **THEN** выбор цвета MUST открыться в режиме градиента с типом, геометрией и стопами значения
- **THEN** переключатель ▣ / ◇ MUST менять вид только этого значения
- **THEN** строка стопа MUST показывать HEX и прозрачность целиком, без обрезки

#### Scenario: Элементы без действия

- **WHEN** открыт выбор цвета
- **THEN** выбор MUST NOT показывать отключённый вид заливки и значки, которые ничего не делают

#### Scenario: Закрытие

- **WHEN** пользователь нажимает Escape, кнопку закрытия или щёлкает вне выбора цвета
- **THEN** выбор цвета MUST закрыться, а фокус внутри него MUST оставаться до закрытия

### Requirement: Дерево показывает хранимые группы и подгруппы

Дерево SHALL строиться по группам и подгруппам токенов дизайн-системы (`GET …/token-groups?kind=color`) в их хранимом порядке. Токены SHALL располагаться в своей группе или подгруппе по `position`. Группы и подгруппы без токенов SHALL показываться.

#### Scenario: Строка токена

- **WHEN** дерево показывает токен
- **THEN** строка MUST содержать отображаемое имя и чип, верхняя половина которого — цвет Light, нижняя — Dark
- **THEN** выбор строки MUST открыть токен в инспекторе и прокрутить канвас к его свотчу

#### Scenario: Группы и подгруппы

- **WHEN** у дизайн-системы есть группа Text & Icons с подгруппами Accent и Status и токеном прямо в группе
- **THEN** дерево MUST показать заголовок группы, под ним токены группы без подгруппы, затем заголовки подгрупп с их токенами

#### Scenario: Пустая группа

- **WHEN** у группы или подгруппы нет токенов
- **THEN** дерево MUST показать её заголовок без строк токенов

#### Scenario: Токен без группы

- **WHEN** у токена `groupId` равен `null`
- **THEN** дерево MUST показать его в подгруппе «Без группы» группы, код которой совпадает с первым сегментом имени, а если такой группы нет — в конце дерева

#### Scenario: Сортировка

- **WHEN** пользователь выбирает «А–Я»
- **THEN** токены внутри группы или подгруппы MUST быть упорядочены по отображаемому имени
- **WHEN** пользователь выбирает «Исходные»
- **THEN** группы, подгруппы и токены MUST быть в хранимом порядке

#### Scenario: Поиск

- **WHEN** пользователь вводит строку поиска
- **THEN** дерево MUST показать плоским списком без заголовков групп и подгрупп токены, имя или отображаемое имя
  которых содержит строку без учёта регистра
- **THEN** при пустом результате MUST показываться пустое состояние «По вашему запросу ничего не найдено»

#### Scenario: Фильтр проблем

- **WHEN** пользователь включает фильтр — кнопку с подсказкой «Только токены с ошибками» (в прототипе подсказки нет)
- **THEN** дерево MUST показать только токены, у которых хотя бы одно значение Light, Dark или подтемы не проходит проверку значения

#### Scenario: Сворачивание

- **WHEN** пользователь сворачивает группу или подгруппу
- **THEN** её содержимое MUST скрыться, а состояние MUST сохраниться после перезагрузки страницы
