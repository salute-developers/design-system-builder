## Контекст

Изменение продолжает `add-figma-token-export` и `update-figma-export-states-and-copy`. Plugin API позволяет привязать цвет стопа градиента (`ColorStop.boundVariables.color`) и сплошной заливки к цветовой переменной, поэтому градиент может зависеть от режима коллекции, как обычный цвет.

## Решения

### Стопы градиентов — переменные темы

Для каждого градиентного токена план создаёт в `01. Theme` переменные `GradientStops/<имя переменной темы>/Stop N` для стопов и `…/Fill N` для сплошных слоёв, нумерация сквозная по слоям сверху вниз. Значения режимов `Light` и `Dark` — цвета стопов из значений web. Имя строится по токену, а не по группе, как в образце: у темы несколько градиентов в одной группе. Области применения пустые, как у остальных переменных темы.

Стиль заливки один на токен, по имени переменной темы, например `Surfaces/Default/Accent/Solid/AccentGradient`. Его стопы и сплошные слои привязаны к переменным, поэтому стиль показывает цвет того режима, который выбран у фрейма. Угол и позиции стопов не привязываются к переменным в Figma, поэтому берутся из Light.

Одним стилем градиент описывается, только если в Light и Dark совпадают число слоёв, тип каждого слоя, угол и число стопов, а позиции отличаются не больше чем на 0,01 (`99.688%` и `100%` считаются одним стопом). Иначе остаётся пара стилей `Light/…` и `Dark/…` со значениями без переменных и причиной в отчёте.

Ключ единого стиля — `gradient:<tokenId>`. Прежние пары стилей с ключами `gradient:<tokenId>:light|dark` при повторном экспорте считаются устаревшими и не удаляются.

### Архив недостающих шрифтов

`exportSource` дополнительно читает значения `fontFamily`. В них для iOS и Android уже лежат ссылки на файлы `.otf` с насыщенностью и начертанием. План получает `fontFiles`: семейство, насыщенность, начертание и ссылку, только для семейств, которые используются в типографике. Основной поток по-прежнему собирает `missingFonts`, а окно для недостающих семейств показывает инструкцию и одну кнопку «Скачать шрифты одним архивом (ZIP)». Плагин не устанавливает шрифты: у плагинов Figma нет доступа к файловой системе.

Файлы качает общее Kotlin-ядро (`DsBuilderCore.fontFile`): спецификация окна запрещает `fetch` в коде на TypeScript. Запрос идёт без `Authorization` и только по `https`. Архив без сжатия (метод STORE) собирает основной поток: код архиватора не увеличивает окно, размер которого ограничен. Имена путей в архиве очищаются от `..` и разделителей, повторы нумеруются. Неполный архив не сохраняется: отчёт называет нескачанные файлы, и кнопку можно нажать снова.

## Риски / Компромиссы

- [Позиции стопов в Light и Dark немного различаются] → берутся из Light при расхождении до 0,01; заметное расхождение оставляет пару стилей.
- [Устаревшие пары стилей остаются в файле после перехода на единый стиль] → отчёт считает их устаревшими; привязанные к ним слои дизайнер переключает на новый стиль.
- [Ссылки на шрифты ведут на внешний CDN] → домен `cdn-app.sberdevices.ru` разрешён в манифесте; ядро принимает любой адрес `https`, ограничение держит манифест. Шрифт на другом хосте Figma заблокирует, и отчёт покажет, что файл недоступен: такой хост нужно добавить в манифест.
