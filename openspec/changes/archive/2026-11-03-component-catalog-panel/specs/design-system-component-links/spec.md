## ADDED Requirements

### Requirement: Скрытый компонент остаётся доступным для чтения

`GET /api/ds/components` SHALL возвращать компонент с оформлением в дизайн-системе проекта, даже если все его связи удалены. `GET /api/ds/design-systems/{id}/appearances` MUST продолжать возвращать оформления скрытых компонентов. Право записи MUST NOT расширяться.

#### Scenario: Скрыт во всех дизайн-системах проекта

- **WHEN** обычный пользователь запрашивает `/components` после скрытия компонента во всех дизайн-системах проекта
- **THEN** запись MUST присутствовать в ответе.

#### Scenario: Чужой проект

- **WHEN** компонент связан только с дизайн-системой другого проекта
- **THEN** запись MUST NOT присутствовать в ответе.

### Requirement: Восстановление скрытой связи

`POST /api/ds/design-system-components` и импорт конфигурации SHALL восстанавливать удалённую связь с опубликованной историей новой ревизией прежней записи, а связь без истории создавать заново. Для активной связи запрос MUST возвращать её же.

#### Scenario: Возврат связи с опубликованной историей

- **WHEN** связь из опубликованной версии удалена и создаётся снова
- **THEN** сервис MUST вернуть успешный ответ с прежним `id`.

#### Scenario: Возврат связи без истории

- **WHEN** связь, созданная в текущем черновике, удалена и создаётся снова
- **THEN** сервис MUST вернуть успешный ответ с новой связью.

#### Scenario: Импорт в скрытый компонент

- **WHEN** импорт конфигурации затрагивает скрытый компонент
- **THEN** импорт MUST завершиться успешно и связь MUST стать активной.

### Requirement: Скрытый компонент не выгружается

Выгрузка конфигурации дизайн-системы MUST NOT содержать компоненты со скрытой связью.

#### Scenario: Экспорт после скрытия

- **WHEN** компонент скрыт и запрошена выгрузка `component-config/export`
- **THEN** ответ MUST NOT содержать этот компонент.
