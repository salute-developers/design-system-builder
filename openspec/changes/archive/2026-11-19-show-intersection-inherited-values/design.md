## Context

Источник правки при двух выбранных стилях и больше — пересечение. Модель строк (`collectProperties`) берёт значения только из записи пересечения ровно этих стилей. Превью (`composePreview/draft.ts`) собирает значения иначе: стили выбранных вариаций в порядке модели, затем пересечения, все стили которых выбраны, от меньших к большим.

## Goals / Non-Goals

**Goals:**
- Инспектор пересечения показывает значения выбранных стилей и пересечений так, как их применяет превью.
- Видно, какое значение задано на пересечении, а какое унаследовано, и откуда.

**Non-Goals:**
- Инвариант и одиночный стиль: их строки не меняются.
- Инварианты в значениях пересечения: превью накладывает их отдельно, в источник правки пересечения они не входят.

## Decisions

- **Правило приоритета — порядок дерева.** Значения стилей выбранных вариаций в порядке уровней дерева «Структуры» (порядок модели, цветовая схема `view` последней), более поздняя вариация перекрывает раннюю; затем пересечения из выбранных стилей по возрастанию числа стилей; последним — само пересечение. Сейчас превью (`composePreview/draft.ts`) берёт порядок модели без переноса `view` в конец; оно переходит на ту же общую функцию, поэтому инспектор и превью не расходятся. Тот же порядок задаёт и списки «Вариаций».
- **Общая функция слияния.** `resolveSelectedProps(config, styleIDs: string[]): Map<propertyId, { prop: PropUnion; from: PropertySource }>` в модели: стили — в порядке дерева, затем пересечения, все стили которых входят в `styleIDs`, по возрастанию числа стилей. Превью передаёт ID стилей своего выбора (с подставленными стилями по умолчанию) и проецирует `prop` как раньше; инспектор передаёт стили, выбранные в «Вариациях», и берёт `from` для подсказки. Порядок дерева — одна функция `variationOrder(config)`: вариации модели, цветовая схема (`view` по имени каталога) последней; ей же пользуются списки «Вариаций».
- **Унаследованная строка.** У строки появляется источник значения `inheritedFrom` — подпись стиля (`size: m`) или пересечения. Такая строка не считается заданной в источнике (`isSet = false`): сброса нет, первое значение пишется в пересечение прежней операцией. `inheritedFrom` — поле `InspectorProperty`, оно доходит до строки и до фильтра. Ссылки на стили, свойства Behaviour и состояния цвета у унаследованной строки только для чтения: у пересечения для них нет операций записи. Значение показывается в поле; подпись получает подсказку `<подпись> · <источник значения>` и приглушённый цвет.
- **Фильтр.** Видимы строки `isSet || inheritedFrom`.

## Risks / Trade-offs

- [Одно свойство задано в двух выбранных стилях] → действует стиль вариации, которая ниже в дереве; источник видно в подсказке.
- [Превью дополнительно рисует стили по умолчанию невыбранных вариаций, пересечения с ними и инварианты] → инспектор их не показывает: они не входят в выбор; оговорено в спеке.
- [Перекрытие цвета на пересечении снимает состояния стиля: у пересечения нет записи состояний] → оговорено в спеке; запись состояний пересечения — отдельная задача.
- [У старых конфигураций `view` стоит в модели не последней] → превью раньше применяло её значения раньше других; теперь — последними, как показывает дерево.
