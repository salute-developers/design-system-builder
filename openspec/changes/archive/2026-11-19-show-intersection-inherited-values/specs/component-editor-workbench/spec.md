## MODIFIED Requirements

### Requirement: Свойства сочетания по секциям

Вкладка «Стилизация» SHALL показывать под «Variants» свойства компонента со значениями источника правки (инварианта, стиля или пересечения); у пересечения — с действующими значениями по требованию «Значения пересечения с учётом выбранных стилей». Каждое свойство MUST показываться одной строкой: значения других источников MUST NOT показываться отдельными строками.

Свойства типа `value` (сырой CSS) SHALL показываться текстовым полем без единиц: значение отображается и сохраняется строкой как введено, без приведения; пустой ввод не сохраняется. Секция такого свойства определяется по имени: `color` или `background` в имени — Color, имя оканчивается на `width` или `height` — Size, `radius` — Appearance, остальное — Layout.

Свойства SHALL раскладываться по секциям по правилу, которое проверяется сверху вниз (первое совпадение определяет секцию):

| Порядок | Условие | Секция |
|---|---|---|
| 1 | `shadow` или `shadow`/`blur` в имени | Effects |
| 2 | `shape` или `radius` в имени | Appearance |
| 3 | `border`, `outline` или `stroke` в имени | Border |
| 4 | `color`, а также `opacity` или `alpha` в имени | Color |
| 5 | `typography` | Text |
| 6 | имя оканчивается на `width` или `height` | Size |
| 7 | остальные `dimension` и `float` | Layout |
| 8 | остальные типы (`component_style`, `icon`, `boolean`, `integer`) | дополнительная группа |

Секции SHALL идти в порядке Size, Layout, Color, Text, Border, Appearance, Effects. Секция без строк MUST NOT показываться. Секции SHALL сворачиваться; по умолчанию они развёрнуты.

Строки внутри секции SHALL идти в порядке Width, Height, Padding, Radius, Typography, Background, Text, Icon, затем остальные по алфавиту подписи. Подпись — имя свойства, разбитое на слова, с заглавной буквы. При наведении на подпись SHALL показываться подсказка `<подпись> · <источник значения>`, где источник — «Инвариант», `<вариация>: <стиль>` или стили пересечения через ` · `. У значения, унаследованного пересечением, это источник самого значения, а не источник правки.

Внешний вид секций, строк и полей SHALL совпадать с прототипом: заголовок секции 32 px со стрелкой, ширина подписи `min(34%, 220px)`, поля высотой 24 px на фоне `#383a40` с рамкой `#474a51`.

#### Scenario: Цвет фона Chip

- **WHEN** у `Chip` выбрано только `view = default`, и цвет фона задан в стиле `default` вариации `view`
- **THEN** в секции Color MUST быть строка `Background` со значением-токеном и образцом цвета
- **THEN** подсказка подписи MUST быть `Background · view: default`

#### Scenario: Отступы и типографика

- **WHEN** выбран только стиль `size: m`, и у него есть `dimension`-свойство `padding` и `typography`-свойство
- **THEN** `padding` MUST показываться в секции Layout
- **THEN** типографика MUST показываться в секции Text

#### Scenario: Свойство одной строкой

- **WHEN** `height` задан и в инварианте, и в стиле `size: m`, и выбран только `size: m`
- **THEN** `Height` MUST показываться одной строкой со значением стиля `size: m`

#### Scenario: Сырой CSS Avatar

- **WHEN** у стиля `size: xxl` Avatar `avatarSize` равно `6.25rem`, и в «Variants» выбран только `size: xxl`
- **THEN** в секции Layout MUST быть строка `Avatar size` со значением `6.25rem` без `px`
- **WHEN** пользователь вводит `calc(100% - 1.50rem)` и нажимает `Enter`
- **THEN** значение MUST сохраниться строкой `calc(100% - 1.50rem)` без изменений

### Requirement: Все свойства источника видны, незаданные — пустыми

Инспектор SHALL показывать для любого источника правки один и тот же список свойств — все свойства API компонента. Связи свойств с вариациями SHALL загружаться для web- и Compose-компонентов и использоваться для привязки: первое значение непривязанного свойства в стиле SHALL привязывать свойство к вариации стиля.

Строка свойства SHALL быть в одном из трёх состояний: задана в источнике правки, унаследована (только у пересечения: значение из выбранного стиля или меньшего пересечения) или пуста. Пустое свойство SHALL показываться в своей секции пустой строкой того же контрола: пустое поле цвета с подписью «Не задано», пустое число, «Выбрать значение…» у токена, «Выбрать стиль» у типографики. Пустое значение MUST NOT сохраняться и MUST NOT попадать в превью. Ввод значения в пустую строку SHALL добавлять свойство в источник и сохранять его.

У заданного свойства SHALL быть действие «Очистить значение». Оно удаляет значение из источника, и строка снова становится пустой или, у пересечения, унаследованной. У унаследованного свойства действия «Очистить значение» MUST NOT быть: его можно только перекрыть значением пересечения.

Ссылки на стили показываются только заданными или унаследованными, в секции Nested styles; свойства без секции — в сворачиваемой дополнительной группе Behaviour.

В заголовке каждой секции и дополнительной группы SHALL быть фильтр «Показывать только заполненные свойства», по умолчанию включённый: пустые строки скрыты, пока пользователь не выключит фильтр секции; заданные и унаследованные строки фильтр не скрывает. Переключатель «Показать все свойства» MUST NOT показываться.

#### Scenario: Новый стиль вариации

- **WHEN** пользователь добавил стиль `xxxs` в вариацию `size` и выбрал только его в «Variants»
- **THEN** после выключения фильтра секции все свойства компонента MUST показываться в своих секциях пустыми строками с источником `size: xxxs`
- **THEN** сервер MUST NOT получать значений, пока пользователь их не задал

#### Scenario: Заполнение пустого свойства

- **WHEN** пользователь вводит `40` в пустое поле Height с источником `size: xxxs`
- **THEN** свойство `height` MUST добавиться в стиль `xxxs` со значением `40` и сохраниться

#### Scenario: Очистка значения

- **WHEN** пользователь выбирает «Очистить значение» у Height со значением `40`
- **THEN** значение MUST удалиться из источника, а строка Height MUST остаться пустой

#### Scenario: Только заполненные

- **WHEN** пользователь выбирает стиль `size: m`
- **THEN** секции MUST показывать только заданные свойства, фильтр каждой секции MUST быть включён
- **WHEN** пользователь выключает фильтр секции Layout
- **THEN** в Layout MUST появиться пустые строки остальных свойств

#### Scenario: Нет дубля секции Color

- **WHEN** у источника правки нет ссылок на стили и иконок
- **THEN** дополнительные группы MUST NOT показываться

#### Scenario: Компонент без связей

- **WHEN** открыт компонент, у свойств API которого нет вариаций, и у стиля `size: m` задан `height`
- **THEN** при выбранном только `size: m` `Height` MUST показываться одной строкой с источником `size: m`

#### Scenario: Связь по имени вариации

- **WHEN** свойство `padding` связано с вариацией `size` по имени, а стиль `m` вариации `size` не задаёт `padding`
- **THEN** при выбранном только `size: m` и выключенном фильтре Layout `Padding` MUST показываться пустой строкой с источником `size: m`, привязанной к вариации

#### Scenario: Одинаковый список свойств

- **WHEN** пользователь переключает выбор с `size: m` на `view: accent`, затем на их пересечение
- **THEN** при выключенных фильтрах набор строк в секциях MUST оставаться прежним, меняются только значения

## ADDED Requirements

### Requirement: Значения пересечения с учётом выбранных стилей

Когда источник правки — пересечение, инспектор SHALL показывать действующие значения по правилу приоритета: значения стилей, выбранных в «Variants», в порядке уровней дерева «Структуры» (вариации в порядке модели, цветовая схема `view` последней), причём значение более поздней вариации перекрывает более раннее; поверх них — значения пересечений, все стили которых входят в выбранные, от меньших к большим; последним — значения самого пересечения. Превью SHALL применять значения выбранных стилей и пересечений по тому же правилу (требование «Пересечения в модели редактора»). Стили по умолчанию невыбранных вариаций, пересечения с ними и инварианты превью накладывает дополнительно; инспектор пересечения их MUST NOT показывать.

Значение, заданное на самом пересечении, SHALL показываться заданным: со сбросом, подсказка подписи — `<подпись> · <стили пересечения>`. Значение из стиля или меньшего пересечения SHALL показываться унаследованным: без сброса, подсказка подписи называет его источник (`<вариация>: <стиль>` или стили меньшего пересечения). У редактируемых типов новое значение в такой строке MUST записываться в пересечение; пустой ввод MUST NOT ничего записывать, и поле SHALL вернуть унаследованное значение. Унаследованные ссылки на стили, свойства группы Behaviour и состояния цвета SHALL показываться только для чтения. Значение пересечения заменяет свойство стиля целиком: состояния цвета стиля после перекрытия на пересечении MUST NOT действовать. Фильтр «только заполненные» SHALL скрывать только строки без значения.

Для инварианта и одного выбранного стиля SHALL показываться только их собственные значения.

#### Scenario: Только size

- **WHEN** в `size = m` заданы `height = 100`, `width = 200`, в `view = default` — `background = red`, `textColor = white`, на пересечении `size = m` + `view = default` — `textColor = green`, и выбран только `size = m`
- **THEN** `width` MUST быть 200, `height` — 100, `background` и `textColor` MUST быть не заданы

#### Scenario: Только view

- **WHEN** при тех же значениях выбран только `view = default`
- **THEN** `background` MUST быть `red`, `textColor` — `white`, `width` и `height` MUST быть не заданы

#### Scenario: Пересечение

- **WHEN** при тех же значениях выбраны `size = m` и `view = default`
- **THEN** `width` MUST быть 200, `height` — 100, `background` — `red`, `textColor` — `green`
- **THEN** `textColor` MUST быть заданным на пересечении с подсказкой `Text color · size: m · view: default`, а `width`, `height`, `background` — унаследованными с подсказками `Width · size: m`, `Height · size: m`, `Background · view: default`

#### Scenario: Приоритет по дереву

- **WHEN** в дереве `Button` вариации идут `shape`, `size`, `view`, `padding` задан и в `shape = pilled`, и в `size = m`, и выбраны `shape = pilled` и `size = m`
- **THEN** инспектор и превью MUST использовать `padding` из `size = m`
- **WHEN** пользователь переставляет вариации в дереве на `size`, `shape`, `view`
- **THEN** инспектор и превью MUST использовать `padding` из `shape = pilled`

#### Scenario: Цветовая схема последней

- **WHEN** `textColor` задан и в `size = m`, и в `view = default`, и выбраны оба стиля
- **THEN** MUST действовать `textColor` из `view = default`

#### Scenario: Перекрытие унаследованного значения

- **WHEN** выбрано то же пересечение, и пользователь меняет унаследованный `background` на `blue`
- **THEN** `blue` MUST записаться в пересечение, а стиль `view = default` MUST сохранить `red`

#### Scenario: Унаследованные состояния цвета

- **WHEN** у `background` стиля `view = default` есть состояние `hovered`, и выбрано пересечение `size = m` + `view = default`
- **THEN** строка `Background` MUST показывать унаследованное значение и состояние `hovered` только для чтения
- **WHEN** пользователь задаёт `background` на пересечении
- **THEN** состояние `hovered` стиля MUST перестать действовать на пересечении

#### Scenario: Стиль по умолчанию не показывается

- **WHEN** у `Button` выбраны `size = m` и `view = default`, а `shape` — «Все варианты», и у стиля `shape` по умолчанию задан `radius`
- **THEN** инспектор MUST NOT показывать `radius` унаследованным, хотя превью рисует его

#### Scenario: Фильтр пересечения

- **WHEN** выбрано то же пересечение и включён фильтр «только заполненные»
- **THEN** MUST показываться `width`, `height`, `background`, `textColor`, а свойства без значения MUST скрываться
