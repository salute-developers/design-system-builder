## MODIFIED Requirements

### Requirement: Flags and defaults in the editor

Редактор SHALL показывать вариацию-флаг переключателем в секции «Variants» инспектора и SHALL позволять снимать стиль по умолчанию у вариации из её меню в «Variants».

#### Scenario: Флаг переключается

- **WHEN** вариация имеет единственный стиль `true`
- **THEN** секция «Variants» инспектора MUST показывать её переключателем
- **THEN** включённый флаг MUST передавать компоненту булев проп `true`, выключенный — не передавать проп

#### Scenario: Дефолт снимается

- **WHEN** выбранный стиль вариации стоит по умолчанию
- **THEN** меню вариации в «Variants» MUST предлагать «Снять по умолчанию»
- **THEN** после снятия вариация MUST остаться без стиля по умолчанию и не попадать в `defaults` конфига
