## ADDED Requirements

### Requirement: Значение свойства компонента подписывается свойством и местом

Поле изменённого значения в записи значения свойства компонента (вариационного или инвариантного) SHALL подписываться именем свойства и местом значения вместо «Значение». Подпись строится как `<свойство> · <место>[ · <состояния>]`:

- место — `<вариация>: <стиль>` для значения стиля и «Инвариант» для значения инварианта;
- состояния — имена состояний набора через ` + ` в порядке `focused`, `pressed`, `hovered`; базовый набор без состояний не пишется;
- имя свойства — как в инспекторе компонента: имя разбито на слова, первое — с заглавной буквы.

Смена токена значения (путь `token_id`) SHALL показываться тем же полем с именами прежнего и нового токена; если токена нет, показывается сырое значение. Такое поле отменяется только записью целиком.

Неизвестные части MUST пропускаться без вывода идентификаторов. Если неизвестны ни свойство, ни место, подпись MUST остаться «Значение».

#### Scenario: Значение стиля вариации

- **WHEN** в журнале запись изменения значения свойства `accordionGap` стиля `m` вариации `size` с `2` на `32`
- **THEN** поле MUST быть подписано «Accordion gap · size: m» с прежним значением `2` и новым `32`

#### Scenario: Значение инварианта

- **WHEN** в журнале запись изменения инвариантного значения свойства `disableAlpha`
- **THEN** поле MUST быть подписано «Disable alpha · Инвариант»

#### Scenario: Значение состояния

- **WHEN** изменилось значение свойства `background` стиля `default` вариации `view` для набора состояний `pressed`, `hovered`
- **THEN** поле MUST быть подписано «Background · view: default · pressed + hovered»

#### Scenario: Имя свойства неизвестно

- **WHEN** свойства записи нет в метаданных журнала, а стиль и вариация известны
- **THEN** поле MUST быть подписано «size: m» без идентификатора свойства

#### Scenario: Смена токена

- **WHEN** у значения свойства `background` стиля `default` вариации `view` сырое значение `#000000` заменено токеном `surface.default.accent`
- **THEN** запись MUST показать поле «Background · view: default» с прежним значением `#000000` и новым `surface.default.accent`
