## Why

В журнале правка значения свойства компонента выглядит как «Изменение компонента «Accordion»» с полем «Значение» и парой «2 → 32». Непонятно, какое свойство поменялось, в каком стиле какой вариации и для какого состояния. Несколько подряд идущих правок одного компонента не различить, а значит, нельзя уверенно отменить нужную.

Все данные для понятной подписи уже есть:

- в записи журнала значения свойства сервер передаёт `property_id`, `style_id` (у значения вариации) и `state_set_id`;
- клиент при открытии журнала уже читает имена свойств, вариаций и стилей (`loadJournalComponentMetadata`).

Не хватает только связи «стиль → вариация» и имён состояний набора.

## What Changes

- Поле изменённого значения в записи значения свойства подписывается свойством и местом значения вместо «Значение»:
  - `Accordion item gap · size: m` — значение стиля вариации;
  - `Disable alpha · Инвариант` — значение инварианта;
  - `Background · view: default · hovered` — значение с набором состояний; базовый набор не пишется.
- Смена токена значения (например, цвета), которую журнал сейчас не показывает вовсе, показывается тем же полем с именами токенов.
- Имя свойства пишется так же, как в инспекторе компонента: имя разбито на слова, первое — с заглавной буквы.
- Если имя свойства, стиля или состояния неизвестно, подпись использует то, что известно, и не показывает идентификаторы. Если неизвестно ничего, остаётся «Значение».
- `loadJournalComponentMetadata` дополнительно читает `/states` и `/state-sets` и запоминает вариацию стиля.
- Заголовок записи («Изменение компонента «Accordion»»), отмена и переход к источнику не меняются.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities
- `design-system-version-journal-ui`: появляется требование подписывать изменённое значение свойства компонента именем свойства и местом значения.

## Impact

- `js/apps/client`:
  - `api/journalComponentMetadata.ts` — вариация стиля и имена наборов состояний;
  - `features/versionJournal/journalPresenter.ts` — подпись полей значения свойства;
  - тесты презентера и метаданных.
- `backend-kt`, `frontend-kt`: не затрагиваются; контракт журнала не меняется.
