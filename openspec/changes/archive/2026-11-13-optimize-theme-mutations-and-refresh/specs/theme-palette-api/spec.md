## ADDED Requirements

### Requirement: Раскрытие ссылок не требует представления палитры
Чтение значений SHALL раскрывать ссылки с сохранением групп, источников, ступеней, прозрачности и исторической границы без вычисления связей и счётчиков интерфейса палитры.

#### Scenario: Замена источника и ступени
- **WHEN** ссылка использует заменённый источник или переопределённую ступень группы
- **THEN** результат MUST совпасть с раскрытием по полной палитре на той же границе

#### Scenario: Нераскрываемая ссылка
- **WHEN** источник или ступень отсутствует
- **THEN** ответ MUST сохранить прежнее поведение для нераскрываемой ссылки

### Requirement: Инспектор получает области связей одним чтением
Инспектор SHALL получать связи слота для общей области и выбранной группы одним чтением без повторного формирования полной палитры.

#### Scenario: Слот используется несколькими группами
- **WHEN** слот связан с токенами разных групп
- **THEN** общая область MUST содержать все связи, область группы MUST содержать только её связи
