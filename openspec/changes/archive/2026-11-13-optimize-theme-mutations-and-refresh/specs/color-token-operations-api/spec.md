## ADDED Requirements

### Requirement: Пакетная запись сохраняет независимость предметных редакций
Сохранение значений семейства SHALL атомарно проверять каждую переданную редакцию и возвращать подтверждённые значения и итоговый тип без повторения общей подготовки для каждого значения.

#### Scenario: Устаревшее основание обычной записи
- **WHEN** один адрес изменён конкурентно по пересекающемуся пути
- **THEN** сервер MUST сохранить прежнее поведение записи с предупреждением для этого адреса в метаданных

#### Scenario: Недопустимое значение пакета
- **WHEN** одно из значений нарушает предметные ограничения
- **THEN** сервер MUST отклонить весь пакет без частичной записи

#### Scenario: Разные основания значений
- **WHEN** пакет содержит разные базовые редакции, пути, платформы и режимы
- **THEN** сервер MUST проверить каждый адрес отдельно, сохранить непереданные значения и пересчитать тип по всем темам
