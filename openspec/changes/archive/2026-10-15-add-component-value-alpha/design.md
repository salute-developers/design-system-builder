## Context

Колонка `alpha` (`text`) есть в `invariant_property_values`, `variation_property_values` и `style_combinations`; значение
хранится в том виде, в каком пришло из конфигурации (`0.2`). Выгрузка `db/export/componentExport.ts` отдаёт его числом
(`Number(row.alpha)`). Читающий маршрут `legacy.ts` строит `PropConfig` без `alpha`: для значения он добавляет только
`adjustment`. Клиент собирает `PropConfig` в `Prop` (поля `value`, `adjustment`, `states`), а `draft.ts` переносит в
черновик поля `alpha` у свойства и у записей состояний, но `projectProperty` их не заполняет. Ассемблер накладывает
`alpha` на источники `literal` и `tokenRef` (`withAlpha`).

## Проверено на данных

- В базе `alpha` задан у инвариантов `Avatar.background` (0.2, градиент), `Editable` (0.4), `TextField`, `TextArea` (0.4)
  и у значений вариаций `Spinner` (0.32), `TextField` и `TextArea` `backgroundColor` (0.4).
- Колонка текстовая; в корпусе значения числовые.
- Плагин для токена-градиента `alpha` игнорирует: `brushValue` накладывает его только на сплошной цвет.

## Decisions

1. **Формат в API.** Число в поле `alpha` рядом с `value`: `{ id, value, alpha }`; у записи состояния `{ state, value, alpha }`.
   Так же `alpha` отдаёт выгрузка, поэтому формат уже знаком потребителям. Нечисловое или пустое значение колонки
   пропускается, а не превращается в `NaN`.
2. **Где добавляется.** Во всех четырёх местах `legacy.ts`: инварианты, базовое значение вариации, значение состояния,
   значение сочетания.
3. **Клиент.** `PropConfig` и `State` получают необязательное `alpha: number`; `Prop` хранит его и отдаёт
   (`getAlpha`); `projectProperty` переносит его в черновик, в том числе у записей состояний. Остальные потребители
   модели `alpha` не читают, поэтому web-превью не меняется.
4. **Ассемблер.** Менять не нужно: `withAlpha` уже накладывает `alpha` на `literal` и `tokenRef` (градиентный токен —
   это `tokenRef`).
5. **Плагин.** Градиентная кисть оборачивается в `Brush`, который умножает прозрачность (парный change).

## Risks / Trade-offs

- Значения, у которых `alpha` вне 0..1, ассемблер отклоняет диагностикой `incompatible_value`; в корпусе таких нет.
- Без обновлённого плагина `alpha` для градиентов игнорируется, а для сплошных цветов уже применяется: поведение
  меняется у `Editable`, `TextField`, `TextArea` и `Spinner` сразу после обновления клиента и API.
