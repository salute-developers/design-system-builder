## Why

Раздел «Палитра» собран по прототипу SDDS Portal, а экраны «Цвета», «Типографика» и «Размеры и радиусы» изменение
`align-token-screens-with-figma` переводит на Figma и общую грамматику. Аудит палитры против Figma
([docs/figma-audit/palette.md](../../../docs/figma-audit/palette.md)) нашёл 52 расхождения. Шесть из них высокой
важности: ошибка загрузки с неоформленной кнопкой, ряд палитры на борде, удаление, заголовки секций инспектора,
размеры окон, дерево в режиме «Цвет». Рядом с выровненными экранами палитра выглядит как другой продукт. Разработчик
решил выравнивать палитру отдельным изменением: вид по Figma, поведение из спеки палитры сохраняется.

## What Changes

- **Эталон вёрстки.** Вид раздела задаёт Figma (секция `04 · Palette · Handoff`) вместо прототипа SDDS Portal.
  Поведение, которое спека палитры описывает как функции, сохраняется:
  - 15 ступеней с #50;
  - метка «Custom · вне брендовой палитры»;
  - «+» у групп и «Создать группу»;
  - окно удаления с «Сохранить как Custom»;
  - свой выбор цвета;
  - переключатель «Группа N / Все N»;
  - маркеры изменённых растяжек и ступеней.

  Меняется только вид этих элементов.
- **Общая грамматика экранов токенов.** Раздел переходит на общие компоненты и классы `tokenWorkspace` и шкалу
  отступов `--tw-space-*`:
  - ширина панелей меняется, как на соседних экранах;
  - шапка дерева 40 px, поиск на месте заголовка;
  - строки дерева `Builder/ListItem`, выбранная строка;
  - шапка и секции инспектора, строки «имя — значение»;
  - карточка метаданных и интервалы борда;
  - иконки `@salutejs/sdds-icons/16` вместо глифов прототипа и текстовых символов;
  - кегль не меньше 12 px.
- **Дерево.**
  - Заголовок «Палитра» вместо «Overview».
  - Фильтры «Все / Связанные / Изменённые» — вкладки 12/16.
  - В режиме «Цвет» заголовок дерева не меняется, ступени выбранной растяжки идут плоским списком строк
    `Builder/ListItem`, выбор нейтральный.
- **Борд.** Ряд растяжки по `Palette/WorkspaceRamp`: карточка метаданных 114×100 и полоса ступеней по 80×100 вплотную.
  Отступ 16, секции через 24, ряды через 8. Заголовок секции 12/16 600 с описанием 12/14. Кольцо выбранной растяжки
  2 px.
- **Окна.**
  - «Поменять», «Изменить» и выбор цвета ступени — шириной 240 px по Figma, текст 12/14, меню и поля из общей
    грамматики.
  - Окна удаления растяжки и группы — в стиле общего окна подтверждения.
- **Состояния.**
  - Загрузка: дерево остаётся, на месте борда и инспектора — скелетоны.
  - Ошибка загрузки: общее состояние «Не удалось загрузить палитру» с «Повторить». Сейчас при ошибке раздел заменяется
    строкой и неоформленной кнопкой — это исправляется.
  - Пустой поиск: одно сообщение «По вашему запросу ничего не найдено».
  - Режим просмотра: баннер как на соседних экранах, без сдвига панелей за край окна.
- **Попутные ошибки.**
  - Баннер «Только просмотр» уводит сетку за окно на 33 px.
  - При пустом поиске показываются два разных сообщения, а инспектор показывает скрытую поиском растяжку.
  - Открытие «Поменять» прокручивает борд по горизонтали.
- **BREAKING (визуально).** Карточка растяжки больше не 816×80 с ячейкой 84: требование «Вёрстка раздела по прототипу»
  заменяется требованием «Вёрстка раздела по Figma».

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `theme-palette-editor`: изменяются следующие требования.
  - Эталон вёрстки — Figma вместо прототипа.
  - Загрузка и ошибка загрузки.
  - Заголовок и метка раздела, режим «Цвет» в дереве.
  - Пустой результат поиска и фильтра.
  - Вид окна удаления.
  - Строки инспектора.
  - Баннер режима просмотра.

  Функции раздела, API и данные не меняются.

## Impact

- **Клиент `js/apps/client`:**
  - `pages/palette/*`, `styles/palette.css`;
  - `pages/Main.tsx` (палитра сама показывает загрузку и ошибку, как экраны токенов);
  - тесты палитры;
  - удаление `PaletteGlyph` и правил прототипа, которые больше не используются.
- **Зависимость.** Изменение опирается на общие компоненты, классы и шкалу из `align-token-screens-with-figma`.
  Реализация начинается после его слияния или поверх его ветки.
- **Не меняется:**
  - `ds-service`, API палитры и формат данных;
  - другие разделы клиента.
- **Документация.** `docs/figma-audit/palette.md` (отметить исправленное) и `docs/figma-audit/README.md` (строка про
  палитру).
