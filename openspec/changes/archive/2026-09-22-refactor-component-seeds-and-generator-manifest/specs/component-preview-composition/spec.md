# Spec Delta

## Purpose

Определяет поведение превью текущего React-клиента `js/apps/client` для компонентов с несколькими appearance, флагами, свойствами типа `value` и связанными компонентами, чтобы превью показывало то же, что пакет, собранный генератором.

## ADDED Requirements

### Requirement: Preview maps core token keys to CSS variables

Превью SHALL получать значения свойств по ключу токена ядра и переводить ключ в имя CSS-переменной
через объект токенов ядра компонента; при отсутствии ключа в объекте имя SHALL строиться по схеме
`--plasma-<component>-<key>`.

#### Scenario: Переменная из объекта токенов ядра

- **WHEN** объект токенов ядра содержит ключ свойства
- **THEN** превью MUST использовать имя переменной из объекта, даже если оно не выводится из ключа

#### Scenario: Компонент с чужим объектом токенов

- **WHEN** ядро не экспортирует `<x>Tokens` для компонента (TabItem, StepItem, Body)
- **THEN** превью MUST взять объект из клиентской карты соответствий
- **THEN** карта MUST зеркалить `coreTokensExport` манифестов генератора

### Requirement: Related components are rendered with the design-system theme

Превью SHALL собирать компоненты, связанные с текущим через зависимости, с конфигом темы дизайн-системы
и передавать их стори готовыми под ключами `<Имя>` и `<Имя>Config`.

#### Scenario: Вложенный компонент получает свои вариации

- **WHEN** стори рендерит связанный компонент из `relatedComponents` с пропом вариации (`view="clear"`)
- **THEN** он MUST получить значения этого стиля из дизайн-системы
- **THEN** переменные выбранных в панели значений текущего компонента MUST NOT переопределять его

#### Scenario: Конфиг связанного доступен провайдерам

- **WHEN** стори использует провайдер ядра, принимающий конфиг
- **THEN** `relatedComponents` MUST содержать конфиг темы под ключом `<Имя>Config`
- **THEN** сам текущий компонент MUST быть доступен там же

#### Scenario: Runtime-конфиг совпадает с пакетом

- **WHEN** превью собирает конфиг темы компонента
- **THEN** его `defaults` и `variations` MUST совпадать по составу с тем, что генератор пишет в `<X>.config.ts`

### Requirement: Compose-related variables are synchronised

Для связи `compose` превью SHALL класть на сцену переменные дочернего и родительского компонента,
синхронизируя одноимённые вариации с выбранными в панели.

#### Scenario: Дочерний следует за родителем

- **WHEN** на странице Tabs выбран стиль `size=l`
- **THEN** элементы TabItem внутри MUST получить значения своего стиля `l`, если он есть
- **THEN** без одноимённого стиля MUST использоваться дефолт дочернего

#### Scenario: Родитель следует за дочерним

- **WHEN** открыта страница TabItem
- **THEN** контейнер Tabs MUST получить значения своих вариаций, синхронизированные с выбранными у TabItem

### Requirement: Flags and defaults in the editor

Редактор SHALL показывать вариацию-флаг переключателем и позволять снимать дефолт вариации.

#### Scenario: Флаг переключается

- **WHEN** вариация имеет единственный стиль `true`
- **THEN** панель MUST показывать её переключателем
- **THEN** включённый флаг MUST передавать компоненту булев проп `true`, выключенный — не передавать проп

#### Scenario: Дефолт снимается

- **WHEN** стиль является дефолтом вариации
- **THEN** меню стиля MUST предлагать «Снять по умолчанию»
- **THEN** после снятия вариация MUST остаться без дефолта и не попадать в `defaults` конфига

### Requirement: First appearance is edited

Редактор SHALL показывать и сохранять первый appearance компонента; остальные appearance SHALL
оставаться без изменений при сохранении.

#### Scenario: Компонент с двумя appearance

- **WHEN** открыт компонент с appearance `horizontal` и `vertical`
- **THEN** панель MUST показывать вариации и значения `horizontal`
- **THEN** сохранение MUST NOT изменять данные `vertical`

### Requirement: Value properties are applied but not edited

Свойство типа `value` SHALL применяться в превью как есть и SHALL NOT показываться в панели свойств
для редактирования.

#### Scenario: Строка уходит в переменную

- **WHEN** свойство `value` имеет значение `fit-content`
- **THEN** соответствующая CSS-переменная в превью MUST получить `fit-content`
