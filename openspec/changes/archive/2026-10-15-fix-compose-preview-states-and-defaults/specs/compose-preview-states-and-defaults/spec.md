## ADDED Requirements

### Requirement: Приоритет состояний как в Android

Клиент SHALL передавать записи `states` в payload так, чтобы при равном числе совпавших состояний побеждало состояние, стоящее
в конфигурации раньше. Читающий маршрут `component-configs` SHALL отдавать значения состояний в порядке `position`.

#### Scenario: Нажатие при наведении

- **WHEN** у цвета в конфигурации состояния идут `pressed`, затем `hovered`, и оба активны
- **THEN** превью MUST показывать цвет `pressed`.

#### Scenario: Порядок из базы

- **WHEN** значения состояний хранятся в базе в другом порядке, чем их `position`
- **THEN** маршрут MUST вернуть их по возрастанию `position`.

### Requirement: Состояния инвариантов доходят до превью

Маршрут `component-configs` SHALL отдавать значения состояний инварианта в поле `states` рядом с его базовым значением, в порядке `position`.

#### Scenario: Выбранный RadioBox

- **WHEN** у инварианта `toggleColor` есть значение для состояния `checked`
- **THEN** запись в `invariantProps` MUST содержать `states` с этим значением, а не отдельную запись без состояния.

### Requirement: Вариация без стиля по умолчанию получает первый стиль

Редактор SHALL при открытии компонента выбрать первый стиль у каждой вариации без стиля по умолчанию, кроме флагов, чтобы
стили, зависящие от сочетаний, попадали в превью без дополнительных действий.

#### Scenario: Вид без значения по умолчанию

- **WHEN** у `TabBar` вариация `view` не имеет стиля по умолчанию
- **THEN** при открытии payload MUST содержать `tabBarItemStyle` для выбранных размера и первого вида.

#### Scenario: Выключенный флаг

- **WHEN** вариация является флагом без значения по умолчанию
- **THEN** редактор MUST NOT выбирать для неё стиль.

### Requirement: Числовое свойство принимает промежуточный ввод

Числовое поле свойства Compose-компонента SHALL показывать введённый текст и обновлять значение, когда текст разбирается в число.

#### Scenario: Ввод дробного числа

- **WHEN** пользователь вводит `0.5`
- **THEN** поле MUST показать `0.` после второго символа, а значение MUST стать `0.5` после последнего.

### Requirement: Стили по умолчанию превью берутся из темы

Клиент SHALL добавлять в payload раздел `defaults` со стилем и цветом текста по умолчанию и со стилями `button`, `switch`,
`spinner`, собранными из темы дизайн-системы. Если нужного токена или конфигурации нет, соответствующий элемент MUST отсутствовать.

#### Scenario: Тема содержит стили по умолчанию

- **WHEN** в теме есть `body.m.normal`, `text.default.primary`, конфигурации `basic-button`, `switch`, `spinner`
- **THEN** payload MUST содержать `defaults.text` и `defaults.styles.button`, `switch`, `spinner`, а их стили MUST входить в `styles`.

#### Scenario: Конфигурации нет

- **WHEN** в дизайн-системе нет конфигурации `spinner`
- **THEN** `defaults.styles` MUST NOT содержать `spinner`, а превью MUST работать.
