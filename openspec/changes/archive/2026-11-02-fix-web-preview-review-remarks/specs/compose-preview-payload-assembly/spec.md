## ADDED Requirements

### Requirement: Сплошной градиент в web-payload

Ассемблер SHALL собирать web-значение градиента из строки CSS, списка строк и сплошного слоя
`{ kind: 'color', background }` в слой `linear` протокола с двумя одинаковыми остановками.

#### Scenario: Сплошной токен градиентного семейства

- **WHEN** свойство компонента ссылается на токен `dark.outline.default.accent-gradient-active` со значением `["#666666FF"]`
- **THEN** сборка payload MUST завершиться успешно, а токен MUST иметь тип `gradient` с остановками цвета `#666666FF`

#### Scenario: Ссылка на палитру

- **WHEN** сплошное значение градиента записано ссылкой на ступень палитры
- **THEN** слой протокола MUST содержать цвет этой ступени

#### Scenario: Некорректный цвет слоя

- **WHEN** `background` сплошного слоя не является цветом
- **THEN** сборка MUST вернуть диагностику `incompatible_value`
