## ADDED Requirements

### Requirement: Редактор принимает адрес предметного источника из журнала

Веб-клиент SHALL поддерживать адресуемое открытие токена или компонента из журнала дизайн-системы и SHALL сохранять
границу исторического чтения.

#### Scenario: Открывается конкретный токен

- **WHEN** маршрут редактора токенов содержит `tokenId` существующего токена выбранной дизайн-системы
- **THEN** клиент MUST открыть соответствующий раздел, выбрать токен после загрузки данных и сделать его видимым
- **THEN** обновление страницы MUST восстановить тот же выбор

#### Scenario: Открывается конкретный компонент

- **WHEN** маршрут содержит имя существующего компонента выбранной дизайн-системы
- **THEN** клиент MUST открыть редактор этого компонента
- **THEN** обновление страницы MUST восстановить тот же выбор

#### Scenario: Источник открыт из опубликованного журнала

- **WHEN** переход к токену или компоненту содержит `versionId`
- **THEN** клиент MUST сохранить `versionId` во всех последующих предметных запросах и переходах внутри редактора
- **THEN** редактор MUST оставаться в режиме только для чтения

#### Scenario: Указанный токен отсутствует

- **WHEN** `tokenId` не существует на выбранной временной границе
- **THEN** клиент MUST открыть соответствующий раздел без произвольного выбора другого токена как источника
- **THEN** клиент MUST показать, что точный источник недоступен
