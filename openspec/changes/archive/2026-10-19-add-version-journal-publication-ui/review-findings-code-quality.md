# Оставшееся замечание проверки качества клиента

## CQ-1. Связанность кода превышает допустимый показатель

Статус: зафиксировано отдельно по решению разработчика; дальнейший рефакторинг старого клиентского кода
за пределами согласованных изменений пока не выполняется. Это не означает успешное прохождение FULL.

Проверка: `tools/strictacode compare javascript-client js/apps/client`.

| Показатель | Базовое значение | Текущий результат | Допуск |
| --- | ---: | ---: | ---: |
| Общая оценка | 44 | 44 | Без увеличения |
| Плотность сложности | 7.51 | 7.33 | Без увеличения |
| Потребность в рефакторинге (RP) | 58 | 58 | Без увеличения |
| Связанность и избыточность зависимостей (OP) | 10 | 12 | Не более 11 |

Команда завершается с кодом 1: `overengineering pressure exceeds threshold 2 > 1`.
Остальные три показателя укладываются в ограничения. OP — агрегированная оценка графа зависимостей,
а не доказательство конкретного дефекта безопасности или поведения.

Заключительный `tools/verify full --change add-version-journal-publication-ui` также завершился с кодом 1
на этом же сравнении. До остановки прошли backend `verifyFull` и его Strictacode, сборки JavaScript
и 105 сервисных тестов. Следующие сравнения качества CLI и db-service не выполнялись из-за остановки
на первой ошибке. Отдельно прошли 226 клиентских тестов, FAST и независимое ревью без блокирующих замечаний;
14 браузерных сценариев и 2 проверки desktop-раскладки прошли на тестовых данных. Ручная проверка 7.3
впоследствии проведена на локальном контуре; найдены отдельные замечания M-1 и M-2 в `review-findings-manual.md`.
Успешные автоматизированные сценарии не означают успешной приёмки этих замечаний.

Повторная проверка исходного состояния ветки (`70c062b4`, до незакоммиченных изменений интерфейса)
также показала OP=12. Поэтому оставшееся превышение нельзя приписать только новому интерфейсу журнала.
Прежний результат воспроизведён из неизменённой временной копии коммита без изменения рабочего дерева.

В согласованной области уже разделены сетевые операции по предметным областям, выделен жизненный цикл
сессии редактора, объединены загрузка версий и применение загруженных данных, удалено дублирование
цветовых формул. Вычисления формул, диапазоны и порядок правил проверяются по отпечатку исходной таблицы
и результатам 6120 контрольных вычислений.

Базовые показатели, пороги, настройки, исключения и код самого анализатора не менялись.
Задача 6.23 удалена из этого изменения по прямому решению разработчика. Замечание остаётся в этом документе:
выполненный рефакторинг и удаление задачи не равнозначны прохождению проверки.

Для продолжения нужен отдельный согласованный разбор старого клиентского кода с оценкой
реальных лишних зависимостей и проверкой поведения. Менять синтаксис ради сокрытия кода от анализатора,
добавлять исключения или обновлять базовые показатели ради успешного результата не следует.

После исправления M-1/M-2 повторный FULL 19.10.2026 дал тот же результат:
44 / 7.33 / 58 / 12, остановка только на OP. При этом прошли 241 клиентский тест,
сборка, FAST, повторное независимое ревью, браузерные сценарии и повторная ручная проверка.
Замечания M-1/M-2 закрыты в `review-findings-manual.md`; это не отменяет оставшийся отказ FULL.

19.10.2026 разработчик явно подтвердил архивирование изменения и создание коммита с этим известным
превышением. Это согласованное исключение при завершении изменения, а не успешный результат FULL;
правила анализатора и базовые показатели остаются неизменными.
