## Зачем

Имя темы в DS Builder задаёт пользователь, и привычные для него имена вида `my-theme` в `.sdds`
попадают в `meta.json` как есть. Web CLI (`js/cli`, `generate:theme` и `generate:ds`) превращает
это имя в имена файлов и экспортов, поэтому сейчас отказывается генерировать тему с ошибкой
`... is not a valid JavaScript identifier`. Из-за этого `dsbuilder theme generate --platform react`
падает на обычной дизайн-системе, и пользователю приходится переименовывать тему в конструкторе.
Web CLI должен сам приводить такое имя к идентификатору, а падать только тогда, когда это сделать
нельзя.

## Что меняется

- Web CLI приводит имя темы из `meta.json` к идентификатору JavaScript: кириллица
  транслитерируется латиницей, а разделители заменяются нижним подчёркиванием:
  `my-theme` → `my_theme`, `brand night` → `brand_night`, `Тёмная тема` → `Temnaya_tema`.
  Имя, которое уже является идентификатором, не меняется, поэтому результат генерации
  существующих тем остаётся прежним.
- Приведённое имя используется везде, где раньше использовалось исходное: имена файлов,
  экспорты (`my_theme__dark`), тема по умолчанию для `tokens/index.ts`.
- Если имя изменилось, CLI пишет в stderr сообщение с исходным и приведённым именем.
- Совпадение приведённых имён двух тем (без учёта регистра) остаётся ошибкой, и в сообщении
  называются обе темы и их исходные имена.
- Имя, из которого не получается идентификатор (пустое, только из разделителей и символов без
  транслитерации или начинающееся с цифры), по-прежнему даёт ошибку с именем темы, но текст объясняет, что именно не так.
- `meta.json` в `.sdds` не изменяется.

## Возможности

### Новые возможности

Нет.

### Изменённые возможности

- `local-web-generation`: требование «Theme names are validated before generation» теперь
  предписывает приводить имя темы к идентификатору вместо отказа и проверять совпадения
  по приведённому имени.

## Влияние

- `js/cli`: `src/theme-source.ts` (чтение и проверка тем), `src/theme.test.ts` (тесты);
  генератор `src/generator/themeBuilder` получает уже приведённые имена и не меняется.
- `frontend-kt`: не затрагивается — `dsbuilder theme generate --platform react` вызывает web CLI
  и получит исправление без изменений в Kotlin.
- `backend-kt`: не затрагивается; формат `.sdds`, API и хранение данных не меняются.
