## ADDED Requirements

### Requirement: Сообщение о незагруженной иконке

Клиент SHALL различать иконки, SVG которых не загрузился, и сообщать об этом пользователю там, где иконка выбрана. Сбой одного файла MUST NOT влиять на остальные иконки и на работу страницы. Значение иконки MUST NOT блокироваться из-за сбоя файла: иконка есть в каталоге, недоступен только её файл.

#### Scenario: Заглушка в каталоге

- **WHEN** SVG одной иконки не загрузился, а остальные загрузились
- **THEN** плитка этой иконки MUST показать заглушку, а её название для скринридера MUST содержать пометку «не удалось загрузить иконку»; остальные плитки MUST отображаться как обычно, а страница MUST NOT показывать общую ошибку.

#### Scenario: Выбор незагруженной иконки в пикере

- **WHEN** пользователь выбирает в пикере иконку, SVG которой не загрузился
- **THEN** клиент MUST сохранить значение как обычно и показать под полем уведомление, что файл иконки не загрузился из хранилища и в превью её не будет.

#### Scenario: Сохранённое значение с незагруженным файлом

- **WHEN** панель свойств показывает значение, иконка которого есть в каталоге, а её SVG не загрузился
- **THEN** под полем MUST отображаться уведомление о незагруженном файле.

#### Scenario: Уведомление снимается

- **WHEN** пользователь выбирает иконку с загруженным файлом или очищает значение
- **THEN** уведомление MUST исчезнуть.

#### Scenario: Панель сведений каталога

- **WHEN** на странице каталога выбрана иконка, SVG которой не загрузился
- **THEN** панель сведений MUST показать сообщение о незагруженном файле вместо пустого превью.
