## Причина

Полный комплект CLI сейчас хранится в S3, а GitHub Releases содержит только JVM-архив. Перенос дистрибутивов в GitHub Releases убирает дублирование доставки и отдельное управление стабильной версией, сохраняя привычные адреса установки.

## Изменения

- Публиковать четыре существующих архива, `SHA256SUMS` и `release.json` в GitHub Release тега `cli-vX.Y.Z`; открывать выпуск только после проверки полного комплекта.
- Оставить `install.sh` и `install.ps1` в S3 по существующим адресам и с существующими настройками бакета, префикса и публичного корня. Перезаписывать оба скрипта в рамках каждого успешного релизного запуска CLI, включая повтор старого тега; отдельные копии по версиям не создавать.
- Использовать GitHub Latest как единственный указатель стабильной версии; закреплять выбранный тег на всё время установки, сохранять явный выбор версии.
- **BREAKING**: удалить `stable.json` и его синхронизацию; новые установщики больше не читают архивы из S3. Старые объекты S3 автоматически не удалять.
- Разрешить необходимые HTTPS-перенаправления скачивания, сохраняя проверку SHA-256 и защиту распаковки.
- Автоматически выбирать macOS arm64/x64, Windows x64 и JVM для Linux с Java 17+; сохранить явный `--target jvm`. Новые нативные платформы не добавлять.

## Возможности

### Новые возможности

Нет.

### Изменяемые возможности

- `cli-release-delivery`: размещение выпусков, GitHub Latest, доставка установщиков из S3, выбор платформы и обработка перенаправлений.

## Влияние

- `frontend-kt/cli/distribution/`: подготовка и публикация, сетевые установщики, тесты, документация; `frontend-kt/cli/build.gradle.kts`: проверки доставки.
- `.github/workflows/`: публикация CLI с обновлением установщиков в S3, удаление синхронизации stable, замена S3-проверки полных выпусков проверкой доставки установщиков и GitHub-контрактов.
- GitHub: разрешение `contents: write` только для публикации; Latest репозитория резервируется для стабильного CLI. S3 credentials нужны только шагу обновления установщиков.
- `backend-kt` и `js`, их API и хранилища не изменяются. Kotlin-модули, локальные установщики и формат четырёх архивов сохраняются, включая вложенный iOS CLI и необязательную установку web-генератора.
