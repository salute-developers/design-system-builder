## MODIFIED Requirements

### Requirement: Theme является tenant дизайн-системы

Система SHALL представлять каждую пользовательскую Theme одной устойчивой сущностью tenant, принадлежащей ровно одной
дизайн-системе, а её изменяемые данные — предметными редакциями общего черновика дизайн-системы.

#### Scenario: Тема возвращается как tenant DTO

- **WHEN** клиент запрашивает темы дизайн-системы без `versionId`
- **THEN** API MUST вернуть tenant DTO из активного черновика со стабильными `id`, `designSystemId`, `name`,
  необязательным `description` и `colorConfig`
- **THEN** DTO MUST NOT содержать отдельную версию или статус Draft темы

#### Scenario: Запрошена тема опубликованной версии

- **WHEN** клиент запрашивает темы дизайн-системы с `versionId`
- **THEN** API MUST вернуть tenant и значения, действовавшие на границе этой версии
- **THEN** система MUST NOT создавать или искать отдельную версию темы

#### Scenario: Пользователь изменяет тему

- **WHEN** пользователь изменяет метаданные или значения токенов темы
- **THEN** система MUST записать предметные редакции активного черновика дизайн-системы
- **THEN** система MUST NOT создавать версию отдельной Theme

### Requirement: Удаление темы соответствует ролевой политике

Система SHALL позволять удалить tenant из активного состояния только пользователю с разрешением `tenants:delete` и
SHALL сохранять опубликованное состояние для исторического чтения и отката.

#### Scenario: Maintainer или Owner удаляет опубликованную тему

- **WHEN** Maintainer или Owner подтверждает удаление темы, существующей на предыдущей опубликованной границе
- **THEN** API MUST создать в активном черновике предметную редакцию tenant с `deleted = true`
- **THEN** API MUST считать принадлежащие теме значения отсутствующими в активном черновике
- **THEN** прежняя опубликованная версия MUST продолжить возвращать tenant и его значения
- **THEN** журнал MUST содержать обратимое удаление темы

#### Scenario: Созданная в черновике тема удалена до публикации

- **WHEN** пользователь удаляет tenant, созданный в том же черновике и не имеющий опубликованных зависимостей
- **THEN** система MUST удалить его черновые редакции и устойчивую сущность
- **THEN** журнал MUST не содержать создания или удаления этой темы

#### Scenario: Editor не может удалить тему

- **WHEN** Editor просматривает карточку темы
- **THEN** клиент MUST NOT показывать действие удаления

#### Scenario: Viewer не может изменить тему

- **WHEN** Viewer просматривает карточку темы
- **THEN** клиент MUST NOT показывать действия переименования или удаления
