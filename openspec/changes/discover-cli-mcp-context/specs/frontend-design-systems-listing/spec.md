## Purpose

Определяет общий клиентский список доступных дизайн-систем проекта для CLI, MCP и IDE до разрешения контекста конкретной системы.

## ADDED Requirements

### Requirement: Дизайн-системы доступного проекта до выбора контекста

Общие клиентские сценарии SHALL возвращать дизайн-системы явно указанного проекта без `.sdds/config.json` и без заранее выбранной системы, используя пользовательскую сессию и существующие проверки доступа backend.

#### Scenario: Список систем
- **WHEN** авторизованный клиент передаёт projectId
- **THEN** он MUST получить список из `GET /api/projects/{projectId}/ds/design-systems` с ID, именем и описанием при наличии
- **THEN** CLI, MCP и Android Studio plugin MUST использовать общий сценарий получения списка

#### Scenario: Пустой список
- **WHEN** доступный проект не содержит систем
- **THEN** результат MUST быть успешным пустым списком

#### Scenario: Отказ и некорректный ответ
- **WHEN** отсутствует сессия, backend запрещает доступ, недоступен либо возвращает неправильный формат
- **THEN** клиент MUST различать `AUTH_REQUIRED`, `FORBIDDEN`, `NOT_FOUND`, `BACKEND_UNAVAILABLE` и `INVALID_BACKEND_RESPONSE`
- **THEN** он MUST NOT переключаться на project key после отказа и MUST NOT возвращать чужие системы
