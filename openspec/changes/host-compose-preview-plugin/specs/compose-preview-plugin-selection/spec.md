## ADDED Requirements

### Requirement: Клиент получает адрес плагина от бэкенда

Если не задан прямой адрес плагина, клиент SHALL запросить `GET /api/projects/{projectId}/ds/compose-preview/plugin` и использовать `pluginUrl` из ответа как адрес каталога плагина. Дальнейшая загрузка (manifest, entrypoint, iframe, проверка протокола) MUST выполняться существующим способом.

#### Scenario: Активный билд есть

- **WHEN** прямой адрес не задан, а бэкенд вернул `pluginUrl`
- **THEN** клиент MUST загрузить `preview-plugin.json` из этого каталога и продолжить стандартную загрузку плагина.

#### Scenario: Активного билда нет

- **WHEN** бэкенд ответил `404`
- **THEN** клиент MUST NOT запрашивать Compose-компоненты и MUST NOT загружать плагин
- **AND** React-preview MUST работать без изменений.

### Requirement: Недоступность адреса отключает только Compose-preview

Если запрос адреса плагина завершился ошибкой (кроме `404`), клиент SHALL оставить React-preview доступным и показать сообщение о недоступности Compose-preview. Клиент MUST NOT подставлять адрес по умолчанию.

#### Scenario: Ошибка запроса адреса

- **WHEN** бэкенд отвечает ошибкой сервера или запрос не доходит
- **THEN** клиент MUST показать сообщение о недоступности Compose-preview
- **AND** редактор токенов, тем и компонентов MUST продолжить работать.

### Requirement: Прямой адрес плагина обходит запрос к бэкенду

Если задан `VITE_COMPOSE_PREVIEW_PLUGIN_URL`, клиент SHALL использовать его как адрес плагина и MUST NOT запрашивать адрес у бэкенда.

#### Scenario: Локальная разработка

- **WHEN** задан прямой адрес плагина
- **THEN** клиент MUST загрузить плагин по этому адресу
- **AND** запрос `GET .../compose-preview/plugin` MUST NOT выполняться.

### Requirement: Адрес плагина кешируется на время жизни страницы

Клиент SHALL запрашивать адрес плагина не чаще одного раза на загрузку страницы для одного проекта. Новый активный билд MUST подхватываться при следующей загрузке страницы.

#### Scenario: Переключение компонентов не повторяет запрос

- **WHEN** пользователь переключает несколько Compose-компонентов на одной странице
- **THEN** клиент MUST использовать ранее полученный адрес без повторного запроса.

### Requirement: Адрес плагина не зависит от выбранной версии дизайн-системы

Клиент SHALL запрашивать адрес плагина без идентификатора версии дизайн-системы и MUST использовать один и тот же адрес при просмотре черновика и любой опубликованной версии.

#### Scenario: Просмотр опубликованной версии

- **WHEN** пользователь открывает редактор на опубликованной версии дизайн-системы
- **THEN** запрос адреса плагина MUST NOT содержать `versionId`
- **AND** Compose-preview MUST использовать активный билд плагина.
