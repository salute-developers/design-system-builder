## MODIFIED Requirements

### Requirement: Плагин загружается во время работы по адресу
Клиент SHALL загружать плагин Compose-preview во время работы. Адрес плагина определяется либо прямым значением переменной сборки `VITE_COMPOSE_PREVIEW_PLUGIN_URL`, либо выбором билда по каналу из `VITE_COMPOSE_PREVIEW_PLUGIN_BASE_URL` и `VITE_COMPOSE_PREVIEW_CHANNEL` (capability `compose-preview-plugin-selection`); прямое значение имеет приоритет. Файлы плагина MUST NOT входить в сборку клиента, MUST NOT линковаться с кодом клиента и MUST NOT храниться в Git-репозитории.

#### Scenario: Смена адреса плагина
- **WHEN** значение `VITE_COMPOSE_PREVIEW_PLUGIN_URL` указывает на другую сборку плагина
- **THEN** клиент MUST загружать manifest и точку входа новой сборки без изменения кода клиента

#### Scenario: Выбор билда по каналу
- **WHEN** прямой адрес не задан, а заданы базовый адрес и канал
- **THEN** клиент MUST определить адрес билда выбором по версии меты и индексу канала и загрузить manifest и точку входа этого билда

#### Scenario: Сборка клиента не содержит плагин
- **WHEN** выполняется сборка клиента
- **THEN** результат сборки MUST NOT содержать файлы плагина, а только строки адреса и канала

#### Scenario: Архив плагина не хранится в репозитории
- **WHEN** выполняется проверка файлов, добавленных переносом прототипа
- **THEN** бинарный архив плагина и распакованные файлы Wasm MUST отсутствовать в Git

### Requirement: Происхождение выполняемого кода
Эта функция SHALL использовать только плагин, собранный командой SDDS из `plasma-android` и опубликованный в настроенный адрес. Загрузка плагинов из других источников, в том числе пользовательских, MUST NOT поддерживаться, а адрес по умолчанию MUST NOT задаваться в коде клиента.

#### Scenario: Адрес не задан
- **WHEN** клиент собирается без `VITE_COMPOSE_PREVIEW_PLUGIN_URL` и без `VITE_COMPOSE_PREVIEW_PLUGIN_BASE_URL`
- **THEN** клиент MUST NOT пытаться загрузить плагин из какого-либо адреса по умолчанию

#### Scenario: Канал без базового адреса
- **WHEN** задан `VITE_COMPOSE_PREVIEW_CHANNEL`, но не задан ни базовый, ни прямой адрес
- **THEN** клиент MUST NOT загружать плагин

## ADDED Requirements

### Requirement: Документированная настройка выбора билда
`README.md` клиента SHALL описывать переменные `VITE_COMPOSE_PREVIEW_PLUGIN_BASE_URL` и `VITE_COMPOSE_PREVIEW_CHANNEL`, правило выбора билда и предупреждений, приоритет прямого адреса над выбором и принятый риск общего origin плагина и клиента при размещении в одном бакете.

#### Scenario: Разработчик настраивает окружение
- **WHEN** разработчик читает раздел Compose-preview в README клиента
- **THEN** README MUST перечислять переменные, допустимые каналы `dev` и `current`, поведение при отсутствии версии меты и локальный запуск с прямым адресом
