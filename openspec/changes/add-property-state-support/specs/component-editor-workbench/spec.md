## ADDED Requirements

### Requirement: Состояния свойства

Кнопка «+» («Добавить состояние») SHALL показываться у строки свойства источника стиля или инварианта, если признак
`stateSupport` свойства равен `interaction` или `any`, независимо от типа свойства. У свойства без признака (`null`)
кнопка SHALL показываться по прежнему правилу: только у цветового свойства без `focus` в имени. У строк пересечения
и у свойства с признаком `none` кнопки MUST NOT быть.

Кнопка открывает меню с флажками состояний и кнопкой «Добавить» (или «Добавить · N»); кнопка недоступна, пока ничего
не выбрано. Меню SHALL предлагать: при `interaction` — состояния взаимодействия из `states` бандла; при `any` — ещё и
состояния компонента; при незаданном признаке — `hovered`, `pressed`, `focused`. Состояния взаимодействия идут первыми
в порядке `focused`, `pressed`, `hovered`, затем остальные в порядке бандла. Отметка выбранного флажка SHALL рисоваться
глифом `check` по центру флажка.

Подтверждение SHALL добавлять одно состояние из выбранных флажков; подпись сочетания записывается через `+` в порядке
меню. Значение состояния равно базовому значению свойства. Уже существующее состояние MUST NOT добавляться повторно.

Состояния SHALL показываться строками под свойством: соединительные линии слева, подпись состояния, тот же контрол,
что у базового значения этого типа (цвет с пикером, число, форма, тень, типографика, иконка), и кнопка удаления
состояния. Строки уже записанных состояний SHALL показываться у свойства с любым признаком, в том числе `none`, чтобы
их можно было удалить. Добавленное состояние SHALL сохраняться и оставаться после перечитывания компонента.

#### Scenario: Сочетание состояний

- **WHEN** пользователь отмечает `hovered` и `pressed` у цветового свойства с признаком `interaction` и нажимает «Добавить · 2»
- **THEN** под свойством MUST появиться строка `pressed + hovered` со значением базового цвета
- **THEN** состояние MUST записаться в источник свойства как набор состояний `pressed`, `hovered`

#### Scenario: Состояние числового свойства

- **WHEN** у свойства `paddingStart` типа `dimension` признак `any`, и пользователь добавляет состояние `dragging-over`
- **THEN** под свойством MUST появиться строка `dragging-over` с числовым полем и базовым значением
- **THEN** правка числа в строке MUST записать значение состояния

#### Scenario: Состояния компонента только при any

- **WHEN** у свойства признак `interaction`
- **THEN** меню MUST NOT предлагать состояния компонента
- **WHEN** у свойства признак `any`
- **THEN** меню MUST предлагать состояния компонента из `states` бандла

#### Scenario: Свойство без поддержки состояний

- **WHEN** у цветового свойства признак `none`
- **THEN** кнопки «Добавить состояние» MUST NOT быть
- **WHEN** у такого свойства уже записано значение в состоянии `hovered`
- **THEN** строка `hovered` MUST показываться с кнопкой удаления

#### Scenario: Свойство без признака

- **WHEN** у цветового свойства `background` признак `null`
- **THEN** кнопка MUST показываться, а меню MUST предлагать `hovered`, `pressed`, `focused`
- **WHEN** у цветового свойства `focusColor` признак `null`
- **THEN** кнопки MUST NOT быть

#### Scenario: Удаление состояния

- **WHEN** пользователь нажимает удаление в строке состояния `hovered`
- **THEN** состояние MUST удалиться из свойства

#### Scenario: Состояние сохраняется

- **WHEN** пользователь добавил состояние `hovered`, и после автосохранения компонент перечитан или страница перезагружена
- **THEN** строка `hovered` MUST остаться под свойством с прежним значением

## REMOVED Requirements

### Requirement: Состояния цветового свойства

**Reason**: Эвристика «цвет без `focus` в имени» заменяется признаком `stateSupport` из меты; состояния доступны свойствам любого типа.
**Migration**: Поведение описывает требование «Состояния свойства»; для свойств без признака прежнее правило сохраняется там как запасное.
