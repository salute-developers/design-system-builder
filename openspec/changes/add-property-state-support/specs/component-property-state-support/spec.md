## ADDED Requirements

### Requirement: Признак поддержки состояний свойства

Свойство компонента SHALL нести признак `stateSupport` со значениями `none`, `interaction`, `any` либо без значения.
`ds-service` SHALL хранить его в `properties.state_support` типа enum `property_state_support`; столбец MUST допускать
`NULL`. Признак относится к свойству компонента конкретной платформы и MUST NOT выводиться из типа или имени свойства
на стороне `ds-service`.

#### Scenario: Значения признака

- **WHEN** свойство описано мета платформы
- **THEN** `none` MUST означать, что значения по состояниям слот не принимает
- **THEN** `interaction` MUST означать, что допустимы только состояния взаимодействия (строки `states` с `component_id IS NULL`)
- **THEN** `any` MUST означать, что допустимы состояния взаимодействия и состояния этого компонента

#### Scenario: Свойство заведено до признака

- **WHEN** свойство создано до миграции или импортом без признака
- **THEN** `state_support` MUST быть `NULL`
- **THEN** миграция MUST NOT заполнять признак по типу или имени свойства

#### Scenario: Признак в ответах каталога

- **WHEN** клиент читает свойства компонента (`ComponentPropertySummaryResponse`)
- **THEN** ответ MUST содержать поле `stateSupport` со значением `none`, `interaction`, `any` или `null`

### Requirement: Допустимый набор состояний свойства

Набор состояний SHALL считаться допустимым для свойства по его признаку: пустой набор допустим всегда; при `none`
непустой набор недопустим; при `interaction` допустимы только состояния взаимодействия; при `any` — состояния
взаимодействия и состояния компонента свойства; при незаданном признаке допустим любой набор, который разрешается для
компонента.

#### Scenario: Состояние компонента у свойства interaction

- **WHEN** у свойства `interaction`, а набор содержит `dragging-over` компонента `DropZone`
- **THEN** набор MUST считаться недопустимым

#### Scenario: Незаданный признак

- **WHEN** у свойства `stateSupport` равен `null`
- **THEN** любой набор состояний, объявленных для компонента, MUST считаться допустимым
