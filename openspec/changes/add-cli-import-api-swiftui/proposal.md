## Why

`dsbuilder components import-api` наполняет глобальный слой компонентов из API-меты платформы. Нормализаторы есть у `compose` и `android-view`; на `swiftui` команда отвечает, что платформа пока не поддержана, и компоненты iOS в базу не попадают.

Генератор iOS отдаёт `ios-api-meta.json` и за прошедший цикл привёл её к требованиям базы: один `id` внутри компонента несёт один тип, появился блок `stateEnum` с именами состояний в форме конфигурации, из меты убраны свойства, которых нет ни в коде, ни в конфигурациях оформления. Форма меты зафиксирована тестами-инвариантами в репозитории iOS, то есть нормализатор может на неё опереться.

## What Changes

- Платформа `swiftui` становится поддержанной: CLI нормализует `ios-api-meta.json` и отправляет манифест одним запросом с `platform` равным `ios`.
- Добавляется `SwiftUiApiMetaNormalizer` с правилами, общими для всех платформ: ключ свойства — пара `(компонент, id)`, повтор с другим типом попадает в `conflicts`, `--map-type` применяется до сравнения.
- Платформенным именем свойства становится имя свойства в Swift (`methodName`).
- Параметры без кода на платформе (`unmapped`) в манифест не попадают и учитываются в сводке пропущенного.
- Состояния компонента берутся из `stateEnum`; поля `state` у отдельных параметров состояниями компонента не считаются.
- Служебные признаки генератора iOS (`copyOf`, `fromVariation`, `valueEnum`, `markupValue`, `markupZero`, `rawNumber`, `alwaysEmit`, `stateOnly`, `sizeFromIconId`) в манифест не передаются.
- Нормализатор `react` и изменения backend в это изменение не входят: словарь платформ, маршрут импорта и модель манифеста уже есть.

## Capabilities

### New Capabilities

Отсутствуют.

### Modified Capabilities

- `cli-components`: команда импорта API-меты принимает платформу `swiftui` и нормализует мету SwiftUI в общий манифест.

## Impact

- `frontend-kt/feature-components`: нормализатор в `domain/apimeta`, регистрация в `ComponentsApplicationModule`, корпус и тесты.
- `frontend-kt/cli`: сквозной тест команды и раздел про импорт меты SwiftUI в `USAGE.md`.
- Backend, схема базы и формат манифеста не меняются.
- `ios-api-meta.json` менять не требуется: форма, на которую опирается нормализатор, уже закреплена инвариантами на стороне iOS.
