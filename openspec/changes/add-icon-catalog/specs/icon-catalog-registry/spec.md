## ADDED Requirements

### Requirement: Каталог хранит иконки с SVG и ключом старого формата

`ds-service` SHALL хранить каталог иконок, общий для окружения и не привязанный к проекту или дизайн-системе. Запись каталога MUST содержать каноническое имя (имя файла SVG в `@salutejs/sdds-icons` без расширения, например `DisclosureDownFill`), начертание, набор размеров из `16`, `24`, `36`, ключ старого формата, категорию (может отсутствовать) и список синонимов для поиска (может быть пустым). Начертание MUST определяться по суффиксу имени: `OutlineBold` → `outline-bold`, `Outline` → `outline`, `Fill` → `fill`, иначе `none`; сопоставление MUST учитывать только окончание имени. Ключ старого формата MUST получаться из имени разбиением по заглавным буквам и записью строчными через точку (`DisclosureDownFill` → `disclosure.down.fill`); значение свойства старого формата (`disclosure.down.fill.16`) MUST разбираться как ключ и размер после последней точки. Значение без начертания (`close.24`) MUST разрешаться как вариант `Outline` (ключ `close.outline`), если иконки с точным ключом `close` нет; точное совпадение ключа имеет приоритет. Это правило MUST одинаково применяться при проверке значения, в защите используемых иконок и в отчёте сверки. Файл SVG каждого размера MUST храниться в S3.

#### Scenario: Начертание по суффиксу

- **WHEN** загружаются иконки `AddOutline`, `AddOutlineBold`, `AddFill`, `ChevronLeftOutline` и `FillColorOutline`
- **THEN** их начертания MUST быть `outline`, `outline-bold`, `fill`, `outline` и `outline`.

#### Scenario: Ключ старого формата

- **WHEN** загружена иконка `InfoCircleOutline` с размером `16`
- **THEN** значение `info.circle.outline.16` MUST разрешаться в эту иконку и размер.

#### Scenario: Значение без начертания

- **WHEN** в каталоге есть `CloseOutline` с размером `24`, а в конфигурации хранится `close.24`
- **THEN** значение MUST разрешаться в `CloseOutline` размера `24`, считаться разрешённым в отчёте сверки и защищаться от удаления этой иконки.

#### Scenario: Коллизия ключей

- **WHEN** две иконки каталога дают один ключ старого формата
- **THEN** загрузка MUST быть отклонена кодом `400` с причиной `legacy_key_collision` и именами иконок.

### Requirement: Категории и синонимы для поиска

Каталог SHALL хранить для иконки категорию (например `Actions & Feedback`) и список синонимов для поиска, включая русские (`добавить`, `новый`). Категория и синонимы MUST быть общими для всех размеров иконки. Иконка без категории MUST возвращаться с `category: null`, а список категорий для фильтра MUST выводиться клиентом из каталога. Изменение только категории или синонимов MUST считаться изменением иконки и MUST давать новую загрузку.

#### Scenario: Иконка с категорией и синонимами

- **WHEN** загружается `AddOutline` с категорией `Actions & Feedback` и синонимами `add`, `добавить`
- **THEN** чтение каталога MUST вернуть эти значения для `AddOutline`.

#### Scenario: Иконка без категории

- **WHEN** категория иконки не передана
- **THEN** чтение MUST вернуть `category: null` и пустой список синонимов, а загрузка MUST быть принята.

#### Scenario: Изменилась только категория

- **WHEN** повторная загрузка отличается от активной только категорией иконки
- **THEN** итог MUST быть `published`, а иконка MUST быть в списке изменённых.

### Requirement: Формат загрузки каталога

Маршрут `POST /api/admin/icons/catalog` SHALL принимать JSON-тело с полями `schemaVersion` (значение `1`), `source` (`package` и `version` пакета-источника) и `icons` (массив `{name, category, aliases, sizes}`, где `category` — необязательная строка до 100 символов, `aliases` — необязательный массив до 40 строк по 1–64 символа, `sizes` — объект «размер → содержимое SVG», например `{"16": "<svg…", "24": "<svg…"}`). Сервис MUST отклонять запрос кодом `400` и причиной `invalid_body`, если `schemaVersion` неизвестен, `icons` пуст, имя не соответствует `^[A-Z][A-Za-z0-9_]*$`, имя повторяется, `sizes` пуст или содержит ключ вне `16`, `24`, `36`, SVG пуст, `category` или `aliases` не соответствуют ограничениям. Размер одного SVG MUST быть не больше 64 КиБ, тела запроса — не больше 32 МиБ; превышение MUST давать `413`.

#### Scenario: Пустой список иконок

- **WHEN** запрос содержит `icons: []`
- **THEN** сервис MUST ответить `400` с причиной `invalid_body` и MUST NOT менять каталог.

#### Scenario: Недопустимый размер

- **WHEN** иконка содержит размер `20`
- **THEN** сервис MUST ответить `400` и MUST NOT менять каталог.

#### Scenario: Повторяющееся имя

- **WHEN** имя `AddOutline` встречается в `icons` дважды
- **THEN** сервис MUST ответить `400` и назвать имя в ответе.

### Requirement: Проверка содержимого SVG

Сервис SHALL разбирать SVG с отключёнными DTD и внешними сущностями (защита от XXE и billion laughs; документ с `DOCTYPE` или объявлением сущностей MUST отклоняться) и проверять его по allowlist: корневой элемент `svg`; допустимые элементы только графические (`svg`, `g`, `defs`, `path`, `circle`, `ellipse`, `rect`, `line`, `polyline`, `polygon`, `clipPath`, `mask`, `linearGradient`, `radialGradient`, `stop`, `title`, `desc`, `metadata`) и допустимые атрибуты только представления и геометрии (без `on*`, `style`, `href` и `xlink:href`, кроме локальных ссылок вида `#id` в `use`/`fill`/`clip-path`/`mask`). Любой элемент или атрибут вне allowlist (в том числе `script`, `style`, `a`, `animate`, `set`, `foreignObject`, `iframe`, `image`, `use` с внешней ссылкой, `data:` и `javascript:` в значениях) MUST приводить к ответу `400` с причиной `unsafe_svg`. Допустимый перечень зафиксирован в коде и тестируется. Файлы MUST сохраняться в S3 без изменений.

#### Scenario: SVG со скриптом

- **WHEN** в SVG есть элемент `script`
- **THEN** сервис MUST ответить `400` с причиной `unsafe_svg` и именем иконки, ничего не записав в S3 и БД.

#### Scenario: Анимация, подменяющая ссылку

- **WHEN** в SVG есть `<animate>` или `<set>` с `attributeName="href"` и `to="javascript:…"`
- **THEN** сервис MUST ответить `400` с причиной `unsafe_svg`.

#### Scenario: Стили и ссылки

- **WHEN** в SVG есть `<style>` с `@import` или `url(http…)`, элемент `<a>` или `data:` URI в `href`
- **THEN** сервис MUST ответить `400` с причиной `unsafe_svg`.

#### Scenario: DTD и сущности

- **WHEN** SVG содержит `DOCTYPE` с объявлением сущности
- **THEN** сервис MUST ответить `400` с причиной `unsafe_svg`, не раскрывая сущности.

#### Scenario: Корректный SVG

- **WHEN** SVG содержит только `svg`, `path`, `g`, `defs`, `clipPath` и `mask` без внешних ссылок
- **THEN** сервис MUST принять его.

### Requirement: Пробная загрузка по умолчанию

Параметр `dryRun` маршрута загрузки SHALL по умолчанию иметь значение `true`. При `dryRun=true` сервис MUST выполнить все проверки, вычислить различия с активным каталогом и отчёт сверки и MUST NOT изменять БД и S3. Ответ MUST содержать число добавленных, удалённых, изменённых (другой набор размеров, другой SVG, другая категория или другие синонимы) и неизменных иконок и имена добавленных, удалённых и изменённых иконок (не более 200 имён в каждом списке с признаком усечения).

#### Scenario: Пробная загрузка

- **WHEN** запрос выполнен без `dryRun` и каталог отличается от активного
- **THEN** ответ MUST описывать различия, а БД и S3 MUST остаться прежними.

#### Scenario: Большое число различий

- **WHEN** добавлено больше 200 иконок
- **THEN** список имён MUST быть усечён до 200, а счётчик MUST содержать полное число.

### Requirement: Запись переключает каталог атомарно

При `dryRun=false` сервис SHALL выполнить запись в таком порядке: загрузить SVG в тот же бакет S3, что и плагин превью, под префикс `<prefix>/icons/<loadId>/<size>/<Name>.svg` (`<prefix>` — префикс плагина; ключи плагина под `builds/` MUST NOT затрагиваться), затем одной транзакцией БД заменить каталог, записать строку журнала и сделать загрузку активной. Идентификатор загрузки `loadId` MUST быть первыми 12 символами sha256 канонической записи (отсортированные имена, категории, синонимы, размеры и sha256 каждого SVG). Файлы загрузки MUST NOT изменяться после записи. SVG MUST заливаться до начала транзакции (файлы неизменяемы и лежат под идентификатором содержимого), а использование иконок MUST считаться после замены каталога в той же транзакции, чтобы запись значения `icon`, начатая раньше, успела завершиться и была учтена. Ошибка до коммита транзакции MUST оставлять активным прежний каталог, а осиротевшие файлы MUST удаляться очисткой.

#### Scenario: Успешная запись

- **WHEN** запрос с `dryRun=false` отличается от активного каталога
- **THEN** SVG MUST лежать в S3 под новым `loadId`, каталог MUST совпасть с запросом, а ответ MUST иметь итог `published`.

#### Scenario: Сбой записи в БД

- **WHEN** транзакция завершается ошибкой после загрузки в S3
- **THEN** активным MUST остаться прежний каталог и прежний `loadId`.

#### Scenario: Хранилище не настроено

- **WHEN** параметры S3 плагина (`DS_PLUGIN_S3_*`, `DS_PLUGIN_PUBLIC_BASE_URL`) не заданы
- **THEN** сервис MUST ответить на загрузку `503` и MUST NOT менять каталог.

### Requirement: Повторная загрузка идемпотентна, откат повторной загрузкой

Если `loadId` запроса совпадает с активным, сервис SHALL ответить итогом `unchanged` и MUST NOT менять БД и S3. Если `loadId` совпадает с ранее записанной неактивной загрузкой, файлы которой ещё хранятся, сервис MUST сделать её активной без повторной загрузки файлов и ответить `activated`. Версия пакета-источника в `loadId` MUST NOT участвовать.

#### Scenario: Тот же каталог

- **WHEN** запрос с `dryRun=false` повторяет активный каталог
- **THEN** итог MUST быть `unchanged`.

#### Scenario: Возврат к прежнему каталогу

- **WHEN** запрос повторяет содержимое предыдущей загрузки, файлы которой не удалены
- **THEN** итог MUST быть `activated`, а активной MUST стать та загрузка.

### Requirement: Очистка старых загрузок

После успешной записи сервис SHALL оставить в журнале активную загрузку и не более `DS_ICON_KEEP_LOADS` предыдущих (по умолчанию 3) и MUST снять строки остальных. Файлы в S3 MUST удаляться, только когда у загрузки нет строки в БД и они старше `DS_ICON_ORPHAN_GRACE_HOURS` (по умолчанию 24, не меньше 1): так параллельная запись, которая уже залила или активирует загрузку, не теряет файлы. Сбой очистки MUST NOT делать запись неуспешной.

#### Scenario: Лишние загрузки

- **WHEN** после записи в журнале больше четырёх загрузок
- **THEN** строки самых старых MUST быть сняты, а их файлы MUST быть удалены, когда пройдёт срок ожидания.

#### Scenario: Свежие файлы без строки

- **WHEN** в S3 есть файлы загрузки без строки в БД младше срока ожидания (идущая запись)
- **THEN** очистка MUST NOT удалять их.

#### Scenario: Сбой очистки

- **WHEN** удаление в S3 завершилось ошибкой
- **THEN** ответ загрузки MUST остаться успешным.

### Requirement: Защита используемых иконок

Если загрузка удаляет иконку или размер иконки, на которые ссылаются значения свойств типа `icon` в `variation_property_values` или `invariant_property_values` (в формате старого формата), сервис SHALL отклонить загрузку кодом `409` с причиной `icons_in_use` и MUST перечислить иконки, размеры и число ссылок. Параметр `allowRemovingUsed=true` MUST разрешать такую загрузку. Пробная загрузка MUST показывать те же сведения в ответе без ошибки.

#### Scenario: Удаляется используемая иконка

- **WHEN** на иконку `DisclosureDownFill` размера `16` есть ссылка в конфигурации, а новая загрузка её не содержит
- **THEN** запись MUST быть отклонена `409 icons_in_use` с этим именем, а каталог MUST остаться прежним.

#### Scenario: Явное разрешение

- **WHEN** тот же запрос выполнен с `allowRemovingUsed=true`
- **THEN** загрузка MUST быть записана.

#### Scenario: Пробная загрузка

- **WHEN** тот же запрос выполнен с `dryRun=true`
- **THEN** ответ MUST содержать список используемых удаляемых иконок и код `200`.

### Requirement: Отчёт сверки значений с каталогом

Ответ загрузки SHALL содержать отчёт сверки: число значений свойств типа `icon`, разрешаемых в каталоге после загрузки, и число не разрешаемых, а также до 50 различных не разрешаемых значений. Отчёт MUST NOT менять сохранённые значения.

#### Scenario: Значения совпадают с каталогом

- **WHEN** все значения `icon` в конфигурациях разрешаются в загружаемый каталог
- **THEN** число не разрешаемых MUST быть нулём.

#### Scenario: Есть неизвестные значения

- **WHEN** в конфигурации хранится значение `legacy.star.24`, которого нет в каталоге
- **THEN** отчёт MUST перечислить его, а само значение MUST остаться без изменений.

### Requirement: Права на загрузку каталога

Загружать каталог SHALL могут только системный администратор и служебная учётка с ролью `compose_preview_publisher`. Сервис MUST проверять роль до чтения тела запроса и MUST отвечать `403` остальным, включая участников проектов. Личный токен доступа (PAT) MUST NOT допускаться gateway к маршруту: административные операции требуют авторизации OAuth или служебной учётки.

#### Scenario: Участник проекта

- **WHEN** обычный пользователь отправляет запрос загрузки
- **THEN** сервис MUST ответить `403`, тело MUST NOT читаться.

#### Scenario: Служебная учётка публикации

- **WHEN** запрос выполняет служебная учётка с ролью `compose_preview_publisher`
- **THEN** сервис MUST принять загрузку.

#### Scenario: Личный токен доступа

- **WHEN** запрос выполнен с личным токеном доступа (PAT), в том числе владельца-администратора
- **THEN** gateway MUST ответить `403`.

### Requirement: Чтение каталога клиентом

Маршрут `GET /api/projects/{projectId}/design-systems/catalog/icons` (внутренне `GET /api/design-systems/catalog/icons`) SHALL возвращать участнику проекта с правом `components:read` (в том числе по PAT со scope `components:read`) активный каталог одним ответом: `source` (`package`, `version`, `loadedAt`, `loadId`), `assetsBaseUrl` (публичный адрес префикса загрузки без завершающего `/`) и массив иконок `{name, style, sizes, legacyKey, category, aliases}`, упорядоченный по имени. SVG иконки MUST быть доступен клиенту по адресу `<assetsBaseUrl>/<size>/<name>.svg`. Ответ MUST содержать заголовок `ETag`, а запрос с совпадающим `If-None-Match` MUST получать `304`. Если активной загрузки нет, ответ MUST быть `200` с пустым массивом, `source: null` и `assetsBaseUrl: null`.

#### Scenario: Каталог загружен

- **WHEN** участник проекта запрашивает каталог после загрузки
- **THEN** ответ MUST содержать все иконки с начертанием, размерами и ключом старого формата, `source` и `assetsBaseUrl` активной загрузки.

#### Scenario: Каталог ещё не загружался

- **WHEN** в окружении не было ни одной загрузки
- **THEN** ответ MUST быть `200`, `icons` пустым, `source` и `assetsBaseUrl` равными `null`.

#### Scenario: Кеш по ETag

- **WHEN** клиент повторяет запрос с актуальным `If-None-Match`
- **THEN** сервис MUST ответить `304` без тела.

#### Scenario: Не участник проекта

- **WHEN** запрос выполняет пользователь без доступа к проекту
- **THEN** сервис MUST ответить `403`.
