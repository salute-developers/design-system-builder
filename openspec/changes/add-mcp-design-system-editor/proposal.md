# MCP-редактор дизайн-системы

## Зачем

MCP читает модель DS Builder, но пока не позволяет редактировать токены и конфигурации компонентов. Агенту нужны предметные инструменты с исходными значениями, редакциями и устойчивыми повторами записи.

## Зависимость

Change опирается на `scope-design-system-routes` из ПР #149, ветка `feature/ds-routes`. Для интеграции и выпуска его реализация должна предоставить обязательную область DS в URL, серверную проверку принадлежности, повторяемость в этой области и обновлённые существующие клиенты. Независимые транспорт, команды, схемы и адаптеры под целевые URL реализуются заранее и проверяются через поддельный HTTP-клиент. Интеграция и выпуск требуют готовой зависимости.

## Что изменится

- MCP получит точечное редактирование определений и значений токенов, операции цветовых семейств и поддерживаемых цветовых групп.
- Появятся инструменты конфигураций компонентов, осей, вариантов, свойств, наборов состояний и их порядка.
- Чтения исходных данных дадут значения и редакции для подготовки мутаций.
- Общий Kotlin-транспорт поддержит PUT/PATCH/DELETE, вложенные схемы MCP, метаданные и безопасные ошибки.
- Специализированные обновления размеров и типографики получат сохранение повторяемого ответа через существующий серверный механизм.

## Возможности

### Новые возможности

- `mcp-token-editing` — точечное и семейное редактирование токенов, цветовых групп и получение исходных значений.
- `mcp-component-editing` — редактирование конфигураций, осей, вариантов и значений свойств с состояниями.

### Изменённые возможности

- `frontend-mcp-server` — реестр мутаций, вложенные схемы, контекст черновика, результаты и ошибки.
- `multi-user-design-system-editing` — повторяемые ответы специализированных обновлений размеров и типографики поверх области DS из зависимого change.

## Влияние

- `backend-kt/ds-service` — подключение повторяемого ответа в двух специализированных обработчиках, их OpenAPI и контрактные/интеграционные проверки.
- `frontend-kt/core-network`, `feature-theme`, `feature-components`, `mcp-server-core`, средства запуска CLI/Node — транспорт, типизированные команды, адаптеры, схемы и регистрация инструментов.
- Веб-клиент используется для сверки результатов через интерфейс. Перенос маршрутов веб-клиента, IDE-плагинов, серверных потребителей и API Reference выполняется в `scope-design-system-routes`.

## Вне целей

Мутации общего каталога, новые виды групп и семейное создание/удаление теней остаются за границами MCP-редактора. Маршрутная миграция и общая серверная защита принадлежат зависимому change.
