# Контракт публичного входа

`gateway-contract.json` фиксирует все `location` локального и production nginx в исходном
порядке: авторизацию, преобразование пути, ограничения, перенаправления и заголовки.
Контрольная сумма связывает матрицу с полным исходным файлом, включая общие директивы
HTTP/CORS/ограничений. nginx не изменяется и не нужен при запуске монолита.

Это исторический снимок прежнего публичного входа, а не развиваемый контракт монолита.
Актуальные требования поддерживаются в OpenSpec и тестах приложения. Проверка хеша
подтверждает неизменность исходного снимка, но не доказывает соответствие поведения app.

Проверка полноты матрицы без работающего backend:

```bash
python3 backend-kt/app/contracts/check_gateway_contract.py --report /tmp/gateway-contract.json
```

В этом режиме отчёт содержит `executed: false`: это проверка исходного контракта,
а не доказательство работоспособности приложения.

После сборки приложения проверка доступности и основных отказов публичного входа:

```bash
python3 backend-kt/app/contracts/check_gateway_contract.py \
  --target http://localhost:8080 --settings local --report /tmp/gateway-contract-live.json
```

`--settings` выбирает описание окружения отчёта и не переключает поведение приложения:
все параметры app передаются через env. Расширенные сценарии JWT, ключей, загрузок,
изменений DS и браузерного Keycloak выполняются контрактными тестами приложения и
обязательными внешними проверками OpenSpec; успешные базовые HTTP-пробы их не заменяют.

IP-лимиты частоты и соединений из исторической матрицы не являются контрактом app:
они настраиваются внешней инфраструктурой. Приложение сохраняет лимиты тела, авторизацию и таймауты.
