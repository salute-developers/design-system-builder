# Каноническая политика авторизации проектов

`policy.json` — машиночитаемый источник истины, общий для Projects Service и Documentation Service.
`policy.schema.json` определяет его структурный контракт, а `conformance.json` содержит независимые от языка реализации
сценарии проверки вычислителя разрешений.

Политика намеренно объединяет детализированные разрешения Projects Service из ADR-0001 и разрешения вида
«сущность/действие» из `openspec/architecture/Roles.md`. ADR точнее описывает жизненный цикл проекта, управление
участниками и ключами доступа, поэтому при расхождениях приоритет имеют уже действующие правила сервиса. В частности,
Maintainer сохраняет `project:update_metadata`, а архивировать и восстанавливать проект может только Owner. Разрешения
вида «сущность/действие» остаются контрактом для нижестоящих контентных сервисов. Для документации добавлены только
`documentation:read` и `documentation:write`.

Сервисы загружают неизменяемый снимок политики при запуске. Для диагностики развёртывания можно настроить внешний путь,
при этом тот же артефакт встроен в образы обоих сервисов. Если настроенный файл отсутствует или некорректен, сервис не
должен переходить на разрешающую политику по умолчанию.
