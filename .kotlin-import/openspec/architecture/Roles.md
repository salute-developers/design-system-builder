# Сущности DS Builder

- Проекты (projects)
- Участники проекта (members)
- Дизайн-системы (design-systems)
- Тенанты/темы (tenants)
    - Подтемы (tenants:subthemes)
- Токены (tokens)
    - Группы токенов (tokens:groups)
    - Подгруппы токенов (tokens:subgroups)
- Компоненты/конфигурации (components)
    - Вариации компонентов (components:variations)

### Действия над сущностями

#### Проекты
- Создание проекта
- Изменение метаданных проекта
- Удаление проекта
####  Участники проекта
- Добавление пользователей
- Удаление пользователей
- Изменение ролей пользователей
#### Дизайн-системы
- Создание дизайн-системы
- Изменение метаданных дизайн-системы
- Удаление дизайн-системы
#### Тенанты (темы)
- Создание темы
- Удаление темы
- Изменение метаданных темы
#### Подтемы (OnDark, OnLight, Inverse)
- Создание подтемы
- Удаление подтемы
- Изменение метаданных подтемы
#### Токены
- Создание токенов
- Удаление токенов
- Изменение токенов
#### Группы токенов
- Создание группы
- Удаление группы
- Изменение метаданных группы
#### Подгруппы токенов
- Создание подгруппы
- Удаление подгруппы
- Изменение метаданных подгруппы
#### Конфигурации компонентов
- Создание конфигурации
- Удаление конфигурации
- Изменение метаданных конфигурации
#### Вариации компонентов
- Создание вариации
- Удаление вариации
- Изменение метаданных вариации
- Изменение значений вариации

# Ролевая модель

### Модель разрешений (permissions)

Выделяем три основных действия над сущностью:
- read - чтение данных без возможности их изменить
- write - создание и изменение данных
- delete - удаление данных
