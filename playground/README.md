# Playground

Локальная зона для ручной проверки DS Builder CLI.

`playground` намеренно не является Gradle-проектом и не подключается к корневым
`settings.gradle.kts`. Внутренние директории могут быть самостоятельными проектами,
которые запускаются отдельно.

## Projects

- `sdds-ds-compose` - standalone Gradle-проект для проверки CLI на Compose
  дизайн-системе. SDDS-конфиги в репозиторий не добавлены: положите экспорт из БД
  в локальную `.sdds` внутри проекта перед запуском CLI.
