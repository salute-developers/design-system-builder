  `2355:784` «02 Radius / cRxs» (только скриншот `scratchpad/figma/radius-overview.png`, цвета сняты с пикселей).
- **Проверены в Figma во встроенном браузере (визуально, масштаб 68–200 %, и значения из панели Properties
  выделенных слоёв: размеры, переменные цветов с HEX, стили текста, текст слоя):** `5025:113492` «01 Overview /
  Inset M», `2469:91998` «02 Radius / Calculated», `2356:791` «03 Edit / Gap active», `2356:1407` «03 Edit / Radius
  active», `2356:3183` «04 List / Search open», `2356:3408` «04 List / Search results», `2356:3650` «04 List /
  Search no results», `2356:3870` «04 List / Filter open», `2356:4102` «04 List / Filter warnings», `2356:4325`
  «05 System / Loading», `2356:4581` «05 System / Error», `2356:4810` «05 System / Read only», `2563:101165`
  «06 Validation / Gap warning», `2563:101757` «06 Validation / Gap error»; `Workspace · Responsive QA ·
  Foundation`: `6118:194761` «Sizes · 1280×600 · Inspector 400», `6118:195417` «Sizes · 2048×900 · Inspector 320»;
  компоненты `Foundation/SpacingPreview` `4175:90186` и `ResourceCatalog/EmptyState` `2121:47685`.

Не проверены (частично): точные размеры скелетонов в «Loading» (сверено визуально при 68 %); пункты меню
«Filter open» сверены визуально и по `builder.xml`, без Properties; цвет выделенной строки дерева в кадрах,
кроме Gap M, — по пикселям не снимался. Причина — во встроенном браузере Figma рендерит холст с ограниченным
разрешением, а каждое значение берётся отдельным выделением слоя; для перечисленного это не меняло вывода. Шапка
и рейл не описаны (общая оболочка). **Замечание к самому Figma:** в «Search results» и «Filter warnings» строка
`Gap/M` показывает «24 px», а во всех остальных кадрах `Gap/M` = 8 px; в «Gap warning» / «Gap error» тексты
сообщений — заглушки «Text warning» / «Text error».

Стенд: тема `base_default`, тёмная тема интерфейса, окно 1440×800 (и 1280×600, 2048×900 для адаптивных кадров).
Замеры — `getBoundingClientRect` / `getComputedStyle`. Состояния «ошибка значения», «строка нового токена» и
«поиск» воспроизведены на стенде без отправки правок; «только чтение», «загрузка», «ошибка загрузки» — по коду
(`pages/shapes/SizeTokensScreen.tsx`, `ui/SizeTokenInspector.tsx`, `Shapes.tsx`, `styles/size-tokens.css`).

Важно для поля «Осознанно?»: решения change `add-sizes-tokens-editor` сформулированы относительно **прототипа
SDDS Portal**, а не Figma; ссылки на `design.md` ниже — там, где расхождение с прототипом совпадает с расхождением
с Figma. Задача сверки вёрстки с прототипом при 1440 px (`openspec/changes/add-sizes-tokens-editor/tasks.md:53`,
6.4) не выполнена. Ниже `design.md` = `openspec/changes/add-sizes-tokens-editor/design.md`,
`spec.md` = `openspec/changes/add-sizes-tokens-editor/specs/sizes-tokens-editor/spec.md`.
